# Operation Guide

Use the OMX operation guides according to the task you want to run.

| Page | Use it for |
| --- | --- |
| [Cyclo Manager](/docs/systems/omx/quick_start_guide/operation_guide/cyclo_manager) | Use the browser UI to bring up OMX, manage containers, update versions, open noVNC, and use manual jog controls. |
| [Teleoperation](/docs/systems/omx/quick_start_guide/operation_guide/teleoperation) | Run the OMX leader-follower teleoperation stack, camera node, or follower bringup for model inference. |
| [Robot Control](/docs/systems/omx/quick_start_guide/operation_guide/robot_control) | Run standalone bringup, MoveIt 2, OpenMANIPULATOR GUI, or keyboard teleop. |
