# noVNC

Use noVNC to open a remote desktop in the browser and run graphical tools such as **Dynamixel Wizard 2.0** on OMX without attaching a separate display or laptop.

:::info
OMX runs on the user PC, so you can also run **Dynamixel Wizard 2.0** directly on the host.
If you prefer to use the preconfigured container environment, use noVNC to run **Dynamixel Wizard 2.0** inside the container.
:::

Start the noVNC container, then open the **Dynamixel Wizard 2.0** icon on the remote desktop.

1. Click the **Start** control at the top of the page to start the noVNC container.
2. Reload the page, for example press **F5**.
3. Open the **Dynamixel Wizard 2.0** icon on the desktop.

![noVNC page](/img/systems/omx/quick_start_guide/operation_guide/cyclo_manager/novnc_page.png)

You can diagnose and control motors in the browser without attaching a display or laptop to OMX.
