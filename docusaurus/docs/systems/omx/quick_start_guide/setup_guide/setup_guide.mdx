## Choose Your Setup Path

| Setup path | Use it when |
| :---: | :--- |
| [ROS 2 Setup](/docs/systems/omx/quick_start_guide/setup_guide/ros2_setup) | You want to use OMX with ROBOTIS ROS 2 packages, OpenMANIPULATOR, Cyclo Intelligence, Cyclo Control, or Physical AI Tools. |
| [LeRobot](https://huggingface.co/docs/lerobot/omx) | You want to use OMX directly with the LeRobot workflow. |

If you plan to use Cyclo Intelligence, Cyclo Control, or Physical AI Tools, complete **ROS 2 Setup** first. Then continue to the operation guide or imitation learning guide for your workflow.

:::info
The LeRobot workflow does not require the ROS 2 setup on this page.
:::
