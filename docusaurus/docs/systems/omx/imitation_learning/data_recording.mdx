# Recording

With the leader arm, pick up one box and put it on the other, at least 50 times. Cyclo Intelligence records every try, and the AI learns from them. Then you make a dataset from your tries.

Before starting, complete [Setup](/docs/systems/omx/imitation_learning/setup). Everything from [4. Bringup OMX and Start Cyclo Intelligence](/docs/systems/omx/imitation_learning/setup#4-bringup-omx-and-start-cyclo-intelligence) must still be running: four terminals and the **Record** page.

You do not have to match these pictures exactly. But it helps if a small part of each box shows at the start pose: our ACT model looked at this part of the picture to decide whether to start or to wait.

The **Record** page zooms the camera picture a little to fill its frame, so the top and bottom edges of the picture are not shown there. You may see only a small part of each box on the page, but the model gets the whole picture.

Keep the same light for every try and when you run the model.

## 3. Record at Least 50 Tries

Repeat points 2 and 3 of [2. Record One Try](#2-record-one-try), at least 50 times, which is the start LeRobot suggests. Before each try, put the boxes back in their places.

- Start every try from the same arm pose
- Pick up the same box every time, and grasp it the same way
- Hold the leader with one hand and click with the other
- A try went wrong? Click **Discard Episode** and do it again

When you are done, the number after **EP** is 50 or more.

<details className="omx-fix">
  <summary>Something different?</summary>

| You see | Do this |
| --- | --- |
| **Record Start** stays grey | Fill in the first two boxes, `1` and `stack_box`. |
| A red dot in **Topic Monitor** | Something is not running. Do the fix in [Bringup OMX and Start Cyclo Intelligence](/docs/systems/omx/imitation_learning/setup#4-bringup-omx-and-start-cyclo-intelligence). |
| The number after **EP** does not go up | The try was not saved. Click **Save Episode** at the end of each try. |
| No **EP** number on the page | Make the browser window wider. |

</details>

Your tries are saved on the PC, so this is a good place for a break. To go on later, start everything as in [Bringup OMX and Start Cyclo Intelligence](/docs/systems/omx/imitation_learning/setup#4-bringup-omx-and-start-cyclo-intelligence).

<details>
  <summary>How does it work?</summary>

  Each try is saved as one episode: the camera video, the leader's moves and the follower's moves. The AI later learns to turn what the camera sees into the moves you made, so try to make the same clear move every time.

</details>
