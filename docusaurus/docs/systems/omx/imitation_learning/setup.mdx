# Setup

<SectionCard>

## Before You Begin

This Imitation Learning section shows the simplest way to try imitation learning with OMX, using **[Cyclo Intelligence](/docs/software/cyclo/cyclo_intelligence)**. Cyclo Intelligence is the ROBOTIS software that connects recording, dataset preparation, training and running the model.

Right after you assemble OMX, you teach it one task, putting one box on the other, and train ACT, a small imitation learning model, on your tries. The boxes are the two OpenRB-150 boxes that come with OMX.

You do it in four steps, one on each page of this section:

1. **[Setup](/docs/systems/omx/imitation_learning/setup)** (this page): install Cyclo Intelligence, then start OMX, its camera and Cyclo Intelligence.
2. **[Recording](/docs/systems/omx/imitation_learning/data_recording)**: with the leader arm, put one box on the other at least 50 times. Cyclo Intelligence records every try. Then you make a dataset from your tries.
3. **[Training](/docs/systems/omx/imitation_learning/model_training)**: train an ACT model on your dataset, with the NVIDIA graphics card in your PC.
4. **[Inference](/docs/systems/omx/imitation_learning/model_inference)**: run the model. OMX does the task by itself.

Before starting, complete [Teleoperation](/docs/systems/omx/quick_start_guide/teleoperation).

:::info[What is ACT?]
ACT is an imitation learning model. It looks at the camera picture and the arm's angles, and plans the next moves in the way your tries showed it.

ACT is a good model for a first dataset. It is small, and it learns on the one graphics card in your PC.

You show OMX a task at least 50 times with the leader arm. ACT learns from your tries, and then OMX tries the task by itself.
:::

### Requirements

You need OMX and two boxes. [Training](/docs/systems/omx/imitation_learning/model_training) and [Inference](/docs/systems/omx/imitation_learning/model_inference) also need an NVIDIA graphics card in your PC.

## 1. Install Cyclo Intelligence

Cyclo Intelligence records what you show OMX, and later runs the AI model. You install it once.

In a PC terminal:

```bash
curl -fsSL https://raw.githubusercontent.com/ROBOTIS-GIT/cyclo_intelligence/main/install.sh | bash
```

When it is done, it shows where it put Cyclo Intelligence. On your PC, your user name is in place of `robotis`.

<TutorialMedia
  label="The terminal after the install command. The lines in the middle, where git downloads Cyclo Intelligence, are left out and shown as three dots. The line [install] Installed Cyclo Intelligence at: /home/robotis/cyclo_intelligence is marked in red. The last lines say how to start it, and that the model sources were not downloaded."
  src="/img/systems/omx/imitation_learning/setup/install_cyclo_intelligence.webp"
  shape="free"
  width={760}
  height={285}
/>

The last lines also say that the model sources were not downloaded. Download the one this guide uses, LeRobot. [Training](/docs/systems/omx/imitation_learning/model_training) builds the AI program from it.

```bash
cd ~/cyclo_intelligence
git submodule update --init -- \
  cyclo_brain/sdk/zenoh_ros2_sdk \
  cyclo_brain/policy/lerobot/lerobot
```

The last line starts with `Submodule path 'cyclo_brain/policy/lerobot/lerobot': checked out`.

<details className="omx-fix">
  <summary>Something different?</summary>

| `curl: command not found` | Paste `sudo apt install curl`, then do this section again. |

If it was downloaded before, update it:

```bash
cd ~/cyclo_intelligence && git pull --ff-only
git submodule update --init -- \
  cyclo_brain/sdk/zenoh_ros2_sdk \
  cyclo_brain/policy/lerobot/lerobot
```

Then, in [3. Start the AI Program](/docs/systems/omx/imitation_learning/model_training#3-start-the-ai-program) of Training, start the AI program with this line the first time:

```bash
./docker/container.sh start-lerobot --build
```

</details>

## 2. Start It and Enter Its Container

```bash
cd ~/cyclo_intelligence
./docker/container.sh start
./docker/container.sh enter
```

It downloads Cyclo Intelligence, then opens a terminal inside its container. Wait until you can type again. If it asks for your password, type it.

<details className="omx-fix">
  <summary>Something different?</summary>

| You see | Do this |
| --- | --- |
| A line that ends with `no space left on device` | Free some disk space. Then do this section again. |

</details>

## 3. Check the Zenoh Setting

In the Cyclo container, check the [Zenoh](/docs/systems/omx/specifications/software#middleware) setting:

```bash
grep ZENOH_CONFIG_OVERRIDE ~/.bashrc
```

You should see this. The first line, in the red box, is the setting. The second line starts with # and does nothing. That is fine.

<TutorialMedia
  label="The terminal after the check command. The first line, export ZENOH_CONFIG_OVERRIDE='transport/shared_memory/enabled=true', is marked in red. The second line starts with # and does nothing."
  src="/img/systems/omx/imitation_learning/setup/check_zenoh_setting.webp"
  shape="free"
  width={760}
  height={165}
/>

Then type `exit` and press **Enter** to leave the container.

<details className="omx-fix">
  <summary>Something different?</summary>

| You see | Do this |
| --- | --- |
| No line | Paste <code>echo "export ZENOH_CONFIG_OVERRIDE='transport/shared_memory/enabled=true'" >> ~/.bashrc</code>, then `source ~/.bashrc`. |

</details>

<details>
  <summary>How does it work?</summary>

  Cyclo Intelligence runs in its own Docker container, next to the robot software. You use it through a web page, which opens in the next section.

  The [Zenoh](/docs/systems/omx/specifications/software#middleware) setting lets Cyclo Intelligence talk to the robot's programs on this PC. The container comes with it, and this section only checks it.

</details>

</SectionCard>

## 4. Bringup OMX and Start Cyclo Intelligence

Bring up OMX and its camera, then start Cyclo Intelligence and look through the camera. Each time you come back to record, start in the same way.

:::warning
The follower moves by itself when the arms start. Keep its reach clear.
:::

Use four terminals, in this order. Leave each one open.

![The four terminals placed two by two on the screen. Terminal 1, robot container: Zenoh, with zenohd. Terminal 2, robot container: the arms, with ros2 launch open_manipulator_bringup omx_ai.launch.py. Terminal 3, robot container: the camera, with ros2 launch open_manipulator_bringup camera_usb_cam.launch.py. Terminal 4, Cyclo container: Cyclo Intelligence, with cyclo_intelligence.](/img/systems/omx/imitation_learning/setup/terminals_record.webp)

We recommend placing the terminals like this, so that you can see all four at once.

### Enter the Containers

Open four terminals with **Ctrl + Alt + T**. In Terminals 1, 2 and 3, enter the robot container.

```bash
cd $HOME/open_manipulator/docker
./container.sh enter
```

In Terminal 4, enter the Cyclo Intelligence container.

```bash
cd ~/cyclo_intelligence
./docker/container.sh enter
```

### Terminal 1: Zenoh

Start [Zenoh](/docs/systems/omx/specifications/software#middleware):

```bash
zenohd
```

### Terminal 2: The Arms

Hold the leader folded like the follower's start pose, as in [Start the Arms](/docs/systems/omx/quick_start_guide/bringup#2-start-the-arms). Then paste.

```bash
ros2 launch open_manipulator_bringup omx_ai.launch.py
```

### Terminal 3: The Camera

```bash
ros2 launch open_manipulator_bringup camera_usb_cam.launch.py
```

The last line:

```text
[usb_cam]: Timer triggering every 33 ms
```

<span id="another-camera" className="omx-anchor"></span>

<details>
  <summary>Only if your PC has another camera, such as a laptop's own</summary>

The OMX camera may then have another number than `/dev/video0`. Press **Ctrl + C** in Terminal 3, and find its number:

```bash
v4l2-ctl --list-devices
```

<TutorialMedia
  label="The terminal after v4l2-ctl --list-devices. HD USB Camera, and /dev/video0 in the first line under it, are marked in red."
  src="/img/systems/omx/imitation_learning/setup/camera_list_devices.webp"
  shape="free"
  width={430}
  height={107}
/>

Under `HD USB Camera`, take the first `/dev/video` line. Then set the camera topic namespace and video device explicitly, with that number in place of `/dev/video0`:

```bash
ros2 launch open_manipulator_bringup camera_usb_cam.launch.py name:=camera1 video_device:=/dev/video0
```

Keep `name:=camera1`. Cyclo Intelligence looks for the camera by this name.

</details>

### Terminal 4: Cyclo Intelligence

```bash
cyclo_intelligence
```

Wait for this line:

```text
[cyclo_data]: cyclo_data node ready.
```

<details className="omx-fix">
  <summary>Something different?</summary>

| You see | Do this |
| --- | --- |
| No picture, and `Device specified is not available` in Terminal 3 | Unplug the camera's USB cable and plug it in again. Press **Ctrl + C** in Terminal 3 and paste its line again. |
| The picture of another camera, such as a laptop's own | Open the box [Only if your PC has another camera](#another-camera), under Terminal 3. |
| A red dot at `/joint_states` or `/leader/joint_trajectory` | Cyclo Intelligence started before the arms. Press **Ctrl + C** in Terminal 4, paste its line again, reload the page, and choose `omx_f` again. |
| The page does not open | Terminal 4 is not running. Paste its line. |

</details>

<details>
  <summary>How does it work?</summary>

  Each terminal runs one program inside a container: [Zenoh](/docs/systems/omx/specifications/software#middleware), the arms and the camera in the robot container, and Cyclo Intelligence in its own. Cyclo Intelligence listens to the arms and the camera, so they must be running before it starts.

  To stop, lower the follower's gripper onto the table. Then press **Ctrl + C** in each terminal, from Terminal 4 back to Terminal 1.

</details>
