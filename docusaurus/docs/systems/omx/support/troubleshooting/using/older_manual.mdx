# Where Is the Older OMX Manual?

The older versions of the OMX pages are not on the site anymore.

The [docs repository on GitHub](https://github.com/ROBOTIS-GIT/docs) keeps every change. Go to the pull request or commit of the time you want, and build the site on your PC to read it.
