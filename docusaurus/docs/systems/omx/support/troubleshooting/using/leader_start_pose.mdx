# The Leader Does Not Go to Its Start Pose

That is normal. The leader never moves by itself: its arm joints have no torque, so it stays where your hand puts it.

When the arms start, the follower first moves to its start pose by itself. Then it takes the shape of the leader, and copies it. See [Start the arms](/docs/systems/omx/quick_start_guide/move_omx#start-the-arms).
