# Can I Use Two OMX Sets Together, or One Leader for Two Followers?

Not with the official software.

ROBOTIS answered that it can be built with ROS 2: for example, to run two sets on one PC, to move two followers with one leader, or to use two arms together for one task.

- Run each arm in its own ROS 2 namespace.
- Control the arms from one node above them.

You write that part yourself: there is no official example.
