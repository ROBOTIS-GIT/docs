# Which PC Can I Use?

A PC with Ubuntu 22.04 or 24.04, installed on the PC itself. It can be next to Windows (dual boot). On a virtual machine, Windows or macOS, OMX may not be found or may not start: see [OMX Does Not Start on a Virtual Machine, Windows, or Mac](/docs/systems/omx/support/troubleshooting/pc/pc_not_supported).

<SectionCard>

## To train AI models

The PC also needs an NVIDIA GPU. ROBOTIS suggests:

| | Minimum | Recommended |
| --- | --- | --- |
| CPU | Intel Core i5 or AMD Ryzen 5 | Intel Core i7 or AMD Ryzen 7 |
| Memory (RAM) | 16 GB | 32 GB |
| GPU | NVIDIA GPU with CUDA | NVIDIA RTX GPU |
| GPU memory | 6 GB | 8 GB |
| Storage | SSD with 100 GB free | SSD with 100 GB free |

</SectionCard>

<SectionCard>

## On a Jetson

Use a Jetson Orin Nano or better. Jetson Orin NX and AGX Orin run more stably. The first Jetson Nano is not recommended. Training runs better on a PC with an NVIDIA GPU.

</SectionCard>
