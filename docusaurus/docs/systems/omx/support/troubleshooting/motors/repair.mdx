# Where Do I Get a Repair?

Request a repair on the ROBOTIS A/S page. Then send the product to the address it shows, and ROBOTIS checks it.

Many motor problems can be fixed without a repair. Check these first:

- [The Follower Jumps or Does Not Match the Leader](/docs/systems/omx/support/troubleshooting/motors/arm_moves_wrong)
- [A Motor Blinks Red or Is Not Found](/docs/systems/omx/support/troubleshooting/motors/motor_not_found)
