# noVNC

Use noVNC to open a remote desktop in the browser and run graphical tools such as **Dynamixel Wizard 2.0** on OMY without attaching a separate display or laptop.

Start the noVNC container, then open the **Dynamixel Wizard 2.0** icon on the remote desktop.

1. Click the **Start** control at the top of the page to start the noVNC container.
2. Reload the page, for example press **F5**.
3. Open the **Dynamixel Wizard 2.0** icon on the desktop.

![noVNC page](/img/systems/omy/quick_start_guide/operation_guide/cyclo_manager/novnc_page.png)

You can diagnose and control motors in the browser without attaching a display or laptop to OMY.
