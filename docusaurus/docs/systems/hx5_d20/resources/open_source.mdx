# Open Source

The ROBOTIS Hand open-source stack provides the ROS 2 software, robot description, and supporting resources needed to operate and integrate the hand.

:::tip[Where should I start?]

- To set up and operate the hand, start with [`robotis_hand`](https://github.com/ROBOTIS-GIT/robotis_hand) and the [Setup Guide](/docs/systems/hx5_d20/quick_start_guide/setup_guide).
- For the currently available simulation model, see the [Simulation Overview](/docs/systems/hx5_d20/simulation).

:::

## Simulation Models

The following robot-description model is publicly available for ROBOTIS Hand.

| Format | Repository location | Use |
|:-------|:--------------------|:----|
| <span className="badge badge--secondary repository-category-badge">URDF</span> | <GitHubRepositoryLink href="https://github.com/ROBOTIS-GIT/robotis_hand/tree/main/robotis_hand_description/urdf">robotis_hand_description/urdf</GitHubRepositoryLink> | ROS 2 robot description and visualization |

MJCF and USD models are not currently listed for ROBOTIS Hand.

See the [Simulation Overview](/docs/systems/hx5_d20/simulation) for the available format description.
