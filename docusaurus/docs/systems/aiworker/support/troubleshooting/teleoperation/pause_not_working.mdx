# Teleoperation Does Not Pause as Expected

Check the `style` used to launch the Leader:

- With `style:=default`, hold both triggers forward for 2 seconds to pause both arms.
- With `style:=advanced`, hold the joystick button of the active arm alone for 0.5 seconds to pause that arm.

These controls apply to A1, A2, and LG2 Leaders. Release both triggers or all joystick buttons before repeating an action. If `style` is unavailable, update and rebuild the `ai_worker` source to a version that includes these controls.

For launch options, see [CLI Bringup & Teleoperation](/docs/systems/aiworker/quick_start_guide/advanced/cli_bringup_teleoperation#running-teleoperation-from-the-cli).
