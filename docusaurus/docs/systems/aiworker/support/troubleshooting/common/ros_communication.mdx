# ROS 2 Topics Are Not Visible

Check `ROS_DOMAIN_ID` and the robot's ROS 2 topic connections. The provided AI Worker container uses `ROS_DOMAIN_ID=30` by default.

```bash
ros2 topic list
```

To check data on a topic, run `ros2 topic echo` with the topic name. For external PC connections, see [External ROS 2 Communication](/docs/systems/aiworker/quick_start_guide/advanced/external_ros2_communication).
