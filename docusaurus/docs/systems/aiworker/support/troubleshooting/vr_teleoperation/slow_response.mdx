# VR Teleoperation Responds Slowly

Check the Wi-Fi connection. Network performance affects VR updates; a wired connection is recommended. See [Cannot Connect to the Robot](/docs/systems/aiworker/support/troubleshooting/common/network_connection).

If wireless performance is insufficient, host the VR server on the Robot PC and use a USB-C to Ethernet adapter to connect the Meta Quest 3. Connect the Ethernet cable to the robot's LAN port, not the WAN port. See [Hardware Setup](/docs/systems/aiworker/quick_start_guide/setup_hardware) for port identification.
