The same controls apply to **A1, A2, and LG2**. Use **Default Controls** with the standard Leader launch settings, or **Advanced Controls** if the Leader was launched with `style:=advanced`. Selecting a tab does not change the running Leader's settings.

Before starting, stop any other program that is sending motion commands to the Follower.

### Start and Pause Teleoperation

After the Leader has started, push **both triggers forward together for 2 seconds**, then release them to **start or pause teleoperation**.

- **Start:** The Follower's arms begin following the Leader. Keep the Leader steady while the Follower moves toward the Leader's pose.
- **Pause:** The arms stop following the Leader and hold their positions.

![Push both triggers forward to start or pause both arms](/img/systems/aiworker/quick_start_guide/teleoperation/push_trigger_ai_worker.gif)

:::warning
Pausing arm teleoperation does not stop head, lift, or mobile-base movement. Keep the joysticks centered, and use the robot's emergency stop if unexpected motion occurs.
:::

### Joystick & Gripper Controls

On models with a mobile base, press both joystick buttons together and release them **before 0.5 seconds** to switch between **Head mode** and **Base mode**.

| Control | Head mode | Base mode |
| --- | --- | --- |
| **Triggers** | Operate the corresponding grippers | Operate the corresponding grippers |
| **Left joystick** | Move the head | Move the base forward, backward, or sideways |
| **Right joystick: left / right** | — | Rotate the base |
| **Right joystick: up / down** | Move the lift | Move the lift |

![Mobile-base joystick directions: left joystick for translation and right joystick for turning](/img/systems/aiworker/quick_start_guide/teleoperation/LG2_Joystick.png)

:::warning
The arms continue following the Leader during mobile-base control.
:::
