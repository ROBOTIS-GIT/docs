# Bringup Guide

Use Cyclo Manager to start the AI Worker robot stack. Complete [Hardware Setup](/docs/systems/aiworker/quick_start_guide/setup_hardware) before continuing.

<SectionCard>

## 1. Network Connection

#### F1 / BG2

These models do not have a built-in router. Connect the robot's LAN port to an external router, then connect your PC to the same router using Wi-Fi or LAN. An external router is not included with the robot.

<AiWorkerNetworkDiagram router="external" />

#### F2 / SG2

These models have a built-in router. Connect your PC to the robot's Wi-Fi network:

- **Network name:** `AIWORKER` followed by the last four digits of the robot's serial number. ex. `AIWORKER0000`.
- **Default password:** The same as the network name. ex. `AIWORKER0000`

<AiWorkerNetworkDiagram router="built-in" />

</SectionCard>

<SectionCard>

## 2. Open Cyclo Manager

Open `http://ffw-<serial_number>.local:3000` in a browser on your PC, replacing `<serial_number>` with the serial number printed on the robot. For example, if the serial number is `SNPR48A0000`, open `http://ffw-SNPR48A0000.local:3000`. You can also use the robot's IP address with port `3000`.

Use [Cyclo Manager](/docs/software/cyclo/cyclo_manager) to bring up the robot. Cyclo Manager is pre-installed on F1 and F2 models. If it has not been installed, follow [Install](/docs/software/cyclo/manager/install).

Open the **System** page in Cyclo Manager to begin bringup.

![System Page](/img/systems/aiworker/quick_start_guide/operation_guide/cyclo_manager/system_page.png)

</SectionCard>

<SectionCard>

## 3. Start the Zenoh Daemon

:::info[RMW_ZENOH NOTIFICATION]
AI Worker uses Zenoh as RMW since version 2.0.0.
Start the Zenoh daemon before bringing up the robot stack.
For more information about Zenoh, see [Zenoh Communication](/docs/systems/aiworker/specifications/software#middleware).
:::

Click the arrow icon in the **Zenoh Daemon** control box to start the Zenoh daemon.
Check that the status light turns green. Once started, the Zenoh daemon restarts when the robot powers on.

![Zenoh Daemon](/img/systems/aiworker/quick_start_guide/operation_guide/cyclo_manager/zenoh_daemon.png)

</SectionCard>

<SectionCard>

## 4. Bringup the Robot

:::warning
Starting robot bringup will cause the robot to move.  
Before starting, make sure the area around the robot is clear and keep the emergency stop within reach.
:::

Select the robot model to bring up and click the **Robot Bringup(▶️)** button.
The status light turns green when the robot service starts.
Click the paper icon on the far right to view the logs in the side panel.

![Robot Bringup Button](/img/systems/aiworker/quick_start_guide/operation_guide/cyclo_manager/robot_bringup_button.png)

After the robot stack starts, the 3D model and robot status panels update automatically.
If the model or joint states do not update, check `ROS_DOMAIN_ID`, the robot bringup logs, and the relevant ROS 2 topics.

![Robot bringup in Cyclo Manager](/img/systems/aiworker/quick_start_guide/operation_guide/cyclo_manager/bringup_robot.gif)

</SectionCard>
