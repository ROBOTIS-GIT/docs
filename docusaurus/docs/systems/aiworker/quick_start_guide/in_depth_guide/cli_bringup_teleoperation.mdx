# CLI Bringup & Teleoperation

This guide explains how to connect to the robot and use the command line to bring up the robot and operate it through teleoperation.

<span id="running-teleoperation-from-the-cli" />

<SectionCard>

## 1. Connect to the Robot

1. Connect the robot and user PC to the [same network](/docs/systems/aiworker/quick_start_guide/bringup#1-network-connection).

2. Connect to the robot PC via [SSH](/docs/systems/aiworker/quick_start_guide/in_depth_guide/robot_pc_access).

3. Enter the `ai_worker` container ([How to use container.sh](/docs/systems/aiworker/quick_start_guide/in_depth_guide/development_environment)):

   ```bash
   cd ~/ai_worker/docker
   ./container.sh enter
   ```

</SectionCard>

<SectionCard>

## 2. Start the Zenoh Daemon

:::info[RMW_ZENOH NOTIFICATION]
AI WORKER uses zenoh as RMW since version 2.0.0, so you need to bring up the Zenoh daemon before bringup the robot.  
Please refer to the [Zenoh Communication](/docs/systems/aiworker/specifications/software#middleware) guide.
:::

:::warning
If Cyclo Manager is installed, the Zenoh daemon may already be running. In a separate robot PC terminal outside the container, check whether the **zenoh_daemon** container is running. If it is, you do not need to start the Zenoh daemon separately.
```bash
docker ps | grep zenoh_daemon
```
:::

In the AI Worker container, run the following command to bring up the Zenoh daemon:

```bash
ros2 run rmw_zenoh_cpp rmw_zenohd
```

or alias:

```bash
zenohd
```

</SectionCard>

#### Optional Parameters

You can customize the follower launch behavior with optional parameters: For other models, use their Follower launch file.

**Disable Camera Launch**
To run the system without launching the cameras, set the `launch_cameras` parameter to `false`:
```bash
ros2 launch ffw_bringup ffw_bg2_follower_ai.launch.py launch_cameras:=false
```

**Disable Position Initialization**
To start the system without initializing the position, set the `init_position` parameter to `false`:
```bash
ros2 launch ffw_bringup ffw_bg2_follower_ai.launch.py init_position:=false
```

**Enable Automatic Camera Assignment**
To automatically assign the connected RealSense cameras without manually configuring their serial numbers, set the `auto_assign_cameras` parameter to `true`:
```bash
ros2 launch ffw_bringup ffw_bg2_follower_ai.launch.py auto_assign_cameras:=true
```

FFW-W1/FFW-W2 use RealSense cameras for both the head and wrists, and automatic assignment is enabled by default.

:::warning
Automatic camera assignment may not work on some older FFW-BG2 and FFW-SG2 models. If this occurs, set `auto_assign_cameras:=false` and use your existing manual camera configuration.
:::

**Combine Multiple Parameters**
You can use both parameters together:
```bash
ros2 launch ffw_bringup ffw_bg2_follower_ai.launch.py launch_cameras:=false init_position:=false
```

#### Optional: Advanced Button Controls

All three Leaders use `style:=default` unless specified otherwise. To start and pause each arm separately and switch between Teleoperation mode and External control mode with the joystick buttons, add `style:=advanced` to the Leader launch command:

<Tabs groupId="aiworker-leader-type">
  <TabItem value="a1" label="A1">

```bash
ros2 launch ffw_bringup ffw_a1_leader_ai.launch.py style:=advanced
```

  </TabItem>
  <TabItem value="a2" label="A2">

```bash
ros2 launch ffw_bringup ffw_a2_leader_ai.launch.py style:=advanced
```

  </TabItem>
  <TabItem value="lg2" label="LG2">

```bash
ros2 launch ffw_bringup ffw_lg2_leader_ai.launch.py style:=advanced
```

  </TabItem>
</Tabs>

Choose one Leader command; do not run the default and advanced commands together. If the Leader is already running, stop it before relaunching with a different `style`.

## 4. Operation Guide

Launching the programs does not start arm teleoperation. Follow the [Operation Guide](/docs/systems/aiworker/quick_start_guide/teleoperation#4-operation-guide) to start and control teleoperation.

</SectionCard>

<SectionCard>

## 5. Stop the Services

To stop a launch command, press `Ctrl+C` in the terminal where it is running. If the Follower and Leader were started separately, stop each command in its respective terminal.
