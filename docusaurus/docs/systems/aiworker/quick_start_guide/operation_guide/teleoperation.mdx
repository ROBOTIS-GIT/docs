# Teleoperation

This guide explains how to set up and operate the AI Worker using teleoperation.

Select your **Leader** (A1, A2, or LG2) for setup and launch instructions. Select your **Follower** (the robot being controlled) separately for its launch commands. Button controls are shared across all three Leaders.

## Prerequisites

Before starting teleoperation, make sure:
- The follower(AI Worker) is properly set up and powered on

## Running Teleoperation
The following teleoperation commands are executed on the `robot PC`.
You can either connect a keyboard and mouse directly to the Nvidia Orin, or access it via SSH (see the Setup Guide for instructions).<br />

Enter the **ai_worker** Docker container with:

```bash
cd ~/ai_worker
./docker/container.sh enter
```

<RunZenohDaemon />

### Option 1: All-in-One Launch

These commands start an **LG2 Leader with BG2/SG2**, or an **A1 Leader with F1/F2**. For other combinations, use [Option 2: Separate Launches](#option-2-separate-launches).

:::tip[Default arm controls]
Launching the programs does not start arm teleoperation. On A1, A2, and LG2, push both triggers forward together for 2 seconds, then release them, to start both arms. Repeat the action to pause both arms. See [Basic Operation](#basic-operation) before starting.

#### Optional Parameters

You can customize the follower launch behavior with optional parameters: For other models, use their Follower launch file.

**Disable Camera Launch**
To run the system without launching the cameras, set the `launch_cameras` parameter to `false`:
```bash
ros2 launch ffw_bringup ffw_bg2_follower_ai.launch.py launch_cameras:=false
```

**Disable Position Initialization**
To start the system without initializing the position, set the `init_position` parameter to `false`:
```bash
ros2 launch ffw_bringup ffw_bg2_follower_ai.launch.py init_position:=false
```

**Enable Automatic Camera Assignment**
To automatically assign the connected RealSense cameras without manually configuring their serial numbers, set the `auto_assign_cameras` parameter to `true`:
```bash
ros2 launch ffw_bringup ffw_bg2_follower_ai.launch.py auto_assign_cameras:=true
```

F1/F2 use RealSense cameras for both the head and wrists, and automatic assignment is enabled by default.

:::warning
Automatic camera assignment may not work on some older BG2 and SG2 models. If this occurs, set `auto_assign_cameras:=false` and use your existing manual camera configuration.
:::

**Combine Multiple Parameters**
You can use both parameters together:
```bash
ros2 launch ffw_bringup ffw_bg2_follower_ai.launch.py launch_cameras:=false init_position:=false
```

## Basic Operation

:::warning
Pausing arm teleoperation is not an emergency stop and does not stop an independently running inference program or other program. Use the robot's emergency-stop procedure if unexpected motion occurs.
:::

## Stopping Teleoperation

To stop teleoperation:
1. Return to a neutral position or pause the system.
2. Press `Ctrl+C` in the terminal where the launch file is running.

## Troubleshooting

- **Delayed movements**: Check for any obstructions or if you're reaching joint limits
- **Unresponsive gripper**: Ensure proper calibration and connection
- **System unresponsive**: Check ROS topic connections with `ros2 topic list` and `ros2 topic echo`
- **Teleoperation does not pause as expected**: Check the `style` used to launch the Leader. On A1, A2, and LG2, `style:=default` uses both triggers held forward for 2 seconds to pause both arms; `style:=advanced` uses each active arm's joystick button held alone for 0.5 seconds to pause that arm. Release both triggers or all joystick buttons before repeating an action. If `style` is unavailable, update and rebuild the `ai_worker` source to a version that includes these controls.
