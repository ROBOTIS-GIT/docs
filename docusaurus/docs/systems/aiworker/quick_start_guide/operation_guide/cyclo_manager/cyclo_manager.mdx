# Cyclo Manager

**Cyclo Manager** is a web-based robot control tool that runs on the **AI Worker Orin**. Its browser UI makes it easy to operate the robot without relying on manual CLI steps for every task.

## Choose a Guide

- [Install](/docs/systems/aiworker/quick_start_guide/operation_guide/cyclo_manager/install): Install the CLI, start the Cyclo Manager stack, and open the web UI.
- [Bringup](/docs/systems/aiworker/quick_start_guide/operation_guide/cyclo_manager/bringup): Bring up the Zenoh daemon, robot stack, and Physical AI server from the System page.
- [Manage Container](/docs/systems/aiworker/quick_start_guide/operation_guide/cyclo_manager/manage_container): Start, stop, and configure containers, edit **`.bashrc`**, and run commands in a terminal.
- [Version Update](/docs/systems/aiworker/quick_start_guide/operation_guide/cyclo_manager/version_update): Update package versions from the Dashboard.
- [noVNC](/docs/systems/aiworker/quick_start_guide/operation_guide/cyclo_manager/novnc): Start the noVNC container and use Dynamixel Wizard 2.0 in the browser.
