# Jog

Use Jog to move the AI Worker mobile base manually from the browser.
Jog is useful for moving the mobile base during mapping, inspection, and setup without keyboard teleoperation or RViz.

![Jog page](/img/systems/aiworker/quick_start_guide/operation_guide/cyclo_manager/jog_page.png)

## Bringup the Robot

Make sure the robot stack is brought up. See [Bringup](/docs/systems/aiworker/quick_start_guide/operation_guide/cyclo_manager/bringup).

If you only need to move the mobile base, bring up the robot with the **Mobile** type to start only the mobile base stack.

![Mobile base bringup](/img/systems/aiworker/quick_start_guide/operation_guide/cyclo_manager/mobile_base_bringup.png)

## Move the Mobile Base

![Jog page description](/img/systems/aiworker/quick_start_guide/operation_guide/cyclo_manager/jog_page_description.png)

1. On the top of right side, you can check the robot bringup status.  
2. Control Button is used to move the mobile base.  
3. Sensitivity Adjustment Button is used to adjust the sensitivity of the mobile base movement.  

:::tip
You can use jog in mobile browsing in your phone after connecting your phone to the AI Worker's WiFi.  
![jog_mobile](/img/systems/aiworker/quick_start_guide/operation_guide/cyclo_manager/jog_mobile.png)
:::
