# Robot PC Access

This guide explains how to connect to the robot's onboard AGX Orin via SSH and access its source code.

<SectionCard>

## Accessing the Robot PC via SSH

Before connecting, make sure your PC and the robot are on the same network. See [Network Connection](/docs/systems/aiworker/quick_start_guide/bringup#1-network-connection).

1. Find the serial number printed on the sticker on the back of the robot body.

   <img src="/img/systems/aiworker/quick_start_guide/setup_overview/software/serial_number.png" alt="Example of a serial number sticker on the robot" style={{width: '401px', maxWidth: '100%'}} />

   The letter identifies the robot model, followed by its individual number.  
   For example:
   - **SG2/BG2:** `A0000`
   - **F2:** `C0000`
   - **F1:** `D0000`

2. On your user PC, open a terminal and connect using the robot's full serial number:

   ```bash
   ssh robotis@ffw-<serial-number>.local
   ```

   For example, if the serial number is `SNPR48A0000`, run:

   ```bash
   ssh robotis@ffw-SNPR48A0000.local
   ```

3. When prompted, enter the system password `root`.

AI Worker supports mDNS, so you can connect using the hostname without manually checking the IP address.

### If the hostname is not available

Connect a monitor to the robot PC via HDMI, log in locally, and check its IP address. Then connect from your user PC:

```bash
ssh robotis@<robot-ip-address>
```

:::info
The system password is initially configured by ROBOTIS. Change it if required by your security policy.
:::
