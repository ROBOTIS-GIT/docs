# Easy Navi

**Easy Navi** (Easy Navigation) is a browser-based tool in Cyclo Intelligence for mapping, autonomous navigation, and map editing on AI Worker. You can create maps, set navigation goals, and fix map artifacts without using RViz or the command line.

## Prerequisites

- AI Worker **2.0.2** or later
- Cyclo Intelligence **1.2.0** or later

:::info
The Map Viewer is built with WebGL and requires a web browser with hardware acceleration enabled.
If the Map Viewer is not displayed correctly in Google Chrome, we recommend accessing Cyclo Intelligence using Mozilla Firefox.
:::

## Getting Started

### 1. Bring Up the AI Worker

Bring up the AI Worker by following the [Bringup Guide](/docs/systems/aiworker/quick_start_guide/operation_guide/cyclo_manager/bringup) or [Teleoperation Guide](/docs/systems/aiworker/quick_start_guide/operation_guide/teleoperation).

### 2. Start Cyclo Intelligence

Start Cyclo Intelligence by following the [Cyclo Intelligence Setup](/docs/systems/aiworker/imitation_learning/setup) guide.

### 3. Open the Navigation Page

From the Cyclo Intelligence sidebar, click **Navi**. The Easy Navi page opens as shown below.

![Cyclo Intelligence Easy Navi page](/img/systems/aiworker/advanced_features/eazy_navi/navi1.png)

## Interface Overview

| Button | Description |
| --- | --- |
| **Idle** | Shows that the navigation system is waiting. The status changes to **Running** while mapping or navigation is active. |
| **Mapping** | Starts the mapping process. |
| **Navigation** | Starts autonomous navigation using an existing map. |
| **Log** | Opens the navigation log window. |
| **Cancel** | Cancels the current navigation goal and stops the robot. |
| **Stop** | Stops the currently active mapping or navigation process. |
| **Save Map** | Saves the current map using the specified map name. |
| **Fix** | Opens map editing mode. |
| **Goal** | Sets a navigation goal. Click and drag on the map to define the target position and orientation. |
| **Initial** | Corrects the robot's estimated position on the map. Click and drag on the map to define the initial position and orientation. |

## Mapping

![Easy Navi mapping mode](/img/systems/aiworker/advanced_features/eazy_navi/navi2.png)

1. Make sure the AI Worker bringup process is running.
2. Click **Mapping** to start creating a map.
3. Move the robot around the environment using one of the following methods:
   - The **Jog** function in [Cyclo Manager](/docs/systems/aiworker/quick_start_guide/operation_guide/cyclo_manager/jog)
   - The default keyboard teleoperation function from the [Teleoperation Guide](/docs/systems/aiworker/quick_start_guide/operation_guide/teleoperation)
4. Continue moving the robot until the required area has been mapped.
5. Enter a map name.
6. Click **Save Map** to save the generated map.

## Navigation

![Easy Navi navigation mode](/img/systems/aiworker/advanced_features/eazy_navi/navi3.png)

The most recently saved map is loaded automatically.

1. Click **Navigation**.
2. Confirm that the costmap is displayed in the Map Viewer.
3. Click **Initial**.
4. Click and drag on the map to set the robot's current position and orientation.
5. Click **Goal**.
6. Click and drag on the map to set the target position and orientation.
7. The AI Worker begins autonomous navigation toward the selected goal.

To stop the robot while it is moving, click **Cancel**.

## Map Editing

![Easy Navi map editing mode](/img/systems/aiworker/advanced_features/eazy_navi/navi4.png)

1. Click **Fix** to open map editing mode.
2. Select the map that you want to edit.
3. Select one of the editing tools:
   - **[-]**: Erases an area from the map.
   - **[+]**: Draws an occupied area on the map.
4. Adjust the numeric value next to the editing tools to change the brush size in pixels.
5. Edit the required areas of the map.
6. Click **Back** to undo the previous editing operation.
7. After completing the modifications, click **Save** to save the edited map.
