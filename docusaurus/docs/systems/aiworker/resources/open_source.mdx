# Open Source

The AI Worker open-source stack combines the robot's ROS 2 software with an end-to-end imitation learning workflow, control packages, and supporting simulation resources maintained by ROBOTIS.

:::tip[Where should I start?]

- To set up and operate the robot, start with [`ai_worker`](https://github.com/ROBOTIS-GIT/ai_worker).
- To record demonstrations, prepare datasets, train policies, and run inference, start with the [Imitation Learning Overview](/docs/systems/aiworker/imitation_learning/overview) and continue with [Cyclo Intelligence](/docs/systems/aiworker/imitation_learning).
- For constraint-aware arm motion, bimanual control, and VR teleoperation, use [Cyclo Control](/docs/systems/aiworker/advanced_features/cyclo_control).
- For Isaac Lab simulation and robot assets, see [`cyclo_lab`](https://github.com/ROBOTIS-GIT/cyclo_lab).

:::
