# Quick Start Guide

Follow these guides in order to check your AI Worker's connection, motion, cameras, and recording when you first receive the robot. Select your model where tabs are provided.

Open each guide in a new tab to keep this list available as you work through the steps.

1. **[Power On, Check Ports, and Use the E-Stop](/docs/systems/aiworker/quick_start_guide/setup_overview/hardware)**

   Check your model's ports, power on the robot, and learn how to use the remote E-Stop.

2. **[Connect to the Robot](/docs/systems/aiworker/quick_start_guide/setup_overview/software)**

   Connect your computer to the robot's network and access the robot PC.

3. **[Open Cyclo Manager](/docs/systems/aiworker/quick_start_guide/operation_guide/cyclo_manager/install)**

   Open the web UI, following the installation steps only if Cyclo Manager has not been set up.

4. **[Start the Robot](/docs/systems/aiworker/quick_start_guide/operation_guide/cyclo_manager/bringup)**

   Start Zenoh and the Follower, then check the robot status and logs.

5. **[Try Teleoperation](/docs/systems/aiworker/quick_start_guide/operation_guide/teleoperation)**

   Connect and wear the Leader, start it, and check basic robot movements using Default Controls. Learn how to pause and stop operation.

6. **[Open Cyclo Intelligence](/docs/systems/aiworker/imitation_learning/setup)**

   Start Cyclo Intelligence and connect it to the robot.

7. **[Check Cameras and Record](/docs/systems/aiworker/imitation_learning/data_recording)**

   Check the live camera views and robot data, then record and save a short demonstration.

8. **[Review the Recording](/docs/systems/aiworker/imitation_learning/data_tools)**

   Use Review Episodes to replay the saved demonstration and check its camera images and joint data.
