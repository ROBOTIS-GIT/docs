# Imitation Learning

AI Sapiens supports imitation learning workflows for turning demonstration data into robot motion.

<img src="/img/systems/aisapiens/ai_sapiens_imitation_learning.webp" alt="AI Sapiens imitation learning workflow" className="ai-sapiens-imitation-image" />

This section covers the path from data collection to motion preparation, policy training, and deployment.
It will also introduce VLA (Vision-Language-Action) workflows, where visual observations and language-level instructions are connected to robot actions.

Guides for each workflow are available in:

- [LeRobot](/docs/systems/aisapiens/imitation_learning/lerobot)
- [Cyclo Intelligence](/docs/systems/aisapiens/imitation_learning/cyclo_intelligence)
