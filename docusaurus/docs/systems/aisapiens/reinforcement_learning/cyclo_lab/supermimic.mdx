# SuperMimic / BlinkMimic

Train, preview, and export a world-model-based motion-tracking policy with Cyclo Lab. Select **SuperMimic** or **BlinkMimic** in the tabs below; the selection is shared across this page.

Follow the [Cyclo Lab setup](./), then run the commands inside the container from `/workspace/cyclo_lab`.

SuperMimic and BlinkMimic train a single policy on multiple reference clips. The examples use **K1 Rev.2, task `001`**, which trains on **Dance1 and Dance2 together**. To use your own motion, see [How to Add Your Own Task](#how-to-add-your-own-task).

| BlinkMimic | `logs/blinkmimic/<task>/<run>/` |

Both Newton and PhysX support `--visualizer kit`, `--visualizer newton_gl`, and `--visualizer viser`. For Viser, open the URL printed in the terminal.

:::note[Playback motions]

By default, play uses the selected task's current motion list.

For example, if a policy was trained on clips 1 and 2, but the task selected for playback contains clips 1, 2, and 3, all three appear in the motion selector. Playback starts with the first clip; select another clip to switch motions.

:::

In the viewer, use the **Motion tracking → Motion** selector to switch clips. The panel also lets you restart the selected motion and toggle reference overlays.

Play also exports `exported/policy.onnx`. Use `params/sim2real.yaml` from the same run. Deployment requires a controller that supports the selected method’s observations.

## How to Add Your Own Task

A task defines a motion library, rather than a separate policy for each clip. This example creates K1 Rev.2 task **`002`** from a collection of walking, turning, and dancing clips, keeping the existing `001` task.

:::note
This guide assumes you already have robot-motion CSV files exported by [Soma-retargeter](/docs/systems/aisapiens/motion_generation_retargeting/soma_retargeter/) or [UMR](/docs/systems/aisapiens/motion_generation_retargeting/umr/). Choose the matching tab below to convert them for training and deployment.
:::

### 1. Place and Convert the Motion Files

Keep the four source clips for the new task in `task_002_motions/`, as shown in the matching tab below.

<Tabs groupId="motion-source">
<TabItem value="soma" label="Soma-retargeter CSV">

Use the headered robot-motion CSV files. Keep the `_soma.csv` suffix to distinguish them from the converted deployment CSV files.

</TabItem>
<TabItem value="umr" label="UMR CSV">

Use the `_umr.csv` exports, not the `_umr_qpos.npz` archives used for UMR playback.

<MotionConversion platform="cyclo-lab" source="umr" motionName="walk_forward_01" folderName="task_002_motions" otherMotions={["walk_forward_02", "turn_left_01", "dance_01"]} />

</TabItem>
</Tabs>

This creates the Cyclo Lab motion files used after this step:

- `walk_forward_01.csv` for Sim2Real deployment
- `walk_forward_01.npz` for training

After conversion, the source CSV (`walk_forward_01_soma.csv` or `walk_forward_01_umr.csv`) is no longer needed for training or Sim2Real deployment and can be removed from this folder.


### 2. Create a new task config.

In the selected method’s directory, copy `task_001.py` to `task_002.py`:

<Tabs groupId="lab-mimic-method">
<TabItem value="supermimic" label="SuperMimic" default>

```bash
cp source/cyclo_lab/cyclo_lab/manager_based/mimic/supermimic/config/k1_rev2/task_001.py \
   source/cyclo_lab/cyclo_lab/manager_based/mimic/supermimic/config/k1_rev2/task_002.py
```

</TabItem>
<TabItem value="blinkmimic" label="BlinkMimic">

```bash
cp source/cyclo_lab/cyclo_lab/manager_based/mimic/blinkmimic/config/k1_rev2/task_001.py \
   source/cyclo_lab/cyclo_lab/manager_based/mimic/blinkmimic/config/k1_rev2/task_002.py
```

</TabItem>
</Tabs>

In `task_002.py`, point `MOTION_PATHS` to the library directory:

```python
MOTION_PATHS = (
    Path(CYCLO_LAB_ASSETS_DATA_DIR) / "motions/K1_rev2/task_002_motions",
)
```

Both methods include every NPZ in this directory and its subdirectories in the same training task. Add more prepared clips to `task_002_motions/` before starting training; no separate task registration is needed for each clip.

To select only part of the collection, use glob patterns instead:

```python
MOTION_PATHS = (
    Path(CYCLO_LAB_ASSETS_DATA_DIR) / "motions/K1_rev2/task_002_motions/walk_*.npz",
    Path(CYCLO_LAB_ASSETS_DATA_DIR) / "motions/K1_rev2/task_002_motions/turn_*.npz",
)
```
