# Reinforcement Learning Overview

AI Sapiens uses reinforcement learning to develop locomotion with DYNAMIXEL-Q actuators, reducing the gap between simulation and real hardware. Training is performed in NVIDIA Isaac Sim™, enabling physics-based simulation and large-scale policy iteration.
