# SuperMimic / BlinkMimic

Train, preview, and export a world-model-based motion-tracking policy with Cyclo MJLab. Select **SuperMimic** or **BlinkMimic** in the tabs below; the selection is shared across this page.

Follow the [Cyclo MJLab setup](./), then run the commands inside the container from `/workspace/cyclo_mjlab`.

SuperMimic and BlinkMimic train a single policy on multiple reference clips. The examples use **K1 Rev.2, task `001`**, which trains on **Dance1 and Dance2 together**. To use your own motion, see [How to Add Your Own Task](#how-to-add-your-own-task).

## Train

<Tabs groupId="mjlab-mimic-method">
<TabItem value="supermimic" label="SuperMimic" default>

```bash
python scripts/reinforcement_learning/train.py \
  Cyclo-SuperMimic-GenCoord-K1-Rev2-001 \
  --num-envs 4096
```

</TabItem>
<TabItem value="blinkmimic" label="BlinkMimic">

```bash
python scripts/reinforcement_learning/train.py \
  Cyclo-BlinkMimic-K1-Rev2-001 \
  --num-envs 4096
```

</TabItem>
</Tabs>

SuperMimic also supports `MaxCoord` in place of `GenCoord`.

## How to Add Your Own Task

A task defines a motion library, rather than a separate policy for each clip. This example creates K1 Rev.2 task **`002`** from a collection of walking, turning, and dancing clips, keeping the existing `001` task.

### 1. Place the Motion Files

First, follow [Prepare Motion](../motion_preparation) to generate the training NPZ and deployment CSV files for Cyclo MJLab and K1 Rev.2. Then place the prepared files in a dedicated `task_002_motions/` directory as shown below.

<div className="docs-folder-tree" role="img" aria-label="K1 Rev.2 prepared motion library directory structure">
  <div className="docs-folder-tree__root">
    <code>source/assets/motions/K1_rev2/</code>
  </div>
  <ul>
    <li><span className="docs-folder-tree__folder">dance1/</span></li>
    <li><span className="docs-folder-tree__folder">dance2/</span></li>
    <li>
      <strong>task_002_motions/</strong>
      <ul>
        <li><code>walk_forward_01.npz</code></li>
        <li><code>walk_forward_01.csv</code></li>
        <li><code>walk_forward_02.npz</code></li>
        <li><code>walk_forward_02.csv</code></li>
        <li><code>turn_left_01.npz</code></li>
        <li><code>turn_left_01.csv</code></li>
        <li><code>dance_01.npz</code></li>
        <li><code>dance_01.csv</code></li>
        <li><code>…</code></li>
      </ul>
    </li>
  </ul>
</div>

Each clip uses a matching pair of files:

| File | Purpose |
| --- | --- |
| `.npz` | 50 Hz motion reference in Cyclo MJLab format for training and playback |
| `.csv` | Corresponding motion in the deployment format |

Training loads the NPZ files; the CSV files are kept for deployment. Raw retargeter outputs must first be converted to these formats.

Preview the prepared clips before training to check their poses, speed, and loop transitions:

```bash
python scripts/tools/motion/replay_npz.py \
  --model third_party/ai_sapiens/ai_sapiens_description/mujoco/k1_rev2/k1.xml \
  -f source/assets/motions/K1_rev2/task_002_motions/walk_forward_01.npz \
  --loop
```

### 2. Create a new task config.

In the selected method’s directory, copy `task_001.py` to `task_002.py`:

<Tabs groupId="mjlab-mimic-method">
<TabItem value="supermimic" label="SuperMimic" default>

```bash
cp source/tasks/supermimic/config/k1_rev2/task_001.py \
   source/tasks/supermimic/config/k1_rev2/task_002.py
```

</TabItem>
<TabItem value="blinkmimic" label="BlinkMimic">

```bash
cp source/tasks/blinkmimic/config/k1_rev2/task_001.py \
   source/tasks/blinkmimic/config/k1_rev2/task_002.py
```

</TabItem>
</Tabs>

In `task_002.py`, point `MOTION_PATHS` to the library directory:

```python
MOTION_PATHS = (
    SRC_PATH / "assets/motions/K1_rev2/task_002_motions",
)
```

Both methods include every NPZ in this directory and its subdirectories in the same training task. Add more prepared clips to `task_002_motions/` before starting training; no separate task registration is needed for each clip.

To select only part of the collection, use glob patterns instead:

```python
MOTION_PATHS = (
    SRC_PATH / "assets/motions/K1_rev2/task_002_motions/walk_*.npz",
    SRC_PATH / "assets/motions/K1_rev2/task_002_motions/turn_*.npz",
)
```

### 3. Register the Task

Edit the highlighted `__init__.py` in the selected method’s directory. Import `task_002` and add the new task to `TASKS`, keeping the existing entries:

<Tabs groupId="mjlab-mimic-method">
<TabItem value="supermimic" label="SuperMimic" default>

<div className="docs-folder-tree" role="img" aria-label="SuperMimic task registration file structure">
  <div className="docs-folder-tree__root">
    <code>source/tasks/supermimic/config/</code>
  </div>
  <ul>
    <li>
      <strong>k1_rev2/</strong>
      <ul>
        <li><code><strong className="docs-folder-tree__file">&lowbar;&lowbar;init&lowbar;&lowbar;.py</strong></code></li>
        <li><code>task_001.py</code></li>
        <li><code>task_002.py</code><em>copied from task_001.py</em></li>
      </ul>
    </li>
  </ul>
</div>

File: `source/tasks/supermimic/config/k1_rev2/__init__.py`

```python
from . import task_001
from . import task_002  # Add task 002

TASKS = {
    "Cyclo-SuperMimic-GenCoord-K1-Rev2-001": ("gencoord", task_001.make_env_cfg),
    "Cyclo-SuperMimic-MaxCoord-K1-Rev2-001": ("maxcoord", task_001.make_env_cfg),

    # Add task 002
    "Cyclo-SuperMimic-GenCoord-K1-Rev2-002": ("gencoord", task_002.make_env_cfg),
    "Cyclo-SuperMimic-MaxCoord-K1-Rev2-002": ("maxcoord", task_002.make_env_cfg),
}
```

</TabItem>

    "Cyclo-BlinkMimic-K1-Rev2-002": task_002.make_task_cfg(),

Check that the new tasks are registered:

```bash
python scripts/list_envs.py --keyword K1-Rev2-002
```

Check that the registered task IDs appear:

- **SuperMimic**

### 4. Run the New Task

Use the registered task ID with the Train and Play commands above.
