# Open Source

AI Sapiens is designed as an open platform. This page lists the public repositories used to inspect, modify, simulate, and build applications for the robot.

:::tip[Where should I start?]

- For the K1 ROS 2 software stack, start with [`ai_sapiens`](https://github.com/ROBOTIS-GIT/ai_sapiens).
- To train or test policies in simulation, start with [`cyclo_lab`](https://github.com/ROBOTIS-GIT/cyclo_lab).

:::

## Motion Generation and Retargeting

These ROBOTIS repositories provide K1-specific integration for the AI Sapiens motion workflow.

| Category | Repository | AI Sapiens role |
|:---------|:-----------|:----------------|
| <span className="badge badge--secondary repository-category-badge">Video-to-motion generation</span> | <span className="repository-with-origin"><GitHubRepositoryLink href="https://github.com/ROBOTIS-GIT/GEM-X">ROBOTIS-GIT/GEM-X</GitHubRepositoryLink><span className="repository-fork-origin">Forked from <code>NVlabs/GEM-X</code></span></span> | Recovers SOMA-format human motion from monocular video and adds the `ai_sapiens_k1` retargeting path |
| <span className="badge badge--secondary repository-category-badge">Motion retargeting</span> | <span className="repository-with-origin"><GitHubRepositoryLink href="https://github.com/ROBOTIS-GIT/soma-retargeter">ROBOTIS-GIT/soma-retargeter</GitHubRepositoryLink><span className="repository-fork-origin">Forked from <code>NVIDIA/soma-retargeter</code></span></span> | Converts SOMA/BVH motion to K1 joint trajectories using the AI Sapiens robot description and mesh assets |
| <span className="badge badge--secondary repository-category-badge">Text-to-motion generation</span> | <span className="repository-with-origin"><GitHubRepositoryLink href="https://github.com/ROBOTIS-GIT/kimodo">ROBOTIS-GIT/kimodo</GitHubRepositoryLink><span className="repository-fork-origin">Forked from <code>nv-tlabs/kimodo</code></span></span> | Generates source motion from text and kinematic constraints for conversion or retargeting in the K1 motion workflow |

See [GEM-X](/docs/systems/aisapiens/motion_generation/gem-x), [Soma-retargeter](/docs/systems/aisapiens/motion_generation_retargeting/soma_retargeter/), and [Kimodo](/docs/systems/aisapiens/motion_generation_retargeting/kimodo/) for installation and AI Sapiens workflow details.
