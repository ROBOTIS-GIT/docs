# MuJoCo Sim2Sim

MuJoCo Sim2Sim lets you run the K1 deployment software with a simulated K1 instead of the
physical robot. The software responsible for Damping, ReadyPose, Locomotion, Mimic, and safety
checks remains unchanged. The same [Sim2Real](/docs/systems/aisapiens/development_guide/sim2real)
software can control either a physical or simulated K1.

Only the hardware interface changes. On the physical robot, it exchanges commands and feedback
with the K1 motors and sensors. In MuJoCo, `mujoco_hardware_interface` exchanges the same
commands and feedback with the K1 model.

Everything above the orange line is the same software. With the physical K1,
`dynamixel_hardware_interface` sends commands to the actuators and reads the robot sensors. With
the simulated K1, `mujoco_hardware_interface` sends the same commands to MuJoCo and returns
simulated joint and IMU states. The shared software above the hardware interface does not need to
know whether it is controlling the physical or simulated K1.

The simulator includes a gantry that can attach, release, raise, and lower the robot. This makes
it possible to test the same deployment sequence used with the physical K1, including locomotion
and mimic motions.

## Set up

Clone the repository and start its development container:

```bash
git clone https://github.com/ROBOTIS-GIT/ai_sapiens.git
cd ai_sapiens
./docker/container.sh start
./docker/container.sh enter
```

Inside the container, install `tmux` if needed and move to the workspace source directory:

```bash
apt update && apt install -y tmux
cd ~/ros2_ws/src/ai_sapiens
```

The `tmux` installation is only required if it is not already available in the container.

## Run the simulator

Choose one input method:

```bash
./run_k1_tmux.sh --sim --radiomaster-usb  # K1 RadioMaster transmitter
./run_k1_tmux.sh --sim --keyboard         # PC keyboard
./run_k1_tmux.sh --sim --dualsense        # PlayStation DualSense
```

The joystick-based modes use `/dev/input/js0` by default. To select another device,
append an option such as `--device=/dev/input/js1`.

:::note[RadioMaster USB connection]

Turn on the RadioMaster Pocket, then connect its upper USB-C data port to the PC.
When EdgeTX opens the USB mode menu, select **USB Joystick (HID)** and press the
**Menu Wheel / ENTER** inward to confirm.

## Test the deployment flow

Use the same mode sequence as on the physical robot:

1. Change from **Damping** to **ReadyPose**.
2. Lower the gantry until both feet touch the ground.
3. Start **Locomotion**, then release the robot from the gantry.
4. Run the required **Mimic** motions while locomotion is active.
5. Attach the robot to the gantry again.
6. Return from **ReadyPose** to **Damping**.

Use the **Gantry** panel in the MuJoCo viewer to raise, lower, attach, or release the robot.
With the viewer focused, the arrow keys raise and lower the gantry, while `A` and `R`
attach and release it.
When keyboard teleoperation is selected, its terminal pane displays the available controls
and the current mode and mimic selection.
