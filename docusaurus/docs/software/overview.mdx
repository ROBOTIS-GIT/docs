Tools and SDKs for configuring, controlling, and developing with DYNAMIXEL actuators.

<div className="software-overview-subsection">

### DYNAMIXEL Wizard 2.0

[DYNAMIXEL Wizard 2.0](/docs/software/dynamixel_wizard_2_0/introduction) is an optimized tool for managing DYNAMIXEL's from various operating systems.

The following features are provided with DYNAMIXEL Wizard 2.0.

- DYNAMIXEL Firmware Update
- DYNAMIXEL Diagnosis
- DYNAMIXEL Configuration and Test
- DYNAMIXEL Data Plotting in Real-Time
- Generate & Monitor DYNAMIXEL Packets

</div>

<div className="software-overview-subsection">

### DYNAMIXEL SDK

[DYNAMIXEL SDK](/docs/software/dynamixel_sdk) is a software development kit that provides DYNAMIXEL control functions using packet communication.

The API of DYNAMIXEL SDK is designed for DYNAMIXEL actuators and DYNAMIXEL-based platforms.

You need to be familiar with C/C++ programming language for right use of the software.

</div>

<div className="software-overview-subsection">

### DYNAMIXEL Easy SDK

[DYNAMIXEL Easy SDK](/docs/software/dynamixel_easy_sdk) wraps the DYNAMIXEL SDK in a motor-object-oriented design for easier first-time use.

</div>

<div className="software-overview-subsection">

### DYNAMIXEL Workbench

[DYNAMIXEL Workbench](/docs/software/dynamixel_workbench) is library which provides simple and easy APIs to use DYNAMIXEL.

</div>

## RoboPlus (R+)

RoboPlus (R+) software is designed to help you begin creating and programming with ROBOTIS kits straight out of the box.

#### R+ Manager 2.0

[R+ Manager 2.0](/docs/software/rplus_manager_2_0) is a firmware management tool to test and update sensors, motors, controllers and servos.

#### R+ Task 2.0

R+ Task 2.0 is a task editor to create instructions in a simplified C-Language that can be downloaded to our exclusive controller such as CM-550.

#### R+ Motion 2.0

R+ Motion 2.0 is a motion editor to easily create complex robot poses which can be linked together to create full movement routines. Once downloaded to the ROBOTIS controller, motion files can be played back from R+ Motion 2.0 or inserted into code made in R+ Task 2.0.

#### R+ Design 2.0

R+ Design 2.0 can be used as an interactive guide for step-by-step robot assembly. The optional "Creator Mode" allows users to prototype and develop their own structures based on ROBOTIS components.

#### R+ Mobile Apps

<ul className="software-overview-links">
  <li>R+ m.Task 2.0 <em>(legacy e-Manual)</em></li>
  <li>R+ m.Motion 2.0 <em>(legacy e-Manual)</em></li>
  <li>R+ m.Design <em>(legacy e-Manual)</em></li>
  <li>R+ Block <em>(legacy e-Manual)</em></li>
</ul>

R+ Block allows to select ROBOTIS controllers to connect to Scratch 2.0 Offline Editor and program robots in the Scratch block-programming language.
