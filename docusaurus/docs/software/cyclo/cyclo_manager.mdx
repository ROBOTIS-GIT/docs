**Cyclo Manager** is a web-based operation and maintenance tool for **AI Worker, OMY, and OMX**. It runs on the robot computer and provides a browser interface for daily robot operation, monitoring, and software maintenance.

## Main Features

- Bring up the robot stack and related services.
- Start, stop, restart, and inspect Docker containers.
- Monitor robot status, storage usage, and software versions.
- Update robot software packages and container images.
- Access container terminals and GUI tools through the browser, including noVNC.

Available features and setup depend on the robot. Follow the system-specific guide for installation, configuration, and operating precautions.
