# Cyclo Manager

Cyclo Manager is a browser-based interface for operating and maintaining supported robots.

<SectionCard>

## Introduction

<span id="system-guides" />
<span id="ai-worker-operation-guide" />

Cyclo Manager provides access to robot services, control tools, and system management from a web browser. Available controls depend on the connected robot and installed software.

</SectionCard>

<SectionCard>

## Main Features

<span id="what-you-can-do" />

- Start and monitor robot and leader services.
- Move supported joints and mobile bases with Jog.
- Record and play back trajectory commands.
- Inspect ROS 2 topics, containers, logs, and system status.
- Access a container terminal, remote desktop, and host files.

</SectionCard>

<SectionCard>

## How It Works

<span id="how-it-runs" />
<span id="software-architecture" />

Open Cyclo Manager from a browser connected to the Robot PC. The web UI communicates with the Cyclo Manager service on that PC. The service manages containers and communicates with host and container agents to control supported robot services.

</SectionCard>
