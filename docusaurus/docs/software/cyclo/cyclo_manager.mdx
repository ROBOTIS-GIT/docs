**Cyclo Manager** is a web-based operation and maintenance tool for **AI Worker, OMY, and OMX**. It runs on the robot computer and provides a browser interface for daily robot operation, monitoring, and software maintenance.

## Main Features

- Bring up the robot stack and related services.
- Start, stop, restart, and inspect Docker containers.
- Monitor robot status, storage usage, and software versions.
- Update robot software packages and container images.
- Access container terminals and GUI tools through the browser, including noVNC.

Available features and setup depend on the robot. Follow the system-specific guide for installation, configuration, and operating precautions.

## What You Can Do

Use Cyclo Manager to:

- Bring up the AI Worker robot stack and related services from the browser.
- Start, stop, restart, and inspect Docker containers running on the robot.
- Monitor robot status, Docker status, storage usage, and version status.
- Open a browser-based terminal into docker containers.
- Use noVNC to run GUI tools such as **Dynamixel Wizard 2.0** without connecting a monitor.
- Jog the mobile base from a PC or phone browser.

## How It Runs

Cyclo Manager is composed of a Python CLI, a web UI, an API server, and small agents that run inside managed containers.

- The **`cyclo-manager`** Python package provides the **`cyclo_manager`** CLI.
- The CLI creates the Docker Compose stack and registers the host-side agent.
- The **Web UI** provides browser pages for operation and monitoring.
- The **API Server** receives UI requests, controls Docker, communicates with container agents, and exposes log streams.
- The **s6 agent** inside each robot container starts and stops ROS 2 services and reports service status.
- The **host agent** handles host-level operations such as repository update workflows.

## Software Architecture

![Cyclo Manager Software Architecture](/img/systems/aiworker/quick_start_guide/operation_guide/cyclo_manager/sw_architecture.svg)

At a high level, Cyclo Manager separates user-facing controls from the robot runtime:

- **User layer**: A browser is used to operate the robot and CLI is used to install the Cyclo Manager stack.
- **Manager layer**: The Web UI and API Server provide the control surface.
- **Robot container layer**: Robot bringup services run inside containers managed by s6.
- **Host layer**: Docker, storage, serial devices, and git repositories remain on the robot host.

This layout keeps normal operation in the browser while preserving access to the underlying Docker and ROS 2 system when deeper debugging is needed.
