**Cyclo Flow** is the **Orchestrate** module in the CYCLO software layer. Its architectural role is to coordinate robot actions into workflows.

## Related System Guides

The existing AI Worker **Autonomy Studio** guides describe task and mission orchestration using reusable Steps, navigation, and learned actions:

- [Overview: Tasks, Missions, and prerequisites](/docs/systems/aiworker/autonomy_studio/overview)
- [Action Canvas: arrange Steps for tasks at one work location](/docs/systems/aiworker/autonomy_studio/action_canvas)
- [Navigation: prepare maps and robot movement](/docs/systems/aiworker/autonomy_studio/mission_canvas/navigation)
- [Mission: coordinate waypoint Tasks](/docs/systems/aiworker/autonomy_studio/mission_canvas/mission)

These are the currently documented orchestration workflows; a dedicated Cyclo Flow usage guide is not yet available. Check the Autonomy Studio overview for supported robot configurations.
