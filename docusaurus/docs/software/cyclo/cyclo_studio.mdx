---
title: Cyclo Studio
description: Simulate and train Cyclo Ready Robots to create actions and deploy them to physical robots.
---

**Cyclo Studio** is a platform for simulating and training **Cyclo Ready Robots**, creating **actions**, and deploying those actions to physical robots.

The workflow connects simulation and learning with real-world operation: simulate a Cyclo Ready Robot, train it to create actions, then deploy those actions to the physical robot.

:::info[Under Development]
Cyclo Studio is currently under development. Detailed information and usage guides will be added in a future update.
:::
