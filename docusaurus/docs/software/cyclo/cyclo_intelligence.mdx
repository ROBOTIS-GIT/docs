**Cyclo Intelligence** is the **Learn** module in the CYCLO software layer. It connects demonstration recording, dataset preparation, policy training, and model inference through Cyclo Data and Cyclo Brain.

## Legacy: Physical AI Tools

The previous Physical AI Tools workflow is retained for existing AI Worker installations and is no longer updated. New workflows should use Cyclo Intelligence.

[Open the legacy AI Worker guide](/docs/software/cyclo/intelligence/legacy/physical_ai_tools/imitation_learning).

W1/W2 recording and inference use Cyclo Intelligence; the legacy workflow does not include those model configurations.
