**CYCLO** is ROBOTIS's **Physical AI ecosystem**, connecting the creation and sharing of robot capabilities with learning, simulation, control, applications, and operation on DYNAMIXEL-based hardware.

The architecture is organized into three layers:

- **Platform:** Cyclo Studio simulates and trains Cyclo Ready Robots to create actions and deploy them to physical robots. Cyclo Marketplace lets users share and sell datasets, actions, and AI models.
- **Software:** Intelligence, Lab, Control, App, and Flow cover learning, simulation, motion control, applications, and orchestration. Cyclo Manager provides web-based robot operation and maintenance. Under these modules, OS provides the common foundation for DYNAMIXEL management, service management, real-time control, health, and safety.
- **Hardware:** DYNAMIXEL actuators power AI Sapiens, AI Worker, OMY, OMX, ROBOTIS Hand, and custom DYNAMIXEL-based robots.

Together, these layers connect robot development with operation: create a workflow, develop learned or simulated behaviors, combine them with motion control and application logic, and run them on the robot. Module availability and setup depend on the robot; the module pages below link to the existing system-specific guides.

CYCLO follows ROBOTIS's open-source philosophy, making software building blocks available for developers to learn from, integrate, and extend.

| Platform | [Cyclo Marketplace](/docs/software/cyclo/cyclo_marketplace) | Share and sell datasets, actions, and AI models. |
| Software | [Cyclo AI](/docs/software/cyclo/cyclo_ai) | Develop software for DYNAMIXEL actuators and ROBOTIS robots with Codex and Claude Code. |
| Software | [Cyclo Intelligence](/docs/software/cyclo/cyclo_intelligence) | Learn through demonstration recording, policy training, and inference. |
| Software | [Cyclo Lab](/docs/software/cyclo/cyclo_lab) | Simulate robots and develop reinforcement learning policies. |
| Software | [Cyclo Control](/docs/software/cyclo/cyclo_control) | Generate and execute robot motion. |
| Software | [Cyclo App](/docs/software/cyclo/cyclo_app) | Provide robot applications. |
| Software | [Cyclo Manager](/docs/software/cyclo/cyclo_manager) | Operate and monitor robots through a web UI, including bringup, container management, and software updates. |
| Software | [Cyclo Flow](/docs/software/cyclo/cyclo_flow) | Orchestrate robot actions and workflows. |
| Software | [Cyclo OS](/docs/software/cyclo/cyclo_os) | Manage DYNAMIXEL devices, services, real-time control, health, and safety. |
