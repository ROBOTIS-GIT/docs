**CYCLO** is the **Physical AI software platform** for building and operating intelligent robotic systems.

It follows ROBOTIS's open-source philosophy: put the building blocks in the open so Physical AI is easier for anyone to learn, integrate, and run on real hardware — not a closed, single-vendor path. It covers AI integration, action-data workflows, robot control, simulation, and operations. Private infrastructure (supervision, proprietary data, and similar) can plug in alongside the open public stack.

At its core, CYCLO drives ROBOTIS's Physical AI lineup — AI Sapiens, AI Worker, OMY, OMX, and ROBOTIS Hand — through a common layer built around Dynamixel actuator control.

CYCLO's capabilities will continue to expand to support a broader range of Physical AI workflows and robotic systems.

## Modules

| Module | Role | GitHub |
| --- | --- | --- |
| **Cyclo** | Meta-package composing Physical AI software on ROBOTIS hardware | [cyclo](https://github.com/ROBOTIS-GIT/cyclo) |
| **Cyclo Intelligence** | Next-generation imitation learning workflows for training, evaluating, and deploying Physical AI skills | [cyclo_intelligence](https://github.com/ROBOTIS-GIT/cyclo_intelligence) |
| **Cyclo Control** | ROS 2-native motion control for Physical AI robots, enabling smooth, safe, and precise manipulation | [cyclo_control](https://github.com/ROBOTIS-GIT/cyclo_control) |
| **Cyclo Lab** | Reinforcement learning, environment setup, and validation workflows for developing Physical AI robots | [cyclo_lab](https://github.com/ROBOTIS-GIT/cyclo_lab) |
| **Cyclo Manager** | Operation, monitoring, and session tooling for real robots | [cyclo_manager](https://github.com/ROBOTIS-GIT/cyclo_manager) |
| **Cyclo Supervisor** (Private) | Manages data acquisition tasks for the action data factory | — |
| **Cyclo Hub** (Private) | Manages the internal action dataset repository | — |
