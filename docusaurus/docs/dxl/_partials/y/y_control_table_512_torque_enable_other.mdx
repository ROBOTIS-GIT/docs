Controls Torque ON/OFF state. Setting the value to '1' enables Torque state and prevents writing data in the EEPROM area. If Torque cannot be enabled, the Result Fail bit in the returned status packet will be set to '1'.

| Value | Description |
|:-----:| :---------  |
| 0     | Torque OFF  |
| 1     | Torque ON   |

:::note

**NOTE**: If the value of [Hybrid Save(170)] is `0`, changes will not be saved when the device is rebooted or the power is cut.

:::

:::note

**NOTE**: When the value of [Controller State(152)] is Process Torque On(4) or Process Torque Off(6), writing to Torque Enable(512), [Goal PWM(524)], [Goal Current(526)], [Goal Velocity(528)], [Goal Position(532)] will return `Result Fail`.

:::
