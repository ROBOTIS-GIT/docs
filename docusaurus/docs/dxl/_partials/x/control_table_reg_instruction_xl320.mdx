Indicates whether the Write Instruction is registered by [Reg Write Instruction](/docs/dxl/protocol/protocol2#reg-write-0x04)

| Value | Description                                  |
|:-----:|:---------------------------------------------|
|   0   | No instruction registered by REG_WRITE.      |
|   1   | Instruction registered by REG_WRITE exists. |


:::note

**NOTE** : If ACTION instruction is executed, the Registered Instruction (47) will be changed to 0.

:::
