:::tip

The DYNAMIXEL **2XC430-W250** is a ground breaking DYNAMIXEL featuring **2 integrated movement axes** within a single module. Each axis has it's own dedicated Control Table allowing the **2XC430-W250** to control them as if they were two independent DYNAMIXEL servos.

:::
