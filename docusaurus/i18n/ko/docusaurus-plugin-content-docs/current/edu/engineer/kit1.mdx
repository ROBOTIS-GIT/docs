# 개요
![](/img/edu/engineer/kit1/enginner_main.webp)

**ROBOTIS ENGINEER**는 스마트 기기를 활용한 AI 기술이 적용된 차세대 로봇입니다.

- 다양한 수준의 로봇 교육 과정에 활용할 수 있는 표준 커리큘럼을 제공합니다.
- 관절형 구조로 다양한 로봇 동작을 구현할 수 있습니다.
- 3D 부품 설계와 출력 과정을 지원합니다.
- 기본 키트로 3종의 로봇(MAX, SPI, DR. R)을 조립할 수 있으며, 워크북을 활용하면 총 7종의 로봇을 만들 수 있습니다.
- R+ ENGINEER(스마트 기기 앱), R+ Task 3.0(PC 소프트웨어)과 호환됩니다.
- Raspberry Pi와 Camera를 확장할 수 있습니다.

#### CM-550 각 부 명칭
![](/img/common/cm550_1.webp)

![](/img/common/cm550_2.webp)

- `USB` Micro USB Port : 5핀 micro USB 케이블로 PC의 USB 포트와 연결할 수 있습니다.
- `UART` Communication Port : BT-210, BT-410, LN-101, IR receiver 또는 기타 통신 모듈을 연결할 수 있습니다.
- `BAT` Battery Socket : 제공된 Li-Po 배터리를 연결합니다.
- `12VDC` DC Input : 제공된 SMPS의 DC barrel jack을 연결합니다.
- `POWER` Power Switch : 제어기의 전원을 켜거나 끕니다.
- Status LED : 전압 상태와 무선 장치 연결 상태를 RGB LED로 표시합니다.
- `MODE` MODE LED : CM-550의 동작 모드를 표시하는 RGB LED입니다. CM-550의 [Operating Mode]를 참고하세요.
- `START` START LED : CM-550의 [Operating Mode]를 참고하세요.
- `MODE` MODE Button : 이 버튼으로 동작 모드를 변경할 수 있습니다. CM-550의 [Operating Mode]를 참고하세요.
- `START` START Button : 선택한 동작 모드를 실행합니다. CM-550의 [Operating Mode]를 참고하세요.
- `DXL` DYNAMIXEL-X Series Port : DYNAMIXEL-X series를 연결할 수 있는 포트입니다.
- `PORT` ROBOTIS 5 Pin Port : DMS, Touch sensor, IR sensor 등의 센서를 연결할 수 있습니다.
  Servo motor, IR array sensor, Temperature & Humidity sensor는 Port 1 또는 2에만 연결할 수 있습니다.
- `MIC` Internal Microphone : 내장 마이크로 박수 소리를 감지합니다.
- `FUSE` Fuse : 10A fuse가 전기적 손상으로부터 보호합니다.


:::warning

**주의** : CM-550의 USB 포트는 PC와 연결하도록 설계되어 있습니다. 다른 USB 장치를 연결하지 마세요. 제어기가 손상될 수 있습니다.

:::

### 2XL430-W250 DYNAMIXEL
![](/img/edu/engineer/2xl430_intro.webp)

**2XL430-W250**은 하나의 module로 **2축(2 DOF)**을 제어할 수 있는 DYNAMIXEL입니다. 2축을 동시에 제어하기 위해 각 축에는 서로 다른 ID가 부여되며 동일한 Baudrate를 공유합니다. Baudrate를 제외하면 각 축의 Control Table이 분리되어 있어 2XL은 다양한 애플리케이션에 활용할 수 있습니다.

사용 방법은 다른 DYNAMIXEL과 동일하지만, Firmware Recovery를 수행하면 두 축이 모두 공장 출하 상태로 초기화된다는 점에 유의하세요.

## 주의사항
### 안전 주의사항

:::danger

![](/img/common/icon_warning.webp)
1. 시작하기 전에 이 매뉴얼을 충분히 읽어 주세요.
2. 키트에 제공된 공구만 사용하세요.
3. 로봇이 동작 중일 때 얼굴과 몸에서 멀리 떨어뜨리세요.
4. 손가락이나 신체 일부가 로봇 관절에 끼이지 않도록 주의하세요.
5. 직사광선 아래에서 로봇을 동작하거나 보관하지 마세요.
6. 물이나 열원 근처에서 로봇을 동작하거나 보관하지 마세요.
7. 부품을 임의로 개조하거나 분해하지 마세요.
8. 로봇과 부품을 영유아나 어린이의 손이 닿지 않는 곳에 보관하세요.
9. 로봇에 충격을 주거나 날카로운 물체로 찌르지 마세요.

:::


### 사용 시 주의사항

:::warning

1. 나사를 조일 때는 키트에 제공된 드라이버(PH 1)를 사용하세요.
2. 조립 시 나사와 부품에 과도한 힘을 가하지 마세요.
3. 낙하로 인한 파손을 방지하기 위해 로봇은 바닥에서 동작시키세요.
4. 낙하로 인한 우발적 손상은 보증 대상에 포함되지 않습니다.
5. DYNAMIXEL 내부 기어와 로봇 관절은 소모품입니다. 과도하게 사용하거나 장기간 사용하면 backlash가 발생할 수 있습니다.
6. 빠른 동작(예: 전투 동작)을 수행할 때 로봇은 순간적으로 많은 전류를 소모하므로 전원 공급이 부족하면 예기치 않게 전원이 꺼질 수 있습니다. 이 경우 높은 전류(A)를 공급할 수 있는 배터리 또는 SMPS를 사용하세요.

:::


### 배터리 주의사항

:::danger

![](/img/common/icon_warning.webp)
1. 사용하지 않을 때는 배터리를 로봇에서 분리하고, 반드시 지정된 충전기로 충전하세요.
2. 배터리나 충전기를 분해하거나 충격을 가하지 마세요.
3. 배터리에 열을 가하지 말고 불이나 액체에 닿지 않게 하세요.
4. 배터리를 전자레인지, 세탁기, 냉장고 또는 건조기에 넣지 마세요.
5. 손상된 배터리(변형, 부풀어 오름, 외관 손상 등)는 사용하지 마세요.
6. 배터리를 단락시키지 마세요.
7. 충전 시 배터리 극성을 반대로 연결하지 마세요.
8. 배터리가 뜨거운 상태에서는 충전하지 마세요. 배터리를 상온으로 식힌 뒤 충전하세요.
9. 고온 다습한 장소에 보관하지 마세요.
10. 충전기로 여러 배터리를 동시에 충전하지 마세요.
11. 충전기에 전원이 연결되지 않은 상태에서 배터리를 충전기에 연결하지 마세요.

:::

### DYNAMIXEL 조립 확인

1.  main screen에서 로봇 예제를 실행하고 option menu에서 `MOTOR`를 선택합니다.
  ![](/img/edu/engineer/engineer_app_motor.webp)

2. 화면에서 joint ID를 선택합니다. 선택한 joint의 LED가 켜지고 살짝 움직이는지 확인합니다.
  ![](/img/edu/engineer/engineer_app_motor_2.webp)


### DYNAMIXEL Offset
이 기능은 ROBOTIS ENGINEERING KIT에 사용되는 DYNAMIXEL의 offset 값을 보정하여 로봇 자세를 조정할 때 사용합니다. 설정한 offset 값은 각 DYNAMIXEL에 저장됩니다.
잘못 설정하면 motion이 불안정해지거나 hardware가 손상될 수 있으므로 충분히 이해한 후 offset을 조정하세요.

1. main screen에서 로봇 예제를 실행하고 option menu에서 `OFFSET`을 선택합니다.
  ![](/img/edu/engineer/engineer_app_motor_offset.webp)

2.  화면에서 offset을 조정할 joint ID를 선택하면 조정 menu가 나타납니다.
  ![](/img/edu/engineer/engineer_app_motor_offset_2.webp)

    - `+ / -` : offset 값을 증가/감소합니다.
    - `Torque On / Off` : 선택한 joint의 torque를 켜거나 끕니다.
    - `OK / CANCEL` : offset 값 변경을 저장하거나 취소합니다.

3. offset 값을 저장하려면 `OK`를 선택합니다. 확인 message가 나타납니다.
  다시 `OK`를 선택하면 offset 값이 로봇에 저장됩니다.
  ![](/img/edu/engineer/engineer_app_motor_offset_3.webp)

4. 아래 button으로 각 joint의 offset 값을 reset하거나 다시 불러올 수 있습니다.
  ![](/img/edu/engineer/engineer_app_motor_offset_4.webp)

    - `Reset Offset` : 선택하면 확인 창이 나타납니다. [OK]를 선택하면 모든 joint의 offset 값이 reset됩니다.
    - `Initial Pose` : 저장된 offset 값을 다시 불러옵니다. offset이 잘못 설정된 경우 이 button으로 복구할 수 있습니다.

# 참고자료
## BLE Signal 설정
CM-550의 BLE slave module 신호 세기가 약하거나 간섭이 있으면 Bluetooth 통신이 불안정할 수 있습니다.
이 경우 R+ Manager 2.0에서 BLE signal strength를 조정할 수 있습니다.

상황에 따라 CM-550 BLE signal strength를 조정하는 방법은 아래를 참고하세요.


:::note

|   내 CM-550   | 다른 CM-550   | BLE Signal Strength |
|:-------------:|:-------------:|:-------------------:|
| 연결 불안정   | 연결 안정     |      Increase       |
| 연결 불안정   | 연결 불안정   |      Increase       |
| 연결 안정     | 연결 불안정   |      Decrease       |
| 연결 안정     | 연결 안정     |      No Change      |

- 실내에서 CM-550 제어기 1대를 사용할 때 통신이 불안정하다면 signal strength가 약한 것일 수 있습니다. **BLE signal strength를 높이세요**.
- 실내에서 여러 대의 CM-550 제어기를 사용할 때 통신이 불안정하다면 BLE signal이 서로 간섭할 수 있습니다. **불안정한 CM-550의 BLE signal strength를 높이거나, 안정적인 다른 CM-550의 BLE signal strength를 낮추세요**.
- 실내의 모든 CM-550이 안정적이라면 **BLE signal strength를 유지하세요**.

:::


:::note

**참고** : BLE signal strength와 noise는 주변 환경과 기기 수에 따라 달라질 수 있습니다.

:::


1. CM-550 BLE와 페어링된 BT-410 master 또는 BT-410 Dongle의 전원을 끕니다.
  (CM-550 BLE가 페어링된 장치와 연결된 상태에서는 BLE signal strength를 설정할 수 없습니다)

2. PC와 CM-550을 USB 케이블로 연결합니다. 전원 스위치가 꺼져 있어도 5V USB 전원으로 제어기가 자동으로 켜집니다.
3. CM-550의 `MODE` 버튼이 1초마다 깜박일 때까지 기다립니다.
4. R+ Manager 2.0을 실행합니다.
5. `Check for Updates` 버튼을 클릭해 최신 업데이트를 설치합니다.
  ![](/img/edu/engineer/BLE_signal_power_02.webp)

6. `ALL PRODUCTS` tab으로 이동하거나 단축키(`Ctrl` + `A`)를 사용합니다.
  ![](/img/edu/engineer/BLE_signal_power_04.webp)

7. product list에서 `CM-550`을 선택합니다.
  ![](/img/edu/engineer/BLE_signal_power_05.webp)

8.  `Update & Test` 버튼을 클릭합니다.
  ![](/img/edu/engineer/BLE_signal_power_06.webp)

9. `Next` 버튼을 클릭합니다.
  ![](/img/edu/engineer/BLE_signal_power_07.webp)

10. 제어기가 연결된 port를 선택합니다.
  ![](/img/edu/engineer/BLE_signal_power_08.webp)

11. Baudrate를 확인합니다. 기본 baudrate는 57600 bps로 고정되어 있습니다.
  ![](/img/edu/engineer/BLE_signal_power_09.webp)

12. CM-550 제어기가 감지되면 `Next`를 클릭합니다.
  ![](/img/edu/engineer/BLE_signal_power_10.webp)

13. 제어기에 최신 firmware가 설치되어 있으면 `Next`를 클릭합니다. 그렇지 않으면 화면의 update 안내에 따라 최신 firmware를 다운로드합니다.
  ![](/img/edu/engineer/BLE_signal_power_11.webp)

14. 연결이 완료되면 아래 control table이 화면에 나타납니다.
  ![](/img/edu/engineer/BLE_signal_power_12.webp)

15. address `139`의 `BLE Signal Power`를 찾을 때까지 아래로 scroll합니다.
  ![](/img/edu/engineer/BLE_signal_power_13.webp)

16. control table 오른쪽 영역에서 `BLE Signal Power`를 선택한 후 `Save` 버튼을 클릭합니다.
  값이 클수록 signal strength가 증가합니다.

    ![](/img/edu/engineer/BLE_signal_power_14.webp)


:::note

    `BLE Signal Power` 값이 `UNKNOWN(0)`으로 표시되면 1단계로 돌아가 BT-410 Master 또는 BT-410 Dongle module의 전원이 꺼져 있는지 확인하세요.

:::


17. 변경된 `BLE Signal Power` 값을 확인합니다.
  ![](/img/edu/engineer/BLE_signal_power_15.webp)

## 자가진단 체크리스트
1. 로봇의 전원이 켜지지 않나요?
  > 배터리 잔량과 연결 상태를 확인하세요.

2. 배터리 잔량은 어떻게 확인하나요?
  > [배터리 잔량 확인](#배터리-잔량-확인) 섹션을 참고하세요.

3. 로봇에서 계속 경고음이 들립니다.
  > 배터리 잔량이 너무 낮으면 배터리 경고음이 울립니다. [배터리 충전](#배터리-충전) 섹션을 참고하세요.

4. 로봇 동작이 어색합니다.
  > 로봇이 올바르게 조립되지 않았을 수 있습니다. 로봇 조립 상태와 [DYNAMIXEL 조립 확인](#dynamixel-조립-확인) 섹션을 확인하세요.

5. 어댑터를 연결하면 켜지지만 배터리로는 켜지지 않습니다.
  > CM-550 제어기 바닥면의 Fuse를 확인하세요. [Fuse 교체](#fuse-교체) 섹션을 참고하세요.

## Reset 방법
오작동으로 로봇을 공장 출하 상태로 reset해야 하는 경우, 제공된 기본 예제(.tsk3 및 .mtn3)를 CM-550에 다시 다운로드해 로봇을 초기화할 수 있습니다. [예제 다운로드](#예제-다운로드)로 이동한 뒤 [PC에서 다운로드](#pc에서-다운로드)를 참고하세요.

## 배터리 충전

:::warning

**주의**
- 제공된 배터리는 키트에 포함된 충전기(LBC-10)로 충전해야 합니다.
- 배터리를 연결하기 전에 충전기에 전원을 먼저 연결하세요.
- 처음 사용하기 전에 배터리를 완전히 충전하세요.

:::


1. 키트에 포함된 충전 배터리를 준비합니다.
  ![](/img/common/battery_charging_1_kr.webp)

2. 아래 그림과 같이 배터리를 충전기에 연결합니다.
  ![](/img/common/battery_charging_2.webp)

3. 충전이 완료되면 LED가 초록색으로 켜집니다.
  ![](/img/common/battery_charging_3.webp)

4. 배터리 없이 SMPS만으로도 로봇과 제어기에 전원을 공급할 수 있습니다.
  ![](/img/common/battery_charging_4_kr.webp)

5. 배터리는 충전기용 connector와 로봇용 connector가 분리되어 있습니다. 배터리를 충전할 때는 로봇에서 `Robot Connector`를 분리하세요.
  ![](/img/common/battery_charging_5.webp)


## 배터리 잔량 확인
![](/img/common/battery_check.webp)

현재 배터리 잔량은 CM-550의 LED 색상으로 확인할 수 있습니다.

- 파란색 : 70% ~ 100%
- 초록색 : 30% ~ 70%
- 빨간색 : 30% 미만(저전압 경고)


:::note

**참고** : Bluetooth 연결이 끊어지면 Power LED가 깜박입니다.

:::


:::warning

**주의** : 충전이 완료되면 배터리를 충전기에서 분리하세요. 로봇을 동작시키는 동안에는 배터리를 충전하지 마세요.

:::


## Fuse 교체
CM-550의 fuse는 예상치 못한 과전류로부터 hardware를 보호합니다.
CM-550이 SMPS로는 켜지지만 배터리로는 켜지지 않는다면 fuse를 확인하고 필요하면 교체하세요.


:::danger

**위험** : fuse를 교체하기 전에 CM-550에서 모든 전원(SMPS, 배터리, USB)을 분리하세요.

:::


CM-550의 전원을 분리한 후 CM-550 바닥면의 fuse를 교체합니다.
