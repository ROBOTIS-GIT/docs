1. 스마트 기기에서 `Play Store` 또는 `App Store`를 실행합니다.
  ![](/img/edu/engineer/engineer_app_installation/app_installation_01_kr.webp)

2. 스토어에서 **ROBOTIS** 또는 **ROBOTIS ENGINEER**를 검색합니다.
  ![](/img/edu/engineer/engineer_app_installation/app_installation_02.webp)

3. 목록에서 `R+ ENGINEER`를 선택한 후 `Get` 또는 `Install` 버튼을 누릅니다.
  ![](/img/edu/engineer/engineer_app_installation/app_installation_03.webp)

4. **Android** : 설치를 계속하려면 `Agree` 버튼을 누릅니다.
  ![](/img/edu/engineer/engineer_app_installation/app_installation_04.webp)
