아래 순서에 따라 motion(.mtn3) 파일을 CM-550 제어기에 다운로드하세요.

1. 제어기를 PC에 연결한 후 조립한 로봇의 motion 예제를 선택합니다.
  ![](/img/edu/engineer/motion_download_pc/remote_pairing_09.webp)

2. 다운로드할 motion 예제를 선택합니다.
  ![](/img/edu/engineer/motion_download_pc/remote_pairing_10.webp)

3. 메뉴에서 `Motion Download` 탭을 클릭합니다.
  ![](/img/edu/engineer/motion_download_pc/remote_pairing_11.webp)

4. 왼쪽 목록에서 다운로드할 motion group을 선택한 후 `Download` 버튼을 클릭합니다.
  ![](/img/edu/engineer/motion_download_pc/remote_pairing_12.webp)
