R+ Task 3.0 앱으로 CM-550 제어기에 예제를 업로드하려면 스마트 기기와 CM-550을 Bluetooth로 페어링해야 합니다.

1. 스마트 기기에서 R+ Task 3.0 앱을 실행한 후 빨간 박스의 버튼을 누릅니다.
  ![](/img/edu/engineer/connect_controller_mobile/remote_pairing_mobile_01.webp)

2. `Connect Robot` 창이 나타나면 빨간 박스의 Bluetooth 검색 버튼을 누릅니다.
  ![](/img/common/bluetooth_connection_6_2.webp)

3. CM-550 제어기의 BLE MAC 주소를 확인합니다.
  ![](/img/common/bluetooth_connection_5.webp)

4. 왼쪽 입력란에 BLE MAC 주소의 마지막 두 문자를 입력합니다.
  ![](/img/common/bluetooth_connection_6_3.webp)

5. 검색 목록에서 BLE MAC 주소를 선택합니다.
  ![](/img/common/bluetooth_connection_6_4.webp)
  ![](/img/edu/engineer/connect_controller_mobile/bluetooth_connection_6_5.webp)
