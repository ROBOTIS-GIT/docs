1. 배터리 또는 SMPS를 연결한 후 CM-550 제어기의 전원을 켭니다. 약 5초 후 LED가 깜박이며 제어기가 켜집니다.

2. Micro USB 케이블로 PC와 제어기를 연결합니다.

3. PC에서 R+ Task 3.0을 실행하고 `ROBOTIS ENGINEER`에서 `KIT2`를 선택한 다음, 목록에서 로봇 구성 프로그램 파일을 다운로드합니다.

    ![](/img/edu/engineer/python_download_pc/tsk3_python_code_download_01.webp)

4. Python editor에 예제 프로그램 코드가 열렸는지 확인한 후 `Select Device`를 클릭합니다.

    ![](/img/edu/engineer/python_download_pc/tsk3_python_code_download_02.webp)

5. `Connect Robot` 창이 나타나면 `Refresh`를 눌러 장치를 선택한 후 `Connect`를 누릅니다.

    ![](/img/edu/engineer/python_download_pc/tsk3_python_code_download_03.webp)

6. 장치 연결이 완료되면 표시된 `Download` 버튼을 눌러 로봇 구성 프로그램을 제어기에 다운로드합니다.

    ![](/img/edu/engineer/python_download_pc/tsk3_python_code_download_04.webp)
