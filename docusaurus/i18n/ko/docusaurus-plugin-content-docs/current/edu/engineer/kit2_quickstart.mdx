## 예제 다운로드
**참고**: ENGINEER KIT 2 예제 파일을 다운로드하기 전에 CM-550 제어기의 펌웨어를 업데이트해야 합니다. [R+ Manager 2.0 소프트웨어로 CM-550 펌웨어 업데이트하기](/docs/software/dynamixel_wizard_2_0/basic_features#firmware-update)

:::


R+ ENGINEER 앱으로 ENGINEER KIT2를 제어하려면 조립한 로봇 예제에 맞는 Python(.py) 및 Motion(.mtn3) 예제 파일을 CM-550 제어기에 다운로드해야 합니다.
- CM-550 제어기에는 기본적으로 ENGINEER KIT1(`MAX-E1`, `Dr. R`, `SPI`) 예제 파일이 다운로드되어 있습니다.
- PC를 사용해 예제 파일을 제어기에 다운로드하려면 아래 [PC에서 다운로드](#pc에서-다운로드) 항목을 참고하세요.
- 스마트 기기를 사용해 예제 파일을 제어기에 다운로드하려면 아래 [Download from Smart Device](#download-from-smart-device) 항목을 참고하세요.

## 예제 실행
`R+ ENGINEER` 앱을 실행한 후 조립한 로봇 예제를 선택하여 로봇을 동작시킵니다.

![](/img/edu/engineer/kit2_quickstart/engineer2_app_execution.webp)


:::warning

**주의** : 잘못된 예제를 선택하면 로봇이 오작동할 수 있습니다.

:::


앱 설정을 변경하려면 앱 오른쪽 위의 메뉴 버튼을 선택합니다.

![](/img/edu/engineer/engineer_app_configuration.webp)

`Connect to Robot` : 연결할 Bluetooth 장치를 선택합니다.
`Reset Example` : 선택한 예제에서 수정한 내용(코드/이미지 포함)을 삭제합니다.
`Range of Gesture Error Setting` : gesture 명령의 민감도를 설정합니다.
`Display Example Image on Gallery` : 일부 스마트 기기에서는 이 기능을 지원하지 않을 수 있습니다.
`Scanning Media` : PC에서 인식되지 않는 파일과 폴더를 갱신합니다. 스캔 후 PC를 다시 연결하세요.
`Version Information` : 현재 앱 버전을 표시합니다.

### MAX-E2
`ROBOTIS ENGINEER` Kit2 앱을 실행한 후 **MAX-E2**를 선택합니다.

#### 리모컨 화면
![](/img/edu/engineer/kit2_quickstart/max2_controller.webp)

`Menu button`: Control/ Streaming/ Facial Detection/ Robot Inspection Mode를 선택합니다.
`Control Buttons`: MAX-E2의 동작을 제어하고 속도를 변경합니다.
`Mode button`: NORMAL/ FIGHT/ SPECIAL 모드를 선택합니다.

`Function button`: 전체 Torque 설정, LED board 색상 변경, 로봇 일어서기 등을 실행합니다.


:::note

**참고**:

### Commando
`ROBOTIS ENGINEER` Kit2 앱을 실행한 후 **Commando**를 선택합니다.

#### Commando Demo 화면
![](/img/edu/engineer/kit2_quickstart/commando_demo.webp)

`Menu Button` : Demo/ Control/ Streaming/ Robot inspection mode를 선택합니다.
`Mode Button` : 아래 설명을 참고하세요.
- `LINE MODE`는 Raspberry Pi Camera로 선의 색상을 인식하고 그에 따라 이동합니다. 선 색상은 `COLOR SELECTION`에서 선택할 수 있습니다.
- `MARKER MODE`는 Raspberry Pi Camera로 marker를 순서대로 인식한 후 `START MARKER`에 따라 로봇을 동작시킵니다. `DEBUGGING MODE`는 loading time을 기준으로 동작을 확인하고, `RUN MODE`는 loading time 없이 동작을 연결합니다.


:::note

**참고**:
- **Streaming** 기능 사용 방법은 [Setting Video Streaming on ROBOTIS ENGINEER App](/docs/edu/engineer/kit2_reference#setting-video-streaming-on-robotis-engineer-app)을 참고하세요.
- Marker는 camera와 30 cm 정도 떨어져 있어야 인식됩니다.

:::


#### Commando 모드 메뉴
![](/img/edu/engineer/icon_remote.webp)

**REMOTE**: 동작, 방향, camera 등을 제어하고 명령합니다. **WHEEL SPEED**를 선택하면 REMOTE mode에서 로봇의 속도를 변경할 수 있습니다.

![](/img/edu/engineer/kit2_quickstart/commando_control.webp)
> Commando REMOTE Mode 화면

### Scorpi
`ROBOTIS ENGINEER` Kit2 앱을 실행한 후 **Scorpi**를 선택합니다.

#### Scorpi Demo 화면
![](/img/edu/engineer/kit2_quickstart/scorpi_demo.webp)

`Menu Button` : Control/ Gesture/ Demo/ Robot inspection mode를 선택합니다.
`Mode Button` : 아래 설명을 참고하세요.
  - `NORMAL MODE`에서는 Scorpi Robot이 일어서서 이동하며, [DMS-80](/docs/edu/engineer/kit2_introduction#dms-80)이 물체를 감지하면 꼬리로 공격합니다.
  - `GUARD MODE`에서는 Scorpi robot이 경계 자세를 취하고, [DMS-80](/docs/edu/engineer/kit2_introduction#dms-80)이 물체를 감지하면 꼬리로 공격합니다.
