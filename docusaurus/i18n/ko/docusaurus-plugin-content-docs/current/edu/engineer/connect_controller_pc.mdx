CM-550은 Micro USB 포트를 통해 PC와 연결할 수 있으며, task(.tsk3) 및 motion(.mtn3) 파일을 다운로드할 수 있습니다.

1. USB 케이블을 PC에 연결합니다.
2. Micro USB 케이블의 반대쪽을 CM-550 제어기에 연결합니다. 제어기는 USB 전원으로 자동으로 켜집니다.
3. R+ Task 3.0을 실행한 후 왼쪽 아래의 `Connect` 아이콘을 누릅니다.
  ![](/img/edu/engineer/connect_controller_pc/remote_pairing_01.webp)

4. 사용할 serial port를 선택합니다.
  ![](/img/edu/engineer/connect_controller_pc/remote_pairing_03.webp)

5. `Connect` 아이콘을 누릅니다.
  ![](/img/edu/engineer/connect_controller_pc/remote_pairing_04.webp)
6. 알림음이 3회 울리면 CM-550이 PC에 연결됩니다.
  ![](/img/edu/engineer/connect_controller_pc/remote_pairing_05.webp)

# Bluetooth 페어링
CM-550에 내장된 BLE 모듈은 BT-410 Dongle과 페어링하여 PC에 연결할 수도 있습니다. 단, 다운로드 시 무선 연결은 유선 연결보다 느릴 수 있습니다.

1. CM-550의 전원을 켭니다.
2. BT-410 Dongle을 PC의 USB 포트에 연결합니다.
3. CM-550의 `MODE` 버튼 부분을 BT-410 Dongle 가까이에 가져가면 자동으로 페어링됩니다.
4. R+ Task 3.0을 실행한 후 왼쪽 아래의 `Connect` 아이콘을 누릅니다.
  ![](/img/edu/engineer/connect_controller_pc/remote_pairing_01.webp)

5. BT-410 Dongle을 사용할 때는 `Use USB Dongle` 옵션을 반드시 체크합니다.
  ![](/img/edu/engineer/connect_controller_pc/remote_pairing_02.webp)

6. 사용할 serial port를 선택합니다.
  ![](/img/edu/engineer/connect_controller_pc/remote_pairing_03.webp)

7. `Connect` 아이콘을 누릅니다.
  ![](/img/edu/engineer/connect_controller_pc/remote_pairing_04.webp)

8. 알림음이 3회 울리면 CM-550이 PC에 연결됩니다.
  ![](/img/edu/engineer/connect_controller_pc/remote_pairing_05.webp)


:::info

**참고** :
- CM-550의 `MODE` 버튼 부분을 BT-410 Dongle 가까이에 가져가면 자동으로 페어링됩니다.
- BT-410 Dongle 페어링이 완료되면 Bluetooth 신호 범위 안에서 연결이 유지됩니다.
- BT-410 Dongle 페어링이 완료된 장치는 Bluetooth 신호 범위 안에서 자동으로 연결됩니다.

:::
