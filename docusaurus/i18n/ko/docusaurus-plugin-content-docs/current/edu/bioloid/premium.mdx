# 개요
![](/img/edu/bioloid/premium/premium_product.webp)

- 우수한 보행 성능의 humanoid 예제(보행 중 스스로 자세 보정)
- Gyro, Distance, IR 등 다양한 sensor 탑재
- 원격 제어 기능 지원(IR 기본, Bluetooth 선택)
- RoboPlus S/W를 이용한 C-style programming 및 motion teaching(USB interface 포함)
- 사용자 꾸미기를 위한 반투명 humanoid skin
- daisy chain topology를 사용하는 digital packet communication
- 다양한 확장 구조를 활용해 여러 형태의 로봇 제작 가능

## 작동하기
### 프로그램 다운로드

- CM-530에는 출하 시 type A용 program이 기본으로 설치되어 있습니다.
- 다른 동작을 위한 task code와 motion file은 [기본 Program](#기본-program) 페이지에서 확인할 수 있습니다.

### 로봇 켜기

1. 전원 스위치를 켜면 LED가 깜박이기 시작합니다.
2. MODE 버튼을 사용해 LED를 "PLAY"로 이동합니다. MODE 버튼을 누를 때마다 LED 위치가 이동합니다.
3. START 버튼을 누릅니다. "PLAY"의 LED가 깜박이는지 확인하세요.
  - LED가 켜지지 않으면 전원 cable/connection을 확인하세요.
  - cable에 문제가 없다면 battery를 충전하세요. 자세한 내용은 충전을 참고하세요.

![](/img/edu/bioloid/premium/cm_530_turn_on.webp)


#### 전원이 켜지지 않습니다.
1. battery가 올바르게 연결되어 있나요?
2. battery가 충분히 충전되어 있나요?
3. battery fuse가 정상인가요?
  - fuse 교체 방법은 [Fuse Replacement](/docs/faq/cm_510_530_fuse)를 참고하세요.

#### 배터리 잔량을 확인하고 싶습니다.
CM-530을 켠 뒤 U 버튼을 누르세요. 아래 그림처럼 LED가 켜져 battery 잔량을 표시합니다.

![](/img/edu/bioloid/premium/cm_530_battery_check.webp)

#### 로봇이 움직이는 동안 계속 경고음이 납니다.
- alarm은 로봇의 battery 잔량이 부족하다는 의미입니다. 즉시 battery를 충전하세요([충전](#충전) 참고).
- battery를 바로 교체하지 않으면 로봇이 예고 없이 꺼져 넘어질 수 있으며, 심각한 손상이 발생할 수 있습니다.


### 로봇 기본 자세 확인(로봇이 올바르게 조립되었는지 확인)

- 로봇은 아래 그림처럼 기본 자세를 취하고 type에 맞는 melody를 재생해야 합니다.
- 로봇이 기본 자세를 취한 상태로 1분 동안 유지하세요.
  > 로봇이 올바르게 보행할 수 있도록 gyro sensor 기준값을 자동으로 설정하기 위한 과정입니다.

- 팔과 다리의 각도를 확인하세요. 그림과 다르다면 "Check Assembly Mode"로 돌아가세요.
- cable이 다리 바깥쪽에 조립되어 있는지 확인하세요.


:::note

로봇이 심각하게 손상될 수 있을 정도로 잘못 조립된 경우 warning sound가 울립니다. 또한 문제가 있는 motor의 LED가 켜지고 torque가 해제되어 손상을 방지합니다.

:::


![](/img/edu/bioloid/premium/premium_operation_01.webp)

![](/img/edu/bioloid/premium/premium_operation_02.webp)

#### 로봇의 기본 자세와 동작이 어색합니다.
- 기본 자세가 어색한가요?
  > "Check Assembly Mode"로 돌아가 모든 DYNAMIXEL이 올바르게 조립되었는지 다시 확인하세요.
- Free Walk Mode에서 장애물을 감지하지 못하나요?
  > Absolute distance measurement sensor의 cable이 올바르게 연결되어 있는지 확인하세요.

#### 로봇이 보행 중 쉽게 넘어지거나 불안정합니다.
- 로봇 자세를 감지하는 gyro sensor가 동작하지 않습니다.
  > 조립서를 참고하여 gyro sensor가 올바르게 조립되었는지 확인하세요.

#### 경고음 후 torque가 해제되고 DYNAMIXEL LED가 켜집니다.
- motor와 frame이 올바르게 조립되지 않았거나 로봇 joint가 제대로 움직이지 못하면 손상 방지를 위해 warning sound가 울립니다.
  > LED가 켜진 motor를 찾고 조립서를 참고하여 올바르게 조립되었는지 확인하세요.

  > joint에 cable이나 다른 이물질이 끼어 있지 않은지 확인하세요. "Check Assembly Mode"를 참고하세요.

#### 로봇 type과 melody가 일치하지 않습니다.
- ID 7 ~ 10 motor가 올바르게 조립되어 있는지 확인하고, loose connection이 없는지 확인하세요.

#### 리모컨 조종 모드

RC-100으로 로봇을 조종할 수 있습니다.

1. POWER/MODE 버튼을 2초 동안 누릅니다.
2. 아래 버튼을 눌러 로봇을 조종합니다.
  - Walking : U / L / D / R
  - Change Posture : 1 + U / L / D / R

  - Soccer Moves : 3 + U / L / D / R
  - Battle Moves : 4 + U / L / D / R

#### 조립 확인 모드

Check Assembly Mode에서는 로봇이 올바르게 조립되었는지 확인할 수 있습니다. motor를 하나씩 분리해 standard posture와 비교하세요.
1. Check Assembly Mode를 시작하면 torque가 해제됩니다.
2. U 또는 D 버튼을 눌러 motor를 하나씩 확인합니다. 선택한 motor의 LED가 켜지고 기본 위치로 이동합니다. (U : ID를 1 증가, D : ID를 1 감소)
3. LED가 켜진 motor의 ID를 확인하고 조립서의 ID와 비교합니다.
  > 해당 ID가 로봇에 없으면 warning sound가 울립니다.
4. 조립한 motor의 위치를 basic posture와 비교합니다.
  > LED는 켜져 있지만 torque가 해제되어 있다면 cable 또는 motor 조립 상태를 확인하세요.

# 튜토리얼
## 화면 출력하기
이 튜토리얼의 목표는 아래와 같이 output screen에 1과 2를 출력하는 것입니다.

![Screen-Output-1][img_011]

### Task Code 작성

1. RoboPlus Task Program을 실행합니다.

    아래 그림처럼 `Start > All Programs > ROBOTIS > RoboPlus > Software > RoboPlus Task`로 이동해 RoboPlus Task를 실행합니다.

    ![Screen-Output-2][img_012]

   - RoboPlus Task 초기 화면

    ![Screen-Output-3][img_013]

2. Controller를 선택합니다.

    빈 줄을 double click하거나 `Enter`를 누릅니다. `Select Control` window에서 사용할 controller를 선택한 뒤 `OK` 버튼을 누릅니다.

    ![Screen-Output-4][img_014]

3. `Start Program` 생성

    `Select Instruction Type` window에서 `Start Program`을 선택하면 RoboPlus Task에 `Start Program`이 자동으로 생성됩니다.

    ![Screen-Output-5][img_015]

4. `Endless Loop` command 입력

    숫자를 화면에 계속 출력하려면 `Endless Loop` command를 사용합니다(command line 생성).
    Start Program의 `{`와 `}` 사이 빈 줄을 double click하거나 `Enter`를 눌러 `Select Instruction Type` window를 엽니다. 목록에서 `Loop > Endless Loop(while(1))`를 선택합니다.

    ![Screen-Output-6][img_016]

5. `Load` command 입력

    화면에 숫자를 출력하는 데 필요한 `Print` command를 입력하기 위해 `Load` command를 사용합니다.
    `Endless Loop`의 `{`와 `}` 사이 빈 줄에 `Execute > Load (Assignment value)`를 삽입합니다.

    ![Screen-Output-7][img_017]

6. `Print`에 `1` load

    `Load` parameter 중 왼쪽 parameter(?)를 선택합니다(parameter 설명).
    왼쪽 parameter는 오른쪽 parameter의 입력을 받습니다.
    왼쪽 parameter(?)를 double click하거나 한 번 클릭한 뒤 `Enter` key를 눌러 `Select Parameter Window`를 엽니다.
    `Controller > Print`를 선택한 뒤 `OK`를 누릅니다.

    ![Screen-Output-8][img_018]

    같은 방법으로 오른쪽 parameter(?)에는 `Constant Numbers > Number > 1`을 선택합니다.

    ![Screen-Output-9][img_019]

    `Load` command의 두 parameter가 모두 설정되면 아래와 같이 표시됩니다.

    ![Screen-Output-10][img_020]

7. `Print with Line`에 `2` load

    `Print` command 아래의 `}`(endless loop section 끝)을 선택하고 `Space` key를 눌러 새 줄을 추가합니다. 5, 6단계를 반복해 `Load` command를 입력하고 `Controller > Print with Line` 및 `2`를 입력합니다. 최종 task code는 아래와 같습니다.

    ![Screen-Output-11][img_021]

8. Task Code 저장

    Ctrl + S 또는 Save icon을 누릅니다.

    ![Screen-Output-12][img_022]

### Task Code 다운로드

위에서 생성한 task code를 다운로드합니다.([Task Code 다운로드 방법][How to Download Task Code])

### Task Code 실행

1. Program Output Monitor 열기

    program 출력을 확인하려면 **program을 실행하기 전에 Program Output Monitor를 먼저 열어야 합니다**.
    Program Output Monitor를 여는 방법은 세 가지입니다.

    - Download Program window에서 View Print of Program을 클릭합니다.

      ![Screen-Output-13][img_023]

## Gyro Sensor 보정
- 선행 학습 : [Walking Machine](#walking-machine)

[Walking Machine] section에서 사용한 task code에 gyro sensor 제어 code를 추가합니다. 시작하기 전에 [Walking Machine] section을 먼저 확인하세요.

이 튜토리얼의 목표는 gyro sensor를 사용해 humanoid의 자세를 보정하는 방법을 익히는 것입니다.

Gyro sensor는 angular velocity(초당 각도 변화량)를 확인하는 데 사용됩니다. 로봇이 기울어져 특정 방향의 angular velocity가 증가하면 servo motor 값을 반대 방향으로 조정해 로봇 자세를 바로잡을 수 있습니다.

`다운로드` [TASK Code(BIO_PRM_GyroSensorExam_EN.tsk)](https://robotis.s3.ap-northeast-2.amazonaws.com/support/en/baggage_files/bioloid/bio_prm_gyrosensorexam_en.tsk)

### 준비 사항

- gyro sensor의 X-axis 값은 port #3에, Y-axis 값은 port #4에 연결되어야 합니다.
- 그 외의 경우에는 task code를 사용자의 로봇에 맞게 수정하세요.

### 개념

- [Callback Function]

  gyro를 사용하는 humanoid는 [Callback Function]을 이용해 posture adjustment value를 계산합니다.
  callback function은 main program routine과 독립적으로 동작하며 고정 간격으로 자동 실행되는 function입니다. 따라서 일정 간격으로 adjustment value를 계산하고 callback function에서 그 값을 사용해 자세를 보정하면 로봇이 자동으로 자세를 조정할 수 있습니다.

[Callback Function]: /docs/software/rplus_1_0/rplus_task/programming_01#callback-function
- [Joint Offset]

  joint offset은 gyro sensor에서 얻은 adjustment value에 더해져 humanoid 자세 보정에 사용됩니다. 자세한 내용은 [Joint Offset]을 참고하세요. 이는 특정 actuator의 joint position value에 offset을 주는 parameter입니다. 따라서 joint offset이 설정된 actuator는 motion file에 지정된 position value + joint offset value를 사용해 motion을 실행합니다.

[Joint Offset]: /docs/software/rplus_1_0/rplus_task/programming_02#joint-offset
### Task Code 살펴보기

1. `InitializationGyro` Call Function

  ![](/img/edu/bioloid/premium/premium_tutorial_21.webp)

2. Joint Offset 적용을 위한 `BalancePage` 실행

  joint offset을 적용하려면 motion이 실행되어야 합니다. motion이 재생되지 않는 상태에서는 gyro sensor에서 값이 입력되어도 joint offset이 적용되지 않습니다. **BalancePage**는 motion이 실행되지 않을 때 joint offset을 적용하기 위해 사용됩니다.

  ![](/img/edu/bioloid/premium/premium_tutorial_22.webp)

3. `InitializationGyro` Function

  `InitializeGyro` function은 gyro sensor 값을 0.128초 간격으로 10회 읽고 평균값을 gyro sensor standard value로 저장합니다. standard value는 약 250입니다. gyro sensor 값이 230보다 작거나 270보다 크면 gyro sensor가 없는 것으로 판단하고 adjustment를 사용하지 않습니다. 이는 gyro sensor가 없거나 initialization 중 로봇이 움직인 경우입니다.

  ![](/img/edu/bioloid/premium/premium_tutorial_23.webp)

4. `Callback Function`에서 adjustment value 계산

  callback function은 일정 간격으로 현재 gyro sensor 값을 읽고 standard value와 비교해 adjustment value를 계산합니다. `UseGyro` 변수가 false이면 로봇은 자세 보정을 수행하지 않습니다. 따라서 gyro adjustment를 사용하지 않을 구간에서는 `UseGyro` 변수를 false로 설정하세요.

  ![](/img/edu/bioloid/premium/premium_tutorial_24.webp)

  계산된 adjustment value를 joint offset에 적용해 로봇 자세를 보정합니다. 앞/뒤 기울어짐을 보정하려면 무릎과 발목 joint인 actuator 13~16을 사용해야 합니다. 좌/우 기울어짐을 보정하려면 발목과 허리 joint인 actuator 9~10 및 17~18을 사용해야 합니다.

  ![](/img/edu/bioloid/premium/premium_tutorial_25.webp)

### 보정 테스트

- task code를 로봇에 다운로드합니다([Task Code 다운로드 방법][How to Download Task Code]).
- gyro를 initialize하려면 task code 실행 후 로봇을 평평한 바닥에 최소 1.5초 이상 세워 두어야 합니다. gyro sensor가 연결되어 있지 않거나 gyro initialization 중 움직임이 있으면 gyro adjustment를 수행하지 않습니다.
- 똑바로 서 있는 상태에서 강한 외부 힘으로 자세가 변했을 때 로봇이 스스로 보정하려고 하는지 확인하세요.
- 경사면에서 gyro를 사용할 때와 사용하지 않을 때 로봇 동작을 비교하세요.

이 튜토리얼의 목표는 motion과 관계없이 gripper를 제어하는 방법을 익히는 것입니다.

로봇에 gripper를 추가하면 motion과 관계없이 로봇 arm을 고정해야 할 때가 있습니다.

이 경우 arm을 고정하기 위해 motion을 수정할 필요는 없습니다. 대신 특정 actuator가 motion data에 의해 제어되지 않도록 하면서 task code로 gripper를 제어하는 방법을 알아봅시다.

- [다운로드](https://robotis.s3.ap-northeast-2.amazonaws.com/support/en/baggage_files/bioloid/bio_prm_humanoidtypeb_en.mtn) Motion File(BIO_PRM_HumanoidTypeB_EN.mtn)
- [다운로드](https://robotis.s3.ap-northeast-2.amazonaws.com/support/en/baggage_files/bioloid/bio_prm_gripperexam_en.tsk) TASK Code(BIO_PRM_GripperExam_EN.tsk)

### 배경 지식

gripper와 motion을 별도로 제어하기 위한 priority 설정입니다.

- 일반 Control Priority

  일반적으로 **motion data**가 가장 높은 priority를 가지고, **task code**가 그 다음 priority를 가집니다. 따라서 일반적인 상황에서는 motion이 실행되면 task code로 특정 DYNAMIXEL만 제어할 수 없습니다.

- Control Priority 변경

  motion이 실행되는 동안 task code로 motor(gripper를 포함한 arm 전체)를 제어하는 방법은 두 가지입니다.

  1. motion data에서 actuator ID의 “Using Now/Not Using” checkbox를 해제합니다.
  2. actuator의 “Joint Offset” parameter를 1024로 설정합니다.

  첫 번째 방법은 전체 page에서 actuator를 비활성화합니다. 해당 actuator가 필요한 motion이 있더라도 motion data로 제어할 방법이 없습니다. 따라서 필요에 따라 특정 actuator에 대한 motion data 적용을 활성화/비활성화할 수 있는 두 번째 방법이 더 적합할 수 있습니다.

### Task Code 작성

1. Gripper Control 초기화

  양쪽 arm actuator의 joint offset을 1024로 설정해 motion data에 의해 제어되지 않도록 합니다. arm과 gripper의 movement speed, gripper grasping power와 flexibility 같은 data를 초기화한 뒤 arm을 default position에 놓습니다.

  ![](/img/edu/bioloid/premium/premium_tutorial_39.webp)

2. Callback Function 수정(Gyro Adjustment)

  gyro adjustment value를 적용하기 위해 callback function에서 joint offset을 사용하는 경우, gripper에 사용되는 joint에는 joint offset을 설정하지 않아야 합니다. 이는 STEP 1에서 1024로 설정한 값이 변경되는 것을 방지하기 위함입니다.

  ![](/img/edu/bioloid/premium/premium_tutorial_40.webp)

3. Gripper/Arm Control Function

  gripper와 arm을 제어하려면 아래 function을 복사합니다. 이 function은 motion 상태와 관계없이 gripper와 arm의 움직임을 제어할 수 있습니다.

  ![](/img/edu/bioloid/premium/premium_tutorial_41.webp)

  왼쪽 arm과 gripper도 위와 같은 방식으로 function을 작성합니다.

4. remote controller로 arm과 gripper 제어

  remote controller를 사용해 gripper와 arm을 제어하는 code를 추가합니다. [Custom Motions: Task Code]를 확인하면 아래 code를 이해하는 데 도움이 됩니다.

  ![](/img/edu/bioloid/premium/premium_tutorial_42.webp)

## DYNAMIXEL 관리
robot actuator로 사용되는 DYNAMIXEL은 다양한 기능을 가지고 있습니다. 이 section에서는 DYNAMIXEL 설정을 변경하는 방법을 설명합니다.

### ID 변경

1. controller가 연결된 port를 선택합니다.
2. “Connect”를 클릭합니다.

    ![DXL_Management_01](/img/edu/bioloid/premium/dxl_management_01.webp)

3. 왼쪽에 연결된 DYNAMIXEL 목록이 표시됩니다. ID를 변경할 DYNAMIXEL을 클릭합니다.
4. Control Table에서 ID row를 클릭합니다.
5. ID List combo box를 클릭해 선택 가능한 ID 목록을 확인합니다. ID를 선택한 뒤 Apply를 클릭합니다.

    ![DXL_Management_02](/img/edu/bioloid/premium/dxl_management_02.webp)

- RoboPlus Motion과 RoboPlus Task에서 사용하려면 ID가 아래 범위 안에 있어야 합니다.
  - DYNAMIXEL ID는 0~25 사이여야 합니다.
  - AX-S1의 ID는 100~109 사이로 설정해야 합니다.

### Movement Mode 변경

DYNAMIXEL은 두 가지 mode로 동작할 수 있습니다.
- Wheel Mode : 일반 motor처럼 360도 회전합니다.
- Joint Mode : 일반 servo motor처럼 설정된 각도로 움직입니다.

mode는 RoboPlus Manager를 사용해 변경할 수 있습니다. 한 번 설정한 mode는 전원을 꺼도 유지됩니다.

1. controller가 연결된 port를 선택합니다.
2. “Connect”를 클릭합니다.

    ![DXL_Management_03](/img/edu/bioloid/premium/dxl_management_03.webp)

3. 왼쪽에 연결된 DYNAMIXEL 목록이 표시됩니다. mode를 변경할 DYNAMIXEL을 클릭한 뒤 Control Table에서 CW/CCW Angle Limit line을 클릭합니다.
4. Wheel Mode로 설정하려면 CW/CCW Angle Limit 값을 “0”으로 변경합니다. 또는 "Wheel Mode" button을 클릭해도 됩니다.

    ![DXL_Management_04](/img/edu/bioloid/premium/dxl_management_04.webp)

5. 다시 Joint Mode로 설정하려면 CW/CCW Angle Limit 값을 "0"이 아닌 값으로 설정합니다. Joint Mode의 초기값은 CW Angle Limit "0", CCW Angle Limit "1023"입니다.

### 문제 해결

RoboPlus Manager에서 원하는 DYNAMIXEL을 찾을 수 없다면 아래를 시도하세요.
1. DYNAMIXEL 1개만 연결하고 중복 ID가 있는지 확인합니다. DYNAMIXEL 1개만 연결했는데도 왼쪽에 DYNAMIXEL이 보인다면 ID가 중복되었을 가능성이 높습니다. 즉시 ID를 변경하세요.
2. 아래 이미지처럼 어떤 DYNAMIXEL도 찾을 수 없다면 "DYNAMIXEL Search"를 클릭하세요. communication speed가 1Mbps로 설정되어 있지 않으면 "DYNAMIXEL Search" 기능이 controller의 communication speed를 자동으로 1Mbps로 reset해 인식할 수 있게 합니다.

  ![DXL_Management_05](/img/edu/bioloid/premium/dxl_management_05.webp)

문제가 계속되면 DYNAMIXEL 수리가 필요할 수 있습니다. 구매처의 service department에 문의하세요.


## ZIGBee 무선 제어
### ZIGBee
![Zig-100/110](/img/edu/bioloid/premium/zig_100_110.webp)

[ZIG-100/110]은 wireless communication에 ZIGBee를 사용합니다. ZIGBee는 Bluetooth처럼 Personal Area Network(PAN)에서 널리 사용되는 communication technology입니다. ZIGBee는 IR보다 communication quality가 좋아 여러 사용자가 interference 없이 로봇을 제어할 수 있습니다.


:::warning

**주의** : 모든 제품에 zigbee module이 포함되는 것은 아니며, 별도로 구매해야 할 수 있습니다.

:::


### Controller & ZIGBee

OLLO와 Bioloid는 모두 IR communication method를 사용하는 RC-100을 사용합니다. Zigbee communication method로 upgrade하려면 ZIG-110 set를 별도로 구매해야 합니다. ZIG-110 set에는 [RC-100]에 장착하는 Zig-100 module 1개와 Controller에 장착하는 Zig-110 module 1개가 포함됩니다.


:::note

**참고** : 하나의 Zigbee set에 포함된 module들은 서로 communication하도록 미리 설정되어 있습니다. 따라서 한 set의 module은 다른 set의 module과 동작하지 않을 수 있습니다. 서로 섞이지 않도록 주의하세요.

:::

위 이미지는 frame과 AX-12+를 사용해 gripper를 만드는 방법을 보여줍니다. 양손에 gripper를 장착하려면 두 개를 만드세요.

### Gripper 장착

gripper가 장착된 로봇을 만들면 로봇으로 할 수 있는 일을 확장할 수 있습니다.
gripper robot 제어에 대한 자세한 내용은 gripper control을 참고하세요.
아래는 gripper가 장착된 Type B humanoid 이미지입니다.
오른쪽 gripper에는 AX-12+ #9, 왼쪽에는 AX-12+ #10이 사용되었습니다.
