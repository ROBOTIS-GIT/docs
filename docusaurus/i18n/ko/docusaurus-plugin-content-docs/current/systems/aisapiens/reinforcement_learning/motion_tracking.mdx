# Motion Tracking

AI Sapiens K1이 reference motion을 추종하도록 학습하는 방법을 선택합니다. 플랫폼과 학습 방법을 구분하고, 학습 전에 reference를 준비하세요.

## 학습 방법 선택

| 방법 | 학습 방식 | 문서 범위 |
| --- | --- | --- |
| BeyondMimic (PPO) | 시뮬레이터 transition으로 PPO policy를 학습합니다. | 기존 Dance1/Dance2 학습, play, ONNX export 및 같은 실행의 Sim2Real 자산 준비. |
| SuperMimic (World Model) | 수집한 transition으로 dynamics를 학습하고 imagined rollout을 통해 policy를 최적화합니다. | 실험적 world-model 기반 추종. PPO와 checkpoint·관측·배포 계약이 다릅니다. |

학습 방법과 physics backend는 별도 선택입니다. Cyclo Lab의 Newton/PhysX 선택은 PPO를 SuperMimic으로 바꾸지 않습니다. Cyclo MJLab은 MuJoCo를 사용합니다. 플랫폼·방법·backend 조합별 지원 범위를 확인하세요.

## 플랫폼별 지원 범위

| 플랫폼 / 방법 | Runtime 및 physics | 현재 범위 | Play 및 배포 |
| --- | --- | --- | --- |
| Cyclo Lab / BeyondMimic | Isaac Sim 6.2 / Isaac Lab 3.0 흐름의 Newton 또는 PhysX. | K1 Dance1/Dance2 문서화된 흐름. | 시뮬레이션 play와 ONNX/Sim2Real 자산 준비가 문서화되어 있습니다. |
| Cyclo Lab / SuperMimic | Isaac Lab native 통합. 현재 개발 구현은 PhysX를 선택합니다. | 개발 브랜치의 GenCoord single-motion, 이름이 있는 50 Hz reference 공유, 제한된 native 학습을 확인했습니다. Newton·MaxCoord·compiled 실행·장기 추종 품질은 미검증입니다. | 새 process의 headless 로컬 play·resume update 확인. 검증된 Sim2Real export는 없습니다. |
| Cyclo MJLab / BeyondMimic | 기존 Cyclo MJLab runtime 및 MuJoCo. | K1 Dance1/Dance2 문서화된 흐름. | 시뮬레이션 play와 같은 실행의 policy/config export가 문서화되어 있습니다. |
| Cyclo MJLab / SuperMimic | task/learning 흐름에 통합 중인 MuJoCo research API. | 개발 브랜치의 GenCoord·MaxCoord dispatch, 기존 50 Hz Cyclo/MuJoCo NPZ 직접 재사용, 제한된 optimizer 실행을 확인했습니다. 추종 수렴이 검증된 것은 아닙니다. | PPO와 bundle/runtime 요구 조건이 다르며 로봇 배포 계약은 검증되지 않았습니다. |

SuperMimic의 기본 개발 설정은 privileged simulator 관측을 사용합니다. world-model checkpoint나 optimizer update 성공만으로 proprioceptive 로봇 policy가 되는 것은 아닙니다. BeyondMimic의 ONNX 또는 `sim2real.yaml` 경로로 로드하지 마세요.

## 진행 순서

1. [Motion 준비와 검토](./motion_preparation).
2. [Cyclo Lab](./cyclo_lab/) 또는 [Cyclo MJLab](./cyclo_mjlab/) 설정.
3. [Lab BeyondMimic](./cyclo_lab/mimic), [Lab SuperMimic](./cyclo_lab/supermimic), [MJLab BeyondMimic](./cyclo_mjlab/mimic), [MJLab SuperMimic](./cyclo_mjlab/supermimic) 선택.
4. 학습 후 같은 reference/checkpoint로 전체 motion play를 확인합니다.
5. 선택한 방법에 문서화된 배포 계약만 따릅니다. SuperMimic 로봇 배포는 제공되지 않습니다.

## 기존 Mimic 사용자

기존 `/cyclo_lab/mimic`, `/cyclo_mjlab/mimic` URL은 유지하며 방법 이름을 BeyondMimic (PPO)으로 명시합니다. 기존 `Cyclo-Mimic-*` task ID도 호환 이름으로 유지합니다. 메뉴 이름 변경은 task나 checkpoint 형식 변경을 뜻하지 않습니다.

Isaac Sim 6.2 / Isaac Lab 3.0에서는 학습과 play에 같은 task ID를 사용합니다. 별도 `-Play` 등록이나 다른 시각화 옵션이 있던 이전 버전 명령을 6.2 backend 인자와 혼합하지 마세요.

공개된 두 개발 브랜치는 `scripts/reinforcement_learning/train.py`·`play.py`와 선택적 `--algorithm beyondmimic|supermimic`, task 추론을 제공합니다. Backend 인자는 플랫폼별로 다릅니다. Lab은 v2 `--checkpoint`로 learned/optimizer state를 복원하고 replay는 새로 시작합니다. MJLab은 로컬 `--checkpoint-dir` inference bundle을 사용합니다. Offline play에 W&B sync는 필요하지 않으며 두 형식 모두 PPO 배포 export와 다릅니다.
