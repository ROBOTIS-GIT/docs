:::note

**참고** :
- X 시리즈는 [XL320](/docs/dxl/model_reference/x_series/xl_series/xl320)을 제외하고 DYNAMIXEL Protocol 2.0을 DYNAMIXEL Protocol 1.0으로 변경할 수 있습니다
- 각 DYNAMIXEL 모델의 컨트롤 테이블에서 DYNAMIXEL Protocol Type(13)을 참고하세요.

:::


:::info

**정보** :
- MX(2.0) Firmware는 DYNAMIXEL Protocol 1.0을 사용하는 기본 MX Firmware와 다른 컨트롤 테이블 및 Address를 사용합니다.
- MX(2.0) Firmware는 DYNAMIXEL-X 기능을 계승합니다.

:::
