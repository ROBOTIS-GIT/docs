현재 적용되고 있는 Load를 의미합니다.
값의 범위는 0 ~ 2047이며, 단위는 약 0.1 [%]입니다.
값이 0 ~ 1,023이면 CCW 방향으로 Load가 작용한다는 의미입니다.
값이 1,024 ~ 2,047이면 CW 방향으로 Load가 작용한다는 의미입니다.
즉, 10번째 bit가 방향 bit로 사용되어 방향을 나타내며, 1,024는 0과 같습니다.
예를 들어 값이 512이면 Maximum Torque의 약 50 [%]에 해당하는 Load가 CCW 방향으로 감지된다는 의미입니다.

| Bit | 15 ~ 11  | 10 | 9 ~ 0|
| :----: | :---: | :---: | :---: |
| 값 | 0 | Load Direction | Data (Load Ratio)|

:::note

CCW Load : Load Direction = 0, CW Load : Load Direction = 1

:::

:::note

Present Load는 내부 출력값을 기준으로 추정한 값이며, Torque 센서 등으로 측정한 값이 아닙니다. 따라서 무게나 Torque를 측정하는 용도로는 정확하지 않을 수 있습니다. 관절에 작용하는 힘의 방향과 크기를 예측하는 용도로 사용하는 것을 권장합니다.

:::
