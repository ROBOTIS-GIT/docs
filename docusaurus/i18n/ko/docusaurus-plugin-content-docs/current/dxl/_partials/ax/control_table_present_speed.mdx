현재 이동 속도입니다.
0 ~ 2,047 (0x7FF)까지 사용할 수 있습니다.
값이 0 ~ 1,023 범위이면 모터가 CCW 방향으로 회전한다는 의미입니다.
값이 1,024 ~ 2,047 범위이면 모터가 CW 방향으로 회전한다는 의미입니다.
즉, 10번째 bit가 방향 bit로 사용되어 방향을 제어하며, 0과 1,024는 같습니다.
이 값의 단위는 동작 모드에 따라 달라집니다.

+ Joint Mode

  단위는 약 0.111 rpm입니다.
  예를 들어 300으로 설정되면 모터가 CCW 방향으로 약 33.3 rpm의 속도로 움직인다는 의미입니다.

+ Wheel Mode

  단위는 약 0.1 [%]입니다.
  예를 들어 512로 설정되면 CCW 방향으로 Maximum Torque의 50 [%]가 제어된다는 의미입니다.
