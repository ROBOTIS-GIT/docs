Maximum Torque Limit입니다.
0 ~ 1,023(0x3FF)까지 사용할 수 있으며, 단위는 약 0.1 [%]입니다.
예를 들어 값이 512이면 약 50 [%]이며, Maximum Torque의 50 [%]만 사용한다는 의미입니다.
전원이 켜지면 Torque Limit(34)는 [Max Torque(14)] 값으로 초기화됩니다.

:::note

[Alarm LED(17)/Shutdown(18)](#alarm-led17-shutdown18) 기능이 동작하면 Torque Limit(34)가 0이 되어 모터의 Torque가 사라집니다. 오류 조건이 해제되고 Torque Limit(34)를 0이 아닌 값으로 변경하면 모터를 다시 동작시킬 수 있습니다.

:::
