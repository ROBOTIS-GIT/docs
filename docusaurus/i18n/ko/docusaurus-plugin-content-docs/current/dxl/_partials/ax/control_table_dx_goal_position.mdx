Goal Position(30)을 통해 다이나믹셀의 목표 위치를 설정합니다.
사용 가능한 위치 범위는 0 ~ 1,023 (0x3FF)이며, 단위는 0.29 &deg;입니다.
Goal Position(30)이 [CW/CCW Angle Limit(6, 8)](#cwccw-angle-limit6-8) 범위를 벗어나도록 설정되면 Status Packet은 ERROR 필드를 통해 Angle Limit Error Bit (0x01)를 전송합니다. 이때 [Alarm LED(17)/Shutdown(18)](#alarm-led17-shutdown18)에 Angle Limit Error Bit(0x01)가 설정되어 있으면 Alarm LED가 점멸하고 모터 출력은 0 [%]가 됩니다.
