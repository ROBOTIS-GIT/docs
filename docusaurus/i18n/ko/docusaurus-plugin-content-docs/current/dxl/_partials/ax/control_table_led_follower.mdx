LED(65)는 LED의 On/Off를 설정합니다.

|    Bit     | 설명      |
|:----------:|:-----------------|
| 0(Default) | LED를 Off합니다 |
|     1      | LED를 On합니다  |

:::note

LED는 다이나믹셀의 다양한 상태를 표시하는 데에도 사용됩니다. 자세한 내용은 아래 표를 참고하세요.

|      상태      |  LED 표시  |
|:----------------:|:--------------------:|
|     Booting      |  LED가 1회 점멸           |
|   Factory Reset  | LED가 빠르게 4회 점멸 |
| Shutdown Error   |     LED가 계속 점멸     |
| 슬레이브 모드 | 3회 점멸 |
|    Bootloader Mode     |        LED가 계속 켜짐       |

:::
