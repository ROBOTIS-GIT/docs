Temperature Limit(31)은 DYNAMIXEL의 동작 온도 상한 값을 설정합니다.
[Present Temperature(146)](#present-temperature146)가 Temperature Limit(31)보다 높아지면 [Hardware Error Status(70)](#hardware-error-status70)의 **Overheating Error Bit(0x04)**와 **Alert Bit(0x80)**이 설정됩니다. [Shutdown(63)]에 Overheating Error Bit(0x04)가 설정된 경우 [Torque Enable(64)]은 '0'(Torque OFF)으로 변경됩니다.
자세한 내용은 [Shutdown(63)]을 참고하세요.

|     단위     |    범위     | 설명         |
|:------------:|:-----------:|:------------:|
| 약 1&deg; |   0 ~ 100   | 0 ~ 100&deg; |

:::warning

**주의** : 이 값을 기본값보다 높게 설정하지 마십시오. DYNAMIXEL에서 온도 경고 알람(Overheating Error Bit(0x04))이 발생하면 20분 이상 식힌 후 사용하세요. 그렇지 않으면 동작 중 제품이 심하게 손상될 수 있습니다.

:::
