[Operating Mode(11)]가 **PWM Control Mode**일 때는 PID 제어기와 Feedforward 제어기가 모두 비활성화되고, Goal PWM(100) 값이 Inverter를 통해 모터를 직접 제어합니다. 그 외 [Operating Mode(11)]에서는 Goal PWM(100)이 PWM 값을 제한하는 용도로만 사용됩니다. Goal PWM(100)이 Gain과 함께 동작하는 방식은 [Position PID Gain(80, 82, 84), Feedforward 1st/2nd Gains(88, 90)](#position-pid-gain80-82-84) 또는 [Velocity PI Gain(76, 78)](#velocity-pi-gain76-78)을 참고하세요.

|      단위       |                범위                |
|:---------------:|:----------------------------------:|
| about 0.113 [%] | -[PWM Limit(36)] ~ [PWM Limit(36)] |

:::note

**참고** : Goal PWM(100)은 [PWM Limit(36)]을 초과할 수 없습니다.

:::
