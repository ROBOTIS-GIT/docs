[Operating Mode(11)]가 **Torque Control Mode**일 때 Goal Current(102)로 목표 전류를 설정할 수 있습니다. 또한 Current-based Position Control Mode에서는 Goal Current(102)를 전류 제한값으로 사용할 수 있습니다. Goal Current(102)는 [Current Limit(38)]보다 큰 값으로 설정할 수 없습니다.
