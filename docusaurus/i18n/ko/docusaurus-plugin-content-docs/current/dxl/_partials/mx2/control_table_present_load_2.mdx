현재 적용되는 하중을 의미합니다.
예를 들어 값이 500이면 최대 토크의 약 50 [%] 하중이 CCW 방향으로 감지되었다는 의미입니다.

| Unit  | Value Range   | 설명 |
| :---: | :-----------: | :---: |
| 0.1%  | -1,000 ~ 1,000| 양수(CCW 방향 하중), 음수(CW 방향 하중) |

:::note

**참고** : Present Load는 토크 센서 등으로 측정한 값이 아니라 내부 출력 값을 기반으로 추정한 값입니다. 따라서 무게나 토크를 측정하는 용도로는 부정확할 수 있습니다. 관절에 가해지는 힘의 방향과 크기를 예측하는 용도로 사용하는 것을 권장합니다.

:::
