Velocity Trajectory(136)은 Profile에 의해 생성된 목표 속도 궤적입니다. [Operating Mode(11)]에 따라 동작 방식이 달라집니다. 자세한 내용은 [Profile이란?]을 참고하세요.
1. **Velocity Control Mode** : Profile이 종료 지점에 도달하면 Velocity Trajectory(136)은 [Goal Velocity(104)]와 같아집니다.
2. **Position Control Mode, Extended Position Control Mode, Current-based Position Control Mode** : Velocity Trajectory는 Position Trajectory(140)을 생성하는 데 사용됩니다. Profile이 종료 지점에 도달하면 Velocity Trajectory(136)은 '0'으로 초기화됩니다.
