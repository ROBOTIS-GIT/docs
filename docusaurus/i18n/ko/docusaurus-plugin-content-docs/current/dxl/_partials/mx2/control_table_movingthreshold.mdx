Moving Threshold(24)는 다이나믹셀이 움직이는 중인지 여부를 판단하는 기준 속도입니다.
[Present Velocity(128)]의 절대값이 Moving Threshold(24)보다 크면 [Moving(122)]이 `1`로 설정되고, 그렇지 않으면 `0`으로 설정됩니다.

|      단위       |   범위   |                 설명                  |
|:---------------:|:---------:|:--------------------------------------------:|
| 약 0.229 rpm | 0 ~ 1,023 | 속도 관련 Data는 모두 동일한 단위를 사용합니다. |
