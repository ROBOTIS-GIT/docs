Current Limit(38)은 최대 전류(Torque) 출력 제한값을 나타냅니다. [Goal Current(102)]에는 Current Limit(38)을 초과하는 값을 설정할 수 없습니다. Current Limit(38)은 Torque Control Mode와 Current-based Position Control Mode에서 사용되므로, Current Limit(38)을 낮추면 다이나믹셀의 Torque가 감소합니다. 자세한 내용은 [Position PID Gain(80 ~ 84)](#position-pid-gain80-82-84)을 참고하세요.
