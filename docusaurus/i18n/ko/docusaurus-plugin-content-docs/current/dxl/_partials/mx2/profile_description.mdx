Profile은 동작 중 속도와 가속도를 동적으로 변경하여 진동, 소음, 모터 부하를 줄이기 위해 생성되는 이동 궤적입니다.
다이나믹셀 서보는 3가지 Profile Type을 제공합니다.

![](/img/dxl/model_reference/common/profile_types.webp)

Profile은 일반적으로 [Profile Velocity(112)]와 [Profile Acceleration(108)]의 조합에 따라 선택됩니다.

새 [Goal Position(116)]이 주어지면 다이나믹셀의 Profile Configuration은 현재 이동 속도를 기반으로 목표 속도 궤적을 생성합니다.
다이나믹셀이 이전 [Goal Position(116)]으로 이동 중일 때 새로운 [Goal Position(116)]을 받으면, 새로운 목표 속도 궤적에 맞게 속도가 부드럽게 조정됩니다.
다음은 Current-based Position Control Mode, Position Control Mode, Extended Position Control Mode에서 Profile이 [Goal Position(116)] Instruction을 처리하는 방식입니다.

1. 사용자 Instruction이 다이나믹셀 버스를 통해 전달되어 [Goal Position(116)]에 등록됩니다(Velocity-based Profile이 선택된 경우).
2. [Profile Velocity(112)]와 [Profile Acceleration(108)]을 기반으로 가속 시간(t1)이 계산됩니다.
3. [Profile Velocity(112)], [Profile Acceleration(108)], 총 이동 거리(ΔPos, 목표 위치와 현재 위치의 차이)를 기반으로 Profile Type이 결정됩니다.
4. 선택된 Profile Type은 [Moving Status(123)]에 저장됩니다.
5. 다이나믹셀은 Profile에서 계산된 목표 궤적에 따라 구동됩니다.
6. Profile의 목표 속도 궤적과 목표 위치 궤적은 각각 [Velocity Trajectory(136)]와 [Position Trajectory(140)]에 저장됩니다.

| 조건                                                | Profile Type                         |
|:---------------------------------------------------------|:-----------------------------------------|
| V<sub>PRFL</sub>(112) = 0                                | Profile Not Used<br />(Step Instruction) |
| (V<sub>PRFL</sub>(112) ≠ 0) & (A<sub>PRF</sub>(108) = 0) | Rectangular Profile                      |
| (V<sub>PRFL</sub>(112) ≠ 0) & (A<sub>PRF</sub>(108) ≠ 0) | Trapezoidal Profile                      |

![](/img/dxl/model_reference/common/velocity_profile.webp)

:::note

**참고** : Velocity Control Mode에서는 [Profile Acceleration(108)](#profile-acceleration108)만 사용합니다. Step과 Trapezoidal Profile이 지원됩니다. 가속 시간(t1)은 아래 식으로 계산할 수 있습니다.

**Velocity-based Profile** : t<sub>1</sub> = 64 * \{[Profile Velocity(112)](#profile-velocity112) / [Profile Acceleration(108)](#profile-acceleration108)\}
**Time-based Profile** : t<sub>1</sub> = [Profile Acceleration(108)](#profile-acceleration108)

:::

:::note

**참고** : Time-based Profile이 선택되면 [Profile Velocity(112)](#profile-velocity112)는 Profile 총 시간(t<sub>3</sub>)을 설정하고, [Profile Acceleration(108)](#profile-acceleration108)는 허용 가속 시간(t<sub>1</sub>)을 millisecond[ms] 단위로 설정합니다. [Profile Acceleration(108)](#profile-acceleration108)은 설정된 [Profile Velocity(112)](#profile-velocity112) 값의 50%를 초과하지 않습니다.

:::
