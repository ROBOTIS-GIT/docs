[Drive Mode(10)]가 **Velocity-based Profile**인 경우 Profile Acceleration(108)은 생성되는 Profile의 최대 허용 가속도를 설정합니다.
[Drive Mode(10)]가 **Time-based Profile**인 경우 Profile Acceleration(108)은 생성되는 Profile의 허용 가속 시간을 설정합니다.
Profile Acceleration(108)은 **Current Control Mode**와 **PWM Control Mode**를 제외한 모든 제어 모드에서 사용됩니다.

 자세한 내용은 [What is the Profile](#what-is-the-profile)을 참고하세요.

| Velocity-based Profile |            값             | 설명                             |
|:----------------------:|:-----------------------------:|:----------------------------------------|
|          Unit          | 214.577 [rev/min<sup>2</sup>] | Sets maximum acceleration of the Profile        |
|         Range          |           0 ~ 32767           | '0' represents an infinite maximum acceleration |

| Time-based Profile |  값   | 설명                                                                                                                                                                                           |
|:------------------:|:---------:|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|        Unit        | 1 [msec]  | Sets allowed acceleration time of the Profile                                                                                                                                                                 |
|       범위        | 0 ~ 32737 | `0`은 무한대 가속 시간(`0 [msec]`)을 의미합니다.<br />Profile Acceleration(108)은 설정된 Profile Velocity(112) 값의 50%를 초과할 수 없습니다. |


:::note

**참고** : Time-based Profile은 firmware version 42부터 사용할 수 있습니다.

:::
