Moving Threshold(24)는 DYNAMIXEL이 이동 중인지 판단하는 기준값입니다. [Present Velocity(128)]의 절대값이 설정된 Moving Threshold(24)보다 크면 DYNAMIXEL은 이동 중으로 판단되고 [Moving(122)] 값은 `1`로 설정됩니다.

|      단위       |   범위   |                    설명                    |
|:---------------:|:---------:|:-------------------------------------------------:|
| about 0.229 rpm | 0 ~ 1,023 | All velocity related Data uses the same unit scale|
