<a id="normal-horn-assembly"></a>
### 노멀 혼 조립하기
기본 DYNAMIXEL output horn은 DYNAMIXEL 서보 전면 케이스의 output shaft에 장착하며, 액추에이터의 출력을 프레임이나 기타 액세서리에 연결할 때 사용합니다.

![Horn_Assembly](/img/dxl/model_reference/x_series/hn12-n101_assembly.webp)

:::warning

**주의** : thrust washer를 output shaft에 올바르게 맞춰 조립하세요. 제대로 정렬하지 않으면 장착된 horn에 의해 thrust washer가 손상될 수 있습니다.
  ![HowTo_Thrust_Washer](/img/dxl/model_reference/x_series/thrust_washer_02.webp)

:::

:::note

**참고** : output horn의 index mark가 output shaft의 index mark와 일치하도록 정렬하세요.<br />
  ![Horn_Marking](/img/dxl/model_reference/x_series/horn_assembly_marking.webp)

:::

<a id="idler-horn-assembly"></a>
### 아이들러 혼 조립하기
힌지 프레임 액세서리를 설치하려면 DYNAMIXEL의 output horn과 함께 idler horn이 필요합니다.

또한 장착된 idler horn의 hollow shaft를 통해 케이블을 깔끔하게 배선할 수 있습니다.

<a id="idler-horn-disassembly"></a>
#### 아이들러 혼 분해하기
장착된 idler horn을 분리하려면 back case 뒷면에 있는 버튼을 누르고 측면 hook을 부드럽게 들어 올려 idler를 분리하세요.
