[Drive Mode(10)]가 **Velocity-based Profile**인 경우 Profile Acceleration(108)은 Profile의 가속도를 설정합니다.
[Drive Mode(10)]가 **Time-based Profile**인 경우 Profile Acceleration(108)은 Profile의 가속 시간을 설정합니다.
Profile Acceleration(108)은 [Operating Mode(11)]에서 **Current Control Mode**와 **PWM Control Mode**를 제외한 모든 Control Mode에 적용됩니다.

자세한 내용은 [Profile이란?](#what-is-the-profile)을 참고하세요.

| Velocity-based Profile |             값                | 설명                                  |
|:----------------------:|:-----------------------------:|:----------------------------------------|
|          Unit          | 214.577 [rev/min<sup>2</sup>] | Profile의 가속도를 설정합니다        |
|         Range          |           0 ~ 32767           | '0'은 무한대 가속도를 의미합니다 |

| Time-based Profile |    값     | 설명                                                                                                                                                                                                                                       |
|:------------------:|:---------:|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
|        Unit        | 1 [msec]  | Profile의 가속 시간을 설정합니다                                                                                                                                                                                                              |
|       Range        | 0 ~ 32737 | '0'은 가속 시간이 '0 [msec]'인 무한대 가속도를 의미합니다.<br />Profile Acceleration(108, 가속 시간)은 Profile Velocity(112, Profile 도달 시간) 값의 50%를 초과하지 않습니다.                                |

:::note

**참고** : Time-based Profile은 펌웨어 버전 42부터 지원합니다.

:::
