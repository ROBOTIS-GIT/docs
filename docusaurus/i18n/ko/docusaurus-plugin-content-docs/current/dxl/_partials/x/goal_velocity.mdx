Goal Velocity(104)는 [Operating Mode(11)]가 **Velocity Control Mode**일 때 목표 속도를 설정하는 데 사용됩니다. Goal Velocity(104)는 어떤 Operating Mode에서도 이동 속도 제한값으로 사용되지 않습니다.

|   단위    |                 값 범위                  |
|:---------:|:--------------------------------------------:|
| 0.229 rpm | -[Velocity Limit(44)] ~ [Velocity Limit(44)] |


:::note

**참고** : Goal Velocity(104)는 설정된 [Velocity Limit(44)]를 초과할 수 없습니다.

:::


:::note

**참고** : DYNAMIXEL의 최대 속도와 최대 토크는 공급 전압의 영향을 받습니다. 입력 전압이 변경되면 최대 속도와 최대 토크도 함께 변경됩니다. 이 매뉴얼은 권장 입력 전압에서 동작하는 것을 기준으로 합니다.

:::


:::note

**참고** : [Profile Acceleration(108)]과 Goal Velocity(104)를 동시에 변경하면 새로 변경된 [Profile Acceleration(108)]이 갱신된 Goal Velocity(104)를 처리하는 데 사용됩니다.
