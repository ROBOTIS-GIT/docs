DYNAMIXEL 액추에이터에 할당되는 ID는 DYNAMIXEL 네트워크에서 특정 액추에이터를 식별하는 고유 값입니다. 0 ~ 253(0xFD)을 ID로 할당할 수 있으며, 254(0xFE)는 연결된 모든 DYNAMIXEL 서보에 동시에 Instruction Packet을 전송하는 Broadcast ID로 예약되어 있습니다.


:::note

**참고** : 하나의 네트워크에 연결된 모든 DYNAMIXEL의 ID는 고유해야 합니다. 같은 ID를 공유하면 통신 오류가 발생할 수 있습니다.

:::


:::note

**참고** : Instruction Packet ID가 Broadcast ID(0xFE)로 설정되면 Status Return Level(68) 설정과 관계없이 READ 또는 WRITE Instruction에 대한 Status Packet이 반환되지 않습니다. 자세한 내용은 [DYNAMIXEL Protocol 2.0] eManual 페이지의 `Status Packet`을 참고하세요.

:::
