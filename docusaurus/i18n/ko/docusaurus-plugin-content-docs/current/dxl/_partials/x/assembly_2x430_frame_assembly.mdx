<a id="how-to-use-spacer-ring"></a>
### 스페이서 링 사용 방법
조립 중 프레임 손상을 방지하려면 포함된 스페이서 링을 사용해 조립된 프레임과 DYNAMIXEL 케이스 사이의 간격을 채우세요.

![HowTo_SpacerRing](/img/dxl/model_reference/x_series/howto_spacering.webp)

:::note

**참고** : 스페이서 링은 모든 DYNAMIXEL 액추에이터 모델에서 같은 방식으로 설치합니다.

:::

<a id="frame-and-horn-assembly-precautions"></a>
### 프레임과 혼 조립 시 주의사항
:::warning

**주의** : DYNAMIXEL 액세서리를 조립하기 전에 DYNAMIXEL 장착부의 깊이를 고려하여 모든 나사와 볼트의 길이가 올바른지 확인하세요.
나사 길이가 장착부 깊이보다 길면 조립 중 프레임 또는 DYNAMIXEL이 손상될 수 있습니다.

:::

![Warn_HornAssembly](/img/dxl/model_reference/x_series/xl_xc430_warning.webp)
> Model: XL430-W250

:::note

**참고** : DYNAMIXEL 서보 장착부의 크기와 깊이는 제품 eManual 페이지의 [Drawings](#drawings) 섹션에서 확인할 수 있습니다.

:::

<a id="hinge-frame-assembly"></a>
### 힌지 프레임 조립하기
DYNAMIXEL 힌지 프레임은 서보의 idler와 output horn에 장착해 조립합니다.

![Hinge_Assembly](/img/dxl/model_reference/x_series/2x430_fr12-h101k.webp)

> FR12-H101K

![Hinge_Assembly](/img/dxl/model_reference/x_series/2x430_fr12-h104k.webp)

> FR12-H104K

![Hinge_Assembly](/img/dxl/model_reference/x_series/2x430_fr12-h103gm.webp)

> FR12-H103GM

:::note

**참고** : DYNAMIXEL 서보 장착부의 크기와 깊이는 제품 eManual 페이지의 [Drawings](#drawings) 섹션에서 확인할 수 있습니다.

:::

:::note

**참고** : DYNAMIXEL 힌지 프레임을 설치하려면 idler horn이 필요합니다. 자세한 내용은 [Idler Horn Assembly](#idler-horn-assembly) 안내를 참고하세요.

:::

:::warning

**주의** : 힌지 조립 중에는 설치 전에 모든 나사의 길이가 적절한지 확인하세요. 자세한 내용은 [Frame and Horn Assembly Precautions](#frame-and-horn-assembly-precautions)를 참고하세요.

:::
