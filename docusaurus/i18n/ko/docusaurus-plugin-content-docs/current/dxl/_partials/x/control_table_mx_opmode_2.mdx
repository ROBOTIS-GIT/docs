
|   Value    |                  Operating Mode                  | 설명 |
|:----------:|:------------------------------------------------:|:-----|
|     1      |  Velocity Control Mode<br />(0&deg; ~ 360&deg;)  | 속도를 제어하는 모드이며 휠 구동에 적합합니다.<br />기존 DYNAMIXEL의 Wheel Mode(endless)와 동일합니다. |
| 3(Default) |              Position Control Mode               | 위치를 제어하는 모드이며 Joint Mode와 동일합니다.<br />동작 위치 범위는 Max Position Limit(48)와 Min Position Limit(52)로 제한됩니다.<br />각 관절이 360&deg; 미만으로 회전하는 관절형 로봇에 적합합니다. |
|     4      | Extended Position Control Mode<br />(Multi-turn) | 위치를 제어하는 모드이며 Multi-turn Mode와 동일합니다.<br />512회전(-256[rev] ~ 256[rev])을 지원하며, 여러 바퀴를 회전하는 손목 관절, 컨베이어 시스템 또는 추가 감속기가 필요한 시스템에 적합합니다. |
|     16     |   PWM Control Mode<br />(Voltage Control Mode)   | PWM 출력을 직접 제어하는 모드입니다(Voltage Control Mode). |

:::note

**참고** : Operating Mode를 변경하면 선택된 Operating Mode에 맞게 Gain(PID, Feedforward)이 초기화됩니다. Profile generator와 제한값도 함께 초기화됩니다.
1. [Profile Velocity(112)](#profile-velocity112), [Profile Acceleration(108)](#profile-acceleration108) : `0`으로 초기화
2. [Goal PWM(100)](#goal-pwm100) : [PWM Limit(36)](#pwm-limit36) 값으로 초기화

:::

:::note

**참고** : PWM은 Pulse Width Modulation의 약자로, PWM Duty를 변조하여 모터를 제어합니다.
펄스 폭을 변경해 모터에 공급되는 평균 전압을 제어하며, 모터 제어 분야에서 널리 사용됩니다.
1. PWM Control Mode는 DYNAMIXEL [AX](/docs/dxl/model_reference/ax_series/ax-12w#cw-compliance-margin) 및 [RX](/docs/dxl/model_reference/rx_series/rx-10#moving-speed-32) 시리즈의 Wheel Mode와 유사합니다.
2. PWM Control Mode에서는 [Goal PWM(100)](#goal-pwm100)을 사용해 DYNAMIXEL에 공급되는 전압을 제어합니다.

:::
