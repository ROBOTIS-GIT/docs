PWM Limit(36)는 허용 가능한 최대 PWM 출력을 설정하는 데 사용됩니다. [Goal PWM(100)]은 [PWM Limit(36)]을 초과하는 값으로 설정할 수 없습니다. 또한 [PWM Limit(36)]은 모든 Operating Mode에서 모터의 최종 출력 PWM에 대한 절대 제한값으로 사용됩니다. 자세한 내용은 각 Operating Mode의 Gain 섹션을 참고하세요.

|      단위       |          Range           |
|:---------------:|:------------------------:|
| about 0.113 [%] | 0(0 [%]) ~ 885(100 [%] ) |
