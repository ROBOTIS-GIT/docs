LED(65)는 DYNAMIXEL 액추에이터 뒷면에 있는 indicator LED의 상태를 제어합니다.

|    Bit     | 설명      |
|:----------:|:-----------------|
| 0(Default) | LED를 끕니다. |
|     1      | LED를 켭니다. |


:::note

**참고** : 장치의 상태에 따른 LED 동작입니다.

|     상태     | LED 동작 |
|:------------:|:--------:|
|     부팅     | 1회 점멸 |
| 공장 초기화  | 4회 점멸 |
|     알람     |   점멸   |
|  부트 모드   |   점등   |

:::
