:::

> XW540 시리즈 커넥터

![](/img/dxl/model_reference/x_series/xw_series/xw_series_485_pin_connector.png)

> 방진·방수 데이터 케이블


DYNAMIXEL 전원은 Pin1(-), Pin2(+)를 통해 공급됩니다.
(위 회로는 DYNAMIXEL 컨트롤러 내부에만 포함됩니다.)
위 회로도에서 TTL Level의 TxD 및 RxD 데이터 신호 방향은 DIRECTION 485 Level에 따라 다음과 같이 결정됩니다.
DIRECTION485 Level = High인 경우: TxD 신호가 D+와 D-로 출력됩니다.
DIRECTION485 Level = Low인 경우: D+와 D-의 신호가 RxD로 출력됩니다.
