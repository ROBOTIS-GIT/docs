Min/Max Position Limit(48, 52)는 Position Control Mode에서 1회전(0 ~ 4,095) 내 최대 이동 범위를 설정하는 데 사용됩니다.
입력되는 [Goal Position(116)] 값은 설정된 Position Limit 범위 안에 있어야 합니다.

|     단위      |      값 범위      |
|:-------------:|:---------------------:|
| 0.088 [&deg;] | 0 ~ 4,095(1 rotation) |


:::warning

**참고** : Max Position Limit(48)와 Min Position Limit(52)는 1회전 내 Position Control Mode에서만 사용됩니다.
이 컨트롤 테이블 항목으로 설정한 각도 제한은 Extended Position Control Mode에서는 적용되지 않습니다.

:::
