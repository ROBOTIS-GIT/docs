값이 6(4M bps)까지이고 4.5M 항목이 없으며, 115,200 / 57,600 은 오차율이 별도로 표기됩니다.

Baud Rate(8)는 컨트롤러와 DYNAMIXEL 사이의 시리얼 통신 속도를 결정합니다.


|   Value    |   Baud Rate   | Margin of Error |
|:----------:|:-------------:|:---------------:|
|     6      |   4M [bps]    |    0.000 [%]    |
|     5      |   3M [bps]    |    0.000 [%]    |
|     4      |   2M [bps]    |    0.000 [%]    |
|     3      |   1M [bps]    |    0.000 [%]    |
|     2      | 115,200 [bps] |   0.0064 [%]    |
| 1(Default) | 57,600 [bps]  |   0.0016 [%]    |
|     0      |  9,600 [bps]  |    0.000 [%]    |


:::note

**참고** : Baud rate 오차율이 3% 미만이면 UART 통신에 영향을 주지 않습니다.

:::


:::note

**참고** : U2D2로 높은 Baudrate에서 안정적으로 통신하려면 USB Latency 값을 낮게 설정하세요.
[USB Latency Setting](/docs/software/dynamixel_wizard_2_0/advanced_features#usb-latency-setting)

:::
