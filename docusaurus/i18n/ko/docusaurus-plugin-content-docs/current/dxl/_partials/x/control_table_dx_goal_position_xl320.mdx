Goal Position(30)을 통해 DYNAMIXEL의 목표 위치를 설정합니다.
사용 가능한 위치 범위는 0 ~ 1,023(0x3FF)이며 단위값은 0.29&deg;입니다.
Goal Position(30)이 [CW/CCW Angle Limit(6, 8)](#cwccw-angle-limit6-8)를 벗어나도록 설정되면 Status Packet은 ERROR 필드로 Angle Limit Error Bit(0x01)를 전송합니다. 이때 [Shutdown(18)](#shutdown)에 Angle Limit Error Bit(0x01)가 설정되어 있으면 Alarm LED가 점멸하고 모터 출력은 0[%]가 됩니다.

> 위 그림은 DYNAMIXEL을 정면에서 본 모습입니다.


:::note

**참고** : Wheel Mode로 설정하면 Goal Position 값은 사용되지 않습니다.

:::
