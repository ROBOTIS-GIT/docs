Present Load는 모터 출력에 적용되는 현재 부하의 추정값을 나타냅니다.

| Unit  | 값 범위   | 설명 |
| :---: | :-----------: | :---: |
| 0.1%  | -1,000 ~ 1,000| Positive(CCW Load), Negative(CW Load) |


:::note

**참고** : Present Load는 내부 출력값을 기반으로 추정한 값이며 토크 센서 등으로 직접 측정한 값이 아닙니다. 따라서 무게나 토크를 정밀하게 측정하는 용도로는 부정확할 수 있습니다. 서보에 가해지는 힘의 방향과 크기를 예측하고 모니터링하는 용도로만 사용하는 것을 권장합니다.

:::
