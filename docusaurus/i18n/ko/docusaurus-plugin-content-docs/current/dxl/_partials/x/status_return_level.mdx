Status Return Level(68)은 Instruction Packet을 수신했을 때 DYNAMIXEL의 응답 정책을 설정합니다.

| Value |        응답하는 Instruction         |                       설명                       |
|:-----:|:--------------------------------------:|:-------------------------------------------------------:|
|   0   |            PING Instruction            |   Returns a Status Packet for PING Instructions only   |
|   1   | PING Instruction<br />READ Instruction | Returns a Status Packet for PING and READ Instructions |
|   2   |            All Instructions            |     Returns a Status Packet for all Instructions      |


:::note

**참고** : [Instruction Packet ID](/docs/dxl/protocol/protocol2)가 [Broadcast ID(0xFE)](/docs/dxl/protocol/protocol2#packet-id)로 설정되면 Status Return Level(68)과 관계없이 READ 또는 WRITE Instruction에 대해 Status Packet이 반환되지 않습니다. 자세한 내용은 [DYNAMIXEL Protocol 2.0] 페이지의 `Status Packet` 섹션을 참고하세요.

:::

[DYNAMIXEL Protocol 2.0]: /docs/dxl/protocol/protocol2
