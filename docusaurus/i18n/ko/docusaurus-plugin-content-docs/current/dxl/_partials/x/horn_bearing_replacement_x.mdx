
## Horn and Gear Replacement
Horn은 DYNAMIXEL 전면의 wheel gear serration에 장착되며, Bearing Set은 후면에 장착됩니다.

### Installing the Horn

Horn을 설치할 때는 Horn과 wheel gear serration의 정렬 표시를 주의 깊게 맞추세요.

![](/img/dxl/model_reference/x_series/xw_series/x430_marking.webp)

정렬이 올바르게 완료되면 Horn 중앙을 액추에이터 방향으로 부드럽게 눌러 장착합니다.

### Gear Replacement
DYNAMIXEL 내부 기어가 손상되거나 마모된 경우 좋은 상태를 유지하기 위해 DYNAMIXEL의 기어를 교체하세요.

기어를 올바르게 교체하는 방법은 다음 영상을 참고하세요.

<iframe width="560" height="315" src="https://www.youtube.com/embed/wKxcZNMrrCQ" frameborder="0" allow="autoplay; encrypted-media" allowfullscreen></iframe>

### DYNAMIXEL Calibration
기어 교체 후 기어 위치를 올바르게 맞추기 위해 DYNAMIXEL을 캘리브레이션하세요.

소프트웨어를 사용해 DYNAMIXEL을 올바르게 캘리브레이션하는 방법은 다음 영상을 참고하세요.

<iframe width="560" height="315" src="https://www.youtube.com/embed/uK--PBy88Mo" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowfullscreen></iframe>

:::note

**참고**:
- USB2Dynamixel이 단종되었으므로, 영상의 소프트웨어를 PC에서 사용해 DYNAMIXEL과 통신하려면 [U2D2](/docs/parts/interface/u2d2)가 필요합니다.
- 영상에서 사용하는 R+ Manager 2.0 대신 [DYNAMIXEL Wizard 2.0](/docs/software/dynamixel_wizard_2_0/advanced_features#calibration)을 사용해 DYNAMIXEL(X / MX 전용)을 캘리브레이션할 수도 있습니다.

:::
