[Reg Write Instruction](/docs/dxl/protocol/protocol2#reg-write-0x04)에 의해 Instruction이 등록되어 실행 준비가 되었는지 나타냅니다. 등록된 Action이 실행되면 Registered Instruction(69) 값은 자동으로 0으로 갱신됩니다.

| Value | 설명                                  |
|:-----:|:---------------------------------------------|
|   0   | No instruction registered by REG_WRITE.      |
|   1   | Instruction registered by REG_WRITE. |
