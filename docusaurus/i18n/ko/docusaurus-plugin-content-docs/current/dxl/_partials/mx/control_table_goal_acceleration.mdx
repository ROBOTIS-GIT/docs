목표 가속도 값입니다. 0 ~ 254(0xFE)까지 사용할 수 있으며, 단위는 약 8.583 [&deg;] / sec<sup>2</sup>입니다.
0으로 설정하면 가속도를 제어하지 않고 모터의 최대 가속도로 움직인다는 의미입니다.
목표 속도가 0일 경우에도 가속도를 제어하지 않고 모터의 최대 가속도로 움직입니다.
254로 설정하면 2,180 [&deg;] / sec<sup>2</sup>가 됩니다.
예를 들어, 현재 다이나믹셀의 속도가 0이고 Goal Acceleration이 10인 경우 1초 뒤 다이나믹셀의 속도는 14.3 [RPM]이 됩니다.
