Baud Rate는 제어기와 다이나믹셀 사이의 시리얼 통신 속도를 결정합니다.
사용 가능한 값의 범위는 0 ~ 254(0xFE)이며, BPS 계산식은 다음과 같습니다.
**Baudrate(BPS) = 2,000,000 / (Value + 1)**

|    값    | Baud Rate(bps) | 오차율 |
|:-----------:|:--------------:|:---------------:|
|      0      |       2M       |    0.000 [%]    |
|      1      |       1M       |    0.000 [%]    |
|      3      |    500,000     |    0.000 [%]    |
|      4      |    400,000     |    0.000 [%]    |
|      7      |    250,000     |    0.000 [%]    |
|      9      |    200,000     |    0.000 [%]    |
|     16      |     115200     |    -2.124 [%]   |
| 34(Default) |     57600      |    0.794 [%]    |
|     103     |     19200      |    -0.160 [%]   |
|     207     |      9600      |    -0.160 [%]   |

:::note

**참고** : Baud Rate 오차가 3 [%] 이내이면 UART 통신에 영향을 주지 않습니다.

:::

:::note

**참고** : 높은 Baud Rate에서 안정적으로 통신하려면 USB Latency 값을 낮게 설정하세요.
[USB Latency 설정](/docs/software/dynamixel_wizard_2_0/advanced_features#usb-latency-setting)

:::
