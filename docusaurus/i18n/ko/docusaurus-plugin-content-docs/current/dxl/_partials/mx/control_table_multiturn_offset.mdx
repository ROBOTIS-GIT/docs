Offset 위치를 조정합니다. 이 Offset 값은 [Present Position(36)](#present-position)에 더해집니다.
초기값은 0이며 범위는 -24,576 ~ 24,576입니다.
Present Position이 2,048인 DYNAMIXEL에 Offset 1,024를 적용하면 조정된 Present Position은 3,072가 됩니다.
