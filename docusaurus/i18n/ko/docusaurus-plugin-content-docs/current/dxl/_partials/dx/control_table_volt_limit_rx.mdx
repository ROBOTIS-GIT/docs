동작 전압 범위입니다.

| 단위 | 값의 범위 | 설명 |
|:----------:|:-----------:|:-----------:|
| 약 0.1V |   50 ~ 250  | 5.0 ~ 25.0V |

예를 들어, 값이 80이면 전압은 8V입니다.
[Present Voltage(42)]가 설정 범위를 벗어나면 Status Packet의 Voltage Range Error Bit(Bit0)가 `1`로 반환되고, 17번과 18번 Address 설정에 따라 Alarm이 발생합니다.
