Goal Velocity(600)는 목표 속도를 설정할 때 사용하며, 이 값은 Velocity Limit(32)을 초과할 수 없습니다.
Position Control Mode 또는 Extended Position Control Mode에서는 Goal Velocity가 속도 제한값으로 사용됩니다.
단, Goal Velocity가 `0`으로 설정되면 Velocity Limit(32)가 속도 제한값으로 사용됩니다. Position P Gain의 블록 다이어그램을 참고하세요.
Goal Velocity는 감속기 전 모터 RPM을 의미하며, 감속기 후 출력 RPM은 아래 scale factor를 사용해 계산할 수 있습니다.
출력 RPM = Goal Velocity * Scale Factor
