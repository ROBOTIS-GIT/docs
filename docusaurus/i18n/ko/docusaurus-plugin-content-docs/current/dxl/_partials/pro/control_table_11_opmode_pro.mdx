| 값      | Operating Mode                 | 설명                                                                |
|:-----------|:-------------------------------|:---------------------------------------------------------------------------|
| 0          | Torque Control Mode            | Torque만 제어합니다. 속도와 위치는 제어하지 않습니다. |
| 1          | Velocity Control Mode          | 속도와 Torque를 제어합니다. 위치는 제어하지 않습니다.   |
| 3(Default) | Position Control Mode          | 위치, 속도, Torque를 제어합니다.                          |
| 4          | Extended Position Control Mode | 위치, 속도, Torque를 제어합니다. Multi-turn is enabled.   |
