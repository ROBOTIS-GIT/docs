이 값들은 Velocity Control Mode의 P Gain과 I Gain을 나타냅니다. I Gain에는 샘플링 시간이 포함됩니다. DYNAMIXEL 내부 제어기의 Velocity P Gain은 K<sub>V</sub>P, Velocity I Gain은 K<sub>V</sub>I로 표기합니다.

|Gain 값 범위|
| :---: |
