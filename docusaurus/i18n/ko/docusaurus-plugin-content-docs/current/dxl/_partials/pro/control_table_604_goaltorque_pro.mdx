Goal Torque(604)는 목표 Torque를 설정할 때 사용하며, 이 값은 Torque Limit(30)을 초과할 수 없습니다.
Operating Mode(11)가 Torque Control Mode가 아닌 경우 Goal Torque는 Torque를 제한하는 데 사용됩니다.
단, Goal Torque가 `0`으로 설정되면 Torque Limit(30)이 Torque Limit으로 사용됩니다. Position Gain 또는 Velocity Gain의 블록 다이어그램을 참고하세요.
