| 값 | 설명                                  |
|:-----:|:---------------------------------------------|
|   0   | REG_WRITE로 등록된 Instruction이 없습니다.      |
|   1   | REG_WRITE로 등록된 Instruction이 있습니다. |


:::note

**참고** : ACTION Instruction이 실행되면 Registered Instruction(517)은 0으로 변경됩니다.

:::


:::warning

**경고** :  Modbus-RTU는 Registered Instruction(517)을 지원하지 않습니다.

:::
