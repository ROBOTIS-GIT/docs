### 베어링 수명
DYNAMIXEL-Y 출력부의 베어링 수명은 다음 식으로 결정할 수 있습니다.

![](/img/dxl/model_reference/y_series/m_1.webp)

- L<sub>10</sub> - 베어링 수명 [hour]
- N<sub>a</sub> - 평균 출력 속도 [rpm]
- C - 기본 동정격 하중 [N]
- P<sub>c</sub> - 동등가 동하중 [N]
- T<sub>f</sub> - 온도 계수 (Tf=1.0, 100℃ 이하)
- L<sub>f</sub> - 하중 계수 (Table.B2)

### 허용 동등가 하중, Pc_max

![](/img/dxl/model_reference/y_series/m_2.webp)

- L<sub>10</sub> - 베어링 수명 [hour] @ 20,000 hour
- N<sub>n</sub> - 공칭 출력 속도 [rpm]
- C - 기본 동정격 하중 [N]
- T<sub>f</sub> - 온도 계수 (Tf=1.0, 100℃ 이하) @ Tf = 1.0
- L<sub>f</sub> - 하중 계수 (Table.B2) @ Lf=1.0
- P<sub>c_max</sub> - 허용 동등가 동하중 [N]

- L<sub>r</sub> - 레이디얼 하중 거리 [m]
