[Control Table Backup Packet](/docs/dxl/protocol/protocol2#control-table-backup-0x20)을 통해 저장된 컨트롤 테이블 Backup 데이터의 유무를 나타냅니다.

| 값 | 상세 설명                            |
|:--:|:-------------------------------------|
| 0  | Backup된 컨트롤 테이블 데이터가 없음 |
| 1  | Backup된 컨트롤 테이블 데이터가 있음 |

**참고**: 사용 방법은 [Backup and Restore](/docs/software/dynamixel_wizard_2_0/advanced_features#backup-and-restore)를 참고하세요.
