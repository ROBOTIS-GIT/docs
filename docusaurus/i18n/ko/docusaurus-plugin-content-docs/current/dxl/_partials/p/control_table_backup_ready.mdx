이 Address의 값은 [Control Table Backup Packet](/docs/dxl/protocol/protocol2#control-table-backup-0x20)을 전송한 후 컨트롤 테이블의 백업 데이터가 존재하는지 나타냅니다.

| Value | 설명                    |
|:-----:|:-------------------------------|
|   0   | 백업 데이터가 없습니다.       |
|   1   | 저장된 백업 데이터가 있습니다. |


:::note

**참고**
Backup Ready는 펌웨어 **V12**부터 사용할 수 있습니다.
자세한 내용은 [Backup and Restore](/docs/software/dynamixel_wizard_2_0/advanced_features#backup-and-restore)를 참고하세요.

:::
