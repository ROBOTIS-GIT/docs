#### PWM Slope Example

PWM Slope(62)의 설정값이 '255' (equal to 1,008.47 [mV/msec]), and the value of [Goal PWM(100)] is changed from '0' to '885' on PWM Mode (at 12V), the reaching time when the [Present PWM(124)] value reaches to '885' from '0' is going to be 12 [msec] by the following calculation formula: 12,000 [mV]/1,008.47 [mV/msec] = 11.90 [msec].
