T/R/AT/AR은 사용하는 프로토콜 타입을 나타냅니다:

- T: TTL.
- R: RS485.
- AT/AR: 알루미늄 프론트 케이스 적용.

### MX 시리즈 (2.0)


:::note

**참고**: MX(2.0)은 DYNAMIXEL Protocol 2.0을 지원하는 DYNAMIXEL MX 시리즈의 별도 Firmware입니다. DYNAMIXEL Wizard 2.0의 [Firmware Recovery](/docs/software/dynamixel_wizard_2_0/introduction)를 사용하여 Protocol 1.0에서 MX(2.0) Firmware로 업그레이드할 수 있습니다.

:::


- [MX-106T/R(2.0)](/docs/dxl/model_reference/mx_series/mx-106-2)

- [MX-28T/R/AT/AR(2.0)](/docs/dxl/model_reference/mx_series/mx-28-2)


:::note

**참고**: MX(2.0)은 다양한 Operating Mode, Secondary ID, Drive Mode, Bus Watchdog 등의 기능을 지원합니다.
