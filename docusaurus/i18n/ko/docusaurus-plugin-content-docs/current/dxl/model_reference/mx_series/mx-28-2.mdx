## 주요 사양

| 항목                   | 사양                                                                                                                                                                                |
|:-----------------------|:----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| MCU                    | ARM CORTEX-M3 (72 [MHz], 32Bit)                                                                                                                                                               |

| 동작 모드        | Velocity Control Mode<br />Position Control Mode(0&deg; ~ 360&deg;)<br />Extended Position Ctrl Mode(Multi-turn)<br />PWM Control Mode                                                         |
| 무게                 | MX-28AR/AT : 77 [g]<br /> MX-28R/T : 72 [g]                                                                                                                                                    |
| 크기 (W x H x D) | 35.6 x 50.6 x 35.5 [mm]                                                                                                                                                                       |
| 기어비             | 193 : 1                                                                                                                                                                                       |
| 정지 Torque           | 2.3 [N.m] (at 11.1 [V], 1.3 [A], 1.769 [Nm/A])<br />2.5 [N.m] (at 12 [V], 1.4 [A], 1.786 [Nm/A])<br />3.1 [N.m] (at 14.8 [V], 1.7 [A], 1.824 [Nm/A])                                            |
| 무부하 속도          | 50 [rev/min] (at 11.1 [V])<br />55 [rev/min] (at 12 [V])<br />67 [rev/min] (at 14.8 [V])                                                                                                       |
| Radial Load            | `1` 30 [N] (10 [mm] away from the horn)                                                                                                                                                       |
| Axial Load             | `1` 15 [N]                                                                                                                                                                                    |
| 동작 온도  | -5 ~ +80 [&deg;C]                                                                                                                                                                             |
| 입력 전압          | 10.0 ~ 14.8 [V] (**권장 : 12.0 [V]**)                                                                                                                                                  |
| 제어 명령         | Digital Packet                                                                                                                                                                                |
| 물리적 연결    | RS-485 / TTL Multidrop Bus <br /> TTL Half Duplex Asynchronous Serial Communication with 8bit, 1stop, No Parity<br />RS-485 Asynchronous Serial Communication with 8bit, 1stop, No Parity   |
| ID                     | 253 ID (0 ~ 252)                                                                                                                                                                              |
| Feedback               | Position, Velocity, Temperature, Load, Input Voltage, Trajectory, Realtime Tick, etc                                                                                                          |

| 기어 재질          | Full Metal Gear                                                                                                                                                                               |
| 대기 전류        | 100 [mA]                                                                                                                                                                                      |
