# MX-106R, MX-106T

<MxNotice />

:::note

**참고** : MX-106T(TTL)와 MX-106R(RS-485)는 통신 방식만 다르며 동일한 기능과 성능을 제공합니다. TTL은 3핀 커넥터를, RS-485는 4핀 커넥터를 사용합니다.

:::

:::warning

**경고** : MX-106(2.0) Protocol은 컨트롤 테이블이 다르므로 [MX-106(2.0) Control Table](./mx-106-2#control-table)을 참고하세요.

:::

<a id="moving-speed"></a>
#### Moving Speed (32)

- Join Mode, Multi-Turn mode

  Goal Position으로 이동하는 속도입니다.
  0 ~ 1,023(0x3FF)까지 사용할 수 있으며, 단위는 약 0.114rpm입니다.
  0으로 설정하면 속도 제어를 하지 않고 모터의 최대 rpm을 사용한다는 의미입니다.
  1023으로 설정하면 약 116.62rpm입니다.
  예를 들어 300으로 설정하면 약 34.2rpm입니다.
  단, rpm은 No Load Speed를 초과하지 않습니다.

- Wheel Mode

  Goal 방향으로 이동하는 속도입니다.
  0 ~ 2,047(0x7FF)까지 사용할 수 있으며, 단위는 약 0.114rpm입니다.
  0 ~ 1,023 범위의 값을 사용하면 CCW 방향으로 회전하며, 0으로 설정하면 정지합니다.
  1,024 ~ 2,047 범위의 값을 사용하면 CW 방향으로 회전하며, 1024로 설정하면 정지합니다.
  즉, 10번째 bit가 방향을 제어하는 Direction bit입니다.

  :::note

  **참고** : DYNAMIXEL의 최대 rpm을 확인하세요. Moving Speed 값을 더 높게 설정해도 모터는 최대 rpm을 초과할 수 없습니다.

  :::

#### Present Speed (38)
현재 이동 속도입니다.
0 ~ 2,047(0x000 ~ 0x7FF)까지 사용할 수 있습니다.
값이 0 ~ 1,023 범위이면 모터가 CCW 방향으로 회전합니다.

값의 단위는 약 0.11rpm입니다.
예를 들어 300으로 설정하면 모터가 CCW 방향으로 약 34.33rpm의 속도로 이동 중이라는 의미입니다.

<a id="current"></a>
#### Current (68)
전류가 흐르지 않는 Idle 상태에서는 이 값이 2,048(0x800)입니다.
양의 전류가 흐르면 이 값은 2,048(0x800)보다 커지고, 음의 전류가 흐르면 2,048(0x800)보다 작아집니다.
전류 계산식은 다음과 같습니다.

I = ( 4.5mA ) * (CURRENT - 2048 )이며 단위는 Ampere(A)입니다.
예를 들어 Address 68의 값이 2148이면 450mA의 전류가 흐른다는 의미입니다.

![](/img/dxl/model_reference/mx_series/mx_current.webp)
<a id="torque-control-mode-enable"></a>
#### Torque Control Mode Enable (70)

| Value | 의미                                                                                 |
|:-----:|:------------------------------------------------------------------------------------:|
|   0   | Torque Mode를 끕니다. Joint Mode 또는 Wheel Mode로 동작합니다                       |
|   1   | Torque Mode를 켭니다. 위치나 이동 속도는 제어할 수 없고 Torque만 제어합니다         |

Torque Control Mode Enable이 1이면 DYNAMIXEL은 다음과 같이 동작합니다.
- DYNAMIXEL은 위치나 속도를 제어하지 않습니다.
- DYNAMIXEL은 Goal Torque 값으로 제어됩니다.
- DYNAMIXEL은 [Goal Position(30)](#goal-position-30), [Moving Speed(32)](#moving-speed-32) 값의 영향을 받지 않습니다.
- 위치/이동 속도를 제어하지 않으므로 Wheel Mode처럼 동작합니다.
<a id="goal-torque"></a>
#### Goal Torque (71)
0 ~ 2,047(0x7FF) 값을 사용할 수 있으며 단위는 4.5mA입니다. (Torque는 전류 값에 비례합니다.)
0 ~ 1,023 범위의 값을 사용하면 CCW 방향으로 Torque가 적용되고, 0으로 설정하면 정지합니다.
1,024 ~ 2,047 범위의 값을 사용하면 CW 방향으로 Torque가 적용되고, 1,024로 설정하면 정지합니다.
즉, 10번째 bit가 회전 방향을 제어하는 CW/CCW Direction bit입니다.
Goal Torque는 Torque Limit(34, 35)보다 클 수 없습니다.
