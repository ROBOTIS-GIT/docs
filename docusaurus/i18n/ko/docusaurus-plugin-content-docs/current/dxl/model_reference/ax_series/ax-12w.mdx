# AX-12W

:::warning

**참고** : XL430-W250은 AX-12를 직접 대체할 수 있는 X 시리즈 다이나믹셀입니다. X 시리즈 서보는 향상된 성능과 추가 기능을 제공하며 DYNAMIXEL Protocol 2.0도 지원합니다. ROBOTIS는 신규 및 기존 AX-12 사용자가 XL430-W250으로 전환하는 것을 권장합니다.

:::

<a id="baud-rate"></a>
#### Baud Rate (4)
Baud Rate는 제어기와 다이나믹셀 사이의 시리얼 통신 속도를 결정합니다.

|   값    | 통신 속도 | 오차율 |
|:----------:|:---------:|:---------------:|
| 1(Default) |    1M     |     0.000%      |
|     3      |  500,000  |     0.000%      |
|     4      |  400,000  |     0.000%      |
|     7      |  250,000  |     0.000%      |
|     9      |  200,000  |     0.000%      |
|     16     |  115200   |     -2.124%     |
|     34     |   57600   |     0.794%      |
|    103     |   19200   |     -0.160%     |
|    207     |   9600    |     -0.160%     |

:::note

**참고** : Baud Rate 오차가 3 [%] 이내이면 UART 통신에 영향을 주지 않습니다.

:::

:::note

**참고** : 높은 Baud Rate에서 안정적으로 통신하려면 USB Latency 값을 낮게 설정하세요.
[USB Latency 설정](/docs/software/dynamixel_wizard_2_0/advanced_features#usb-latency-setting)

:::
