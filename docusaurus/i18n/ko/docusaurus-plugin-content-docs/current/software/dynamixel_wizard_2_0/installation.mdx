# 설치

## 소프트웨어 설치

### Windows에서 설치하기

1. Windows 전용 패키지를 다운로드 합니다.
  - [Windows 소프트웨어 다운로드](http://www.robotis.com/service/download.php?no=1670)
2. 다운받은 설치파일을 실행합니다.

3. 안내에 따라 `Next`버튼을 눌러 설치를 진행합니다.

    ![](/img/software/dynamixel_wizard_2_0/installation/new_wizard2_setup_win_01.png)

    ![](/img/software/dynamixel_wizard_2_0/installation/new_wizard2_setup_win_02.png)



### Linux에서 설치하기

1. Linux 설치패키지를 다운로드합니다.
  - [Linux 소프트웨어 다운로드](http://www.robotis.com/service/download.php?no=1671)
2. 다음의 명령어를 수행하여 설치파일의 실행권한을 변경합니다.

    ```bash
    $ sudo chmod 775 DynamixelWizard2Setup_x64
    ```

3. 설치파일을 실행합니다.

    ```bash
    $ ./DynamixelWizard2Setup_x64
    ```

4. 안내에 따라 `Next`버튼을 눌러 설치를 진행합니다.

5. 설치가 끝난 후, USB 포트에 접근하기 위해 사용자 계정을 dialout 그룹에 추가하세요. (아래 커맨드의 **\<your_account_id>**에 해당 PC에서 사용하는 계정으로 교체 하세요.)

    ```bash
    $ sudo usermod -aG dialout <your_account_id>
    ```

6. Dialout 그룹에 계정 추가를 완료하기위해 시스템을 재부팅 하세요.

    ```bash
    $ reboot
    ```

### Mac에서 설치하기

:::note

**참고**: 최신 MacOS 이용자는, 앱스토어를 통해 DYNAMIXEL Wizard 2.0을 다운로드 하세요.

:::
1. MacOS 설치 패키지를 다운로드 합니다.
  - [Mac 소프트웨어 다운로드](http://www.robotis.com/service/download.php?no=1760)
2. 다운로드가 완료된 dmg 파일을 오른쪽 클릭하고 `Open(열기)`를 선택합니다.
  ![](/img/software/dynamixel_wizard_2_0/installation/wizard2_setup_mac_01.png)
3. `DynamixelWizard2Setup_x64` 파일을 실행합니다.
  ![](/img/software/dynamixel_wizard_2_0/installation/wizard2_setup_mac_02.png)
4. 아래와 같은 경고창이 나타나면 `Open(열기)`를 선택하고 설치를 진행합니다.
  ![](/img/software/dynamixel_wizard_2_0/installation/wizard2_setup_mac_03.png)
5. `Next(다음)`버튼을 누르고 설치과정을 따라 진행합니다.
  ![](/img/software/dynamixel_wizard_2_0/installation/wizard2_setup_mac_04.png)

## 소프트웨어 제거

### Windows에서 제거하기

1. Windows 설정의 앱 및 기능에서 `Dynamixel Wizard 2`를 선택하고 `제거`버튼을 클릭하면 설치마법사가 시작합니다.

2. `Remove all components`를 선택하고 `Next`버튼을 눌러 제거를 진행합니다.

    ![](/img/software/dynamixel_wizard_2_0/installation/wizard2_setup_win_04.png)

### Linux에서 제거하기

1. 설치된 폴더에서 `maintenancetool`을 실행합니다.

2. `Remove all components`를 선택하고 `Next`버튼을 눌러 제거를 진행합니다.

    ![](/img/software/dynamixel_wizard_2_0/installation/wizard2_setup_linux_03.png)

### Mac에서 제거하기

1. 어플리케이션에서 `DYNAMIXEL2Wizard`를 선택합니다.
2. DYNAMIXEL2Wizard 폴더 내의 `maintenancetool`을 실행합니다.
3. `Remove all components`를 선택하고 `Next`버튼을 눌러 제거를 진행합니다.
