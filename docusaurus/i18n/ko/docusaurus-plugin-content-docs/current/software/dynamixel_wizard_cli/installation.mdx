# 설치

## Windows에서 설치하기

1. 터미널(Windows 터미널, PowerShell 또는 명령 프롬프트)을 실행합니다.
2. 다음 명령어를 실행하여 DYNAMIXEL Wizard CLI를 설치합니다.

    ```bash
    winget install wizard-cli
    ```

3. 터미널을 종료한 후 다시 실행하고 `wizard-cli`를 실행합니다.

    ```bash
    wizard-cli
    ```

:::note

설치 후 터미널을 다시 실행해야 `wizard-cli` 명령어가 인식됩니다.

:::

## Linux에서 설치하기

1. 시스템 아키텍처에 맞는 AppImage를 다운로드합니다. 아키텍처는 다음 명령어로 확인할 수 있습니다.

    ```bash
    $ uname -m
    ```

    | 출력 | 아키텍처 | 하드웨어 예시 | 다운로드 |
    |------|----------|---------------|----------|
    | `x86_64` | x86 64비트 | x86 PC | [wizard-cli-x86_64](https://www.robotis.com/service/download.php?no=2273) |
    | `aarch64` | ARM 64비트 | Jetson AGX Orin, Raspberry Pi 5 | [wizard-cli-aarch64](https://www.robotis.com/service/download.php?no=2272) |

2. 다운로드한 AppImage에 실행 권한을 설정합니다. 아래 예시는 x86_64 파일 기준이며, 파일 이름은 다운로드한 파일에 맞게 바꿔 입력합니다.

    ```bash
    $ chmod +x wizard-cli-x86_64.AppImage
    ```

3. AppImage를 실행합니다.

    ```bash
    $ ./wizard-cli-x86_64.AppImage
    ```

:::note

시리얼 포트에 접근하려면 사용자 계정이 `dialout` 그룹에 속해 있어야 합니다. 아래 명령어로 계정을 추가한 후 시스템을 재부팅하면 적용됩니다.

```bash
$ sudo usermod -aG dialout <your_account_id>
```

:::

설치가 끝나면 [기본 사용법](./basic_usage.mdx)을 참고하여 DYNAMIXEL에 연결합니다.
