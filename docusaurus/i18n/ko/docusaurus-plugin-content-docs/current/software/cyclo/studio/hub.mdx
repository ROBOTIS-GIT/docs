## 허브 열기 \{#open-hub}

1. Cyclo Studio에 로그인합니다.
2. 기본 탐색 메뉴에서 **허브**를 선택합니다.
3. 하려는 작업에 맞는 탭을 선택합니다.

| 탭 | 할 수 있는 작업 |
| --- | --- |
| **공유된 결과**(Shared results) | 공개된 프로젝트를 둘러보고 학습 결과를 확인합니다. |
| **내 결과**(My results) | 준비 중인 결과를 포함해 내 학습 결과를 확인합니다. |
| **배포 이력**(Deployments) | 허브에서 로봇에 배포한 기록을 찾아 진행 상황을 확인합니다. |

![프로젝트 검색, 정렬, 결과 종류 필터, 새로고침 버튼이 있는 허브 화면](/img/software/cyclo/studio/hub/hub_navigation_en.jpg)

학습을 한 번 실행하면 다음 두 패키지가 각각 준비될 수 있습니다.

| 패키지 | 구성 | 주요 기능 |
| --- | --- | --- |
| **Dataset** | 입력 모션과 해당 모션을 생성하고 학습에 사용할 수 있도록 준비하는 데 사용한 설정 | **ZIP 다운로드**, **미리보기 재생** |
| **Actions** | 학습한 모델, 학습 설정, 배포 파일 | **ZIP 다운로드**, **로봇 배포** |

:::note
공개된 결과는 로그인한 다른 사용자도 볼 수 있습니다. **내 결과**를 선택하면 내 프로젝트만 표시되며, 각 프로젝트의 공개 설정은 그대로 유지됩니다.
:::

## 학습 후 자동 저장 \{#automatic-saving-after-training}

Cyclo Studio에서 텍스트나 영상으로 생성한 모션으로 **AI Sapiens K1 Custom Mimic** 학습을 성공적으로 마치면, 저장 대상 결과가 허브에 자동으로 등록됩니다. 결과 파일을 따로 업로드하거나 저장 버튼을 누를 필요가 없습니다.

1. **시뮬레이션**(Simulation)에서 학습을 완료합니다.
2. 학습 완료 화면에서 **Hub 자동 저장 결과**를 확인합니다.
3. **내 Hub 결과 열기**를 선택하면 **내 결과**에서 해당 프로젝트가 열립니다.
4. 프로젝트를 펼쳐 Dataset과 Actions 카드를 확인합니다.

두 패키지는 각각 준비됩니다. Actions가 최종 모델이나 실행 패키지를 기다리는 동안 Dataset이 먼저 준비될 수 있습니다. 학습이 끝난 뒤 각 카드에서 다운로드할 수 있는지 확인합니다.

자동 등록된 결과는 파일 준비, 검증, 공개를 마치면 **공유된 결과**에 표시됩니다.

<details>
<summary>저장 상태 확인하기</summary>

| 상태 | 의미 |
| --- | --- |
| 최종 파일을 기다리고 있습니다 | 필요한 모션, 최종 모델, 설정 또는 최종 모델에 맞는 실행 패키지가 아직 준비되지 않았습니다. 파일을 기다리는 기한이 표시될 수 있습니다. |
| Hub 저장을 준비하고 있습니다 | 결과가 처리 대기 중입니다. |
| 다운로드 ZIP을 만들고 있습니다 | 허브에서 패키지를 만들고 있습니다. |
| 미리보기와 썸네일을 만들고 있습니다 | 허브에서 모션 영상과 이미지를 만들고 있습니다. |
| Hub에 파일을 저장하고 있습니다 / 저장한 파일을 확인하고 있습니다 | 공개하기 전에 파일을 업로드하고 검증하는 단계입니다. |
| 연결을 다시 시도하고 있습니다 | 일시적인 오류가 발생했습니다. 화면에 표시된 자동 재시도 시간을 확인합니다. |
| 저장 공간 확인이 필요합니다 | 저장 공간이 확보되기를 기다리고 있습니다. |
| Hub 저장 완료 | 패키지 저장을 완료했습니다. |
| Hub 저장을 완료하지 못했습니다 | 표시된 원인을 확인해 해결한 뒤 **다시 시도** 버튼이 있으면 선택합니다. |

**새로고침**을 눌러 현재 상태를 확인합니다. 프로젝트를 펼쳐 두면 주요 준비 단계에서 처리 중인 결과의 상태가 자동으로 갱신됩니다.

</details>

:::info
현재 자동 등록은 지원되는 Custom Mimic 작업에 적용됩니다. 이전에 실행한 학습이나 다른 종류의 학습 결과는 허브에 표시되지 않을 수 있습니다.
:::

</SectionCard>

## 프로젝트 찾기 \{#find-a-project}

**공유된 결과**와 **내 결과**에서는 같은 검색과 결과 종류 필터를 사용할 수 있습니다.

| 항목 | 사용 방법 |
| --- | --- |
| **프로젝트, 모션, 작성자 검색** | 프로젝트 이름, 모션 설명 또는 작성자 이름의 일부를 입력합니다. 검색을 해제하려면 입력한 내용을 지웁니다. |
| **프로젝트 최신순 / 프로젝트 이름순** | 프로젝트를 생성 날짜순 또는 이름순으로 정렬합니다. |
| **전체 종류 / Dataset / Actions** | 표시할 결과 종류를 선택합니다. 이 필터는 프로젝트 안의 결과에도 적용됩니다. |
| **프로젝트 더 보기** | 추가 프로젝트가 있으면 다음 목록을 불러옵니다. 화면에 표시되는 개수는 현재 불러온 프로젝트 수입니다. |
| **새로고침** | 현재 결과를 다시 불러옵니다. |

### 공유된 결과 \{#shared-results}

프로젝트 카드에는 썸네일, 프로젝트 이름, 학습 및 결과 개수, 이용할 수 있는 결과 종류, 작성자, 허브 등록일이 표시됩니다.

1. 프로젝트 카드를 눌러 학습 결과를 확인합니다.
2. 하트 버튼을 눌러 프로젝트에 좋아요를 표시합니다. 다시 누르면 취소됩니다. 좋아요는 프로젝트 전체에 적용됩니다.
3. **프로젝트 목록**을 선택하면 목록으로 돌아갑니다. 브라우저의 **뒤로 가기**로도 상세 화면에서 목록으로 돌아갈 수 있으며, **앞으로 가기**를 누르면 해당 프로젝트가 다시 열립니다.

### 내 결과 \{#my-results}

프로젝트는 펼칠 수 있는 행으로 표시됩니다. 프로젝트 이름을 누르면 해당 결과가 펼쳐지고, 다시 누르면 접힙니다. 다른 프로젝트를 선택하면 기존 프로젝트가 접히고 새로 선택한 프로젝트가 열립니다.

내 결과는 공개되기 전에도 이 탭에 표시될 수 있습니다. 각 카드에서 저장 상태와 공개 상태 배지를 확인합니다.

<details>
<summary>공개 상태 배지</summary>

| 배지 | 의미 |
| --- | --- |
| **공개 완료** | 로그인한 다른 사용자도 결과에 접근할 수 있습니다. |
| **공개 전** | 다른 사용자는 아직 결과에 접근할 수 없습니다. |
| **비공개** | 소유자만 결과에 접근할 수 있습니다. |
| **공개 일시 중지** | 파일이 준비됐으며 현재 공개가 일시 중지된 상태입니다. |
| **공개 철회** | 다른 사용자는 더 이상 결과에 접근할 수 없습니다. |
| **공개 확인 필요** | 새로고침하여 현재 공개 여부를 확인합니다. |

</details>

</SectionCard>

## 학습 결과 확인하기 \{#inspect-training-results}

프로젝트는 한 번의 학습에서 나온 결과를 한 그룹으로 묶어 보여줍니다. 각 그룹에는 허브 등록 시각과 해당 학습에서 생성된 Dataset 및 Actions 카드가 표시됩니다.

- 학습 결과를 여러 개 불러왔다면 **불러온 학습 결과 선택**에서 하나를 선택하거나 **불러온 학습 결과 전체**를 선택합니다.
- **학습 결과 더 보기**를 선택하면 추가 결과를 불러옵니다. 선택 메뉴에는 이미 불러온 학습 결과만 표시됩니다.
- 텍스트로 생성한 모션의 경우 **입력 프롬프트**에 원문이 표시됩니다. 긴 텍스트는 처음에 세 줄까지만 표시됩니다. **전체 보기**를 누르면 전체 내용을 볼 수 있으며, **접기**를 누르면 다시 줄여 볼 수 있습니다.
- 영상으로 생성한 결과나 입력 프롬프트가 없는 이전 결과에는 모션 설명이 표시됩니다. 설명이 없으면 제목에 **학습 결과**가 표시됩니다.

결과 종류 필터는 프로젝트 안에서도 적용됩니다. 카드가 보이지 않으면 **Dataset** 또는 **Actions**가 선택되어 있는지 확인한 뒤 **전체 종류**로 바꿉니다.

</SectionCard>

## Dataset 사용하기 \{#use-a-dataset}

### 입력 모션 다운로드하기 \{#download-the-input-motion}

준비가 끝난 Dataset 카드에서 **ZIP 다운로드**(Download ZIP)를 선택합니다. ZIP 파일에는 입력 모션과 함께 모션 생성 방식에 따라 생성, 전처리 또는 리타기팅 설정이 들어 있습니다.

사용자가 업로드한 원본 영상은 허브의 Dataset ZIP 파일과 생성된 미리보기에 포함되지 않습니다. 원본 영상에서 추출한 모션은 Dataset에 포함됩니다.

### 미리보기 재생하기 \{#play-the-preview}

1. Dataset 카드에서 **미리보기 재생**(Play preview)을 선택합니다.
2. 영상 조작 버튼으로 모션을 재생하거나 일시정지하고, 원하는 시점으로 이동합니다.
3. 확인이 끝나면 **미리보기 닫기**를 선택합니다.

미리보기 링크에는 유효기간이 있습니다. 만료 안내와 함께 재생이 멈추면 **미리보기 재생**을 다시 선택해 새 링크를 받습니다.

</SectionCard>

## 브라우저에서 Actions 재생하기 \{#replay-actions-in-the-browser}

준비가 끝난 Actions 카드에서 **로봇 배포**(Deploy)를 선택하면 재생 창이 열립니다. 재생 창은 먼저 선택한 결과와 호환되는 정책 패키지를 확인하고 불러옵니다.

시뮬레이터가 준비되면 다음 기능을 사용할 수 있습니다.

| 기능 | 동작 |
| --- | --- |
| **모델로 움직이기**(Run model) | 브라우저 시뮬레이션에서 선택한 정책을 실행합니다. |
| **모델 종료**(Stop model) | 정책 테스트를 종료하고 시뮬레이션 로봇을 서 있는 상태를 유지하는 제어로 되돌립니다. |
| **처음부터**(Start over) | 시뮬레이션 로봇을 시작 상태로 되돌립니다. |
| **일시정지 / 재개** | 시뮬레이션을 멈추거나 같은 시점부터 이어서 실행합니다. |
| **카메라 시점** | **중심으로 보기**, **로봇에 맞추기**, **정면**, **측면** 중 하나를 선택합니다. |
| **고급 조작** | 관절 상태를 확인하거나 장애물을 추가·편집합니다. **자세·물리 설정**을 열어 시뮬레이션의 지지대, 기본 자세, 댐핑을 조절할 수도 있습니다. |

**닫기**를 선택하면 재생 창에서 나옵니다. Actions 카드에서 **ZIP 다운로드**를 선택하면 모델, 설정, 배포 파일을 받을 수 있습니다.

:::info[영상 미리보기와 정책 재생]
썸네일과 미리보기 영상은 모션 데이터를 보여 주는 자료입니다. 학습한 정책의 동작은 브라우저에서 정책을 실행하는 Actions 재생 창에서 확인합니다. 배포할 로봇을 선택하기 전에 이 창에서 동작을 확인합니다.
:::

패키지를 준비 중이라면 상태가 갱신될 때까지 기다리거나 **다시 확인**을 선택합니다. 호환되는 재생 패키지가 없는 릴리스를 이 창에서 재생하려면 지원되는 원본 파일로 패키지를 다시 빌드해야 합니다. 프로젝트가 보관되었다는 메시지가 표시되면 **시뮬레이션**에서 보관을 해제한 뒤 다시 시도합니다.

</SectionCard>

## Actions를 실물 로봇에 배포하기 \{#deploy-actions-to-a-robot}

### 시작하기 전에 \{#before-you-begin}

- 계정에 **로봇 개발자**(Robot Developer) 또는 **관리자**(Administrator) 역할이 승인되어 있어야 합니다.
- 선택한 Actions에 호환되는 배포 패키지의 준비가 끝나 있어야 합니다.
- 대상 로봇이 배포를 받을 준비가 되어 있어야 합니다. 모델을 보내기 전에 **로봇 ID**를 확인합니다.

배포 권한이 있는 사용자는 자신이 소유하지 않은 프로젝트의 공개 Actions도 사용할 수 있습니다. 배포 기록은 요청을 보낸 사용자에게 남습니다.

### 모델 보내기 \{#send-the-model}

1. Actions 카드에서 **로봇 배포**를 선택하고 브라우저 재생 창에서 정책의 동작을 확인합니다.
2. 재생 창에서 **로봇에 배포**(Deploy to robot)를 선택합니다.
3. 배포 창에서 모델과 체크포인트 정보를 확인합니다.
4. 대상 **로봇 ID**를 입력하거나 목록이 표시되면 **최근 배포 대상**에서 선택합니다.
5. 배포 창에서 요청하는 경우 **모델 이름**을 입력합니다.
6. **배포할 모델과 대상 로봇**을 확인한 뒤 **로봇에 배포**를 눌러 요청을 보냅니다.
7. 배포 창에서 진행 상황을 확인하거나 허브의 **배포 이력** 탭을 엽니다.

로봇 ID는 대소문자를 구분하며, 영문자, 숫자, 밑줄, 하이픈으로 1~64자를 입력할 수 있습니다. 모델 이름을 입력해야 하는 경우 100자 이내로 입력합니다.

**최근 배포 대상**에는 조회한 배포 기록에서 마지막으로 받은 응답이 표시됩니다. 로봇의 현재 연결 여부는 별도로 확인해야 합니다. 선택한 로봇에 진행 중이거나 결과를 확인하지 못한 배포가 있다면 새 배포를 요청하기 전에 해당 기록을 확인합니다.

:::warning[모델 설치와 실물 로봇 동작]
배포하면 대상 로봇에 모델이 설치됩니다. 실물 로봇의 동작은 로봇에서 별도로 시작합니다. 설치한 모델을 사용하기 전에 올바른 로봇인지, 동작 환경이 적절한지 확인합니다.
:::

요청을 보낸 뒤 창을 닫아도 배포는 계속됩니다. **배포 이력**에서 진행 상황을 확인합니다.

## 배포 이력 확인하기 \{#check-deployment-history}

**배포 이력**에서 허브를 통해 로봇에 배포한 기록을 확인합니다.

1. **로봇 ID · 모델 이름 · 체크포인트 검색**에 검색어를 입력합니다.
2. **배포 상태**에서 **전체 상태**, **진행 중**, **확인 필요**, **실패**, **설치 완료** 중 하나를 선택합니다.
3. 기록의 **배포 상세**를 열어 진행 상황, 각 단계의 시각, 체크포인트, 이벤트를 확인합니다. **이전 배포 더 보기**가 표시되면 눌러 이전 배포 기록을 불러옵니다.

| 상태 | 확인할 내용 |
| --- | --- |
| **파일 준비 중 / 전송 대기** | 패키지를 준비하거나 전송을 기다리고 있습니다. |
| **로봇 응답 대기 / 로봇 수신 완료** | 요청이 전송되었거나 로봇이 요청에 응답했습니다. 설치 완료는 아직 확인되지 않았습니다. |
| **다운로드 중 / 파일 검증 중 / 적용 중** | 로봇이 패키지를 내려받거나 검증하거나 설치하고 있습니다. |
| **설치 완료** | 로봇이 설치 성공을 보고했습니다. |
| **배포 실패** | 다시 시도하기 전에 표시된 오류를 확인합니다. |
| **상태 확인 필요** | 최종 결과를 확인하지 못했습니다. 새 배포를 허용하기 전에 로봇에서 직접 확인합니다. |

### 전송이 중단된 배포 처리하기 \{#resolve-an-interrupted-delivery}

- 이미 보낸 요청을 다시 전송할 수 있는 동안 **같은 요청 다시 전달**이 표시됩니다. 이 버튼을 사용하면 새 배포를 만들지 않고 같은 요청을 다시 보낼 수 있습니다.
- **상태 확인 필요**가 표시되면 로봇에서 다운로드와 설치 작업이 끝났는지 직접 확인합니다. 그런 다음 **로봇 상태 확인**을 누르고, 확인 창의 내용이 직접 확인한 상태와 일치하면 **확인했어요 · 새 배포 허용**을 누릅니다.
- **같은 모델로 다시 배포** 또는 **다른 로봇에 배포**가 표시되면 같은 모델로 다시 시도하거나 다른 대상 로봇을 선택할 수 있습니다.

:::caution
**확인했어요 · 새 배포 허용**은 결과를 확인하지 못한 배포의 대상 로봇에 새 요청을 보낼 수 있도록 잠금을 해제합니다. 이 버튼으로는 로봇을 정지하거나 로봇에서 진행 중인 작업을 취소할 수 없습니다. 로봇에서 직접 상태를 확인한 뒤에만 이 버튼을 누릅니다.
:::

## 문제 해결 \{#troubleshooting}

| 상황 | 해결 방법 |
| --- | --- |
| 프로젝트나 결과가 표시되지 않습니다 | 선택한 탭, 검색어, 결과 종류를 확인합니다. 추가 결과가 있으면 불러온 뒤 새로고침합니다. 방금 실행한 학습이라면 Hub 자동 저장 상태를 확인합니다. |
| 결과를 불러올 수 없습니다 | **다시 시도**를 선택합니다. 로그인 세션이 만료되었다면 다시 로그인합니다. |
| 썸네일이 표시되지 않습니다 | 결과를 새로고침합니다. 패키지가 준비되었는지는 저장 상태에서 확인합니다. |
| 다운로드나 미리보기를 열 수 없습니다 | 결과를 새로고침하고 다시 시도해 최신 링크를 받습니다. 릴리스가 변경되었거나 공개 철회됐을 수 있습니다. |
| Hub 저장에 실패했습니다 | 결과 카드에 표시된 원인을 확인합니다. 누락된 파일, 접근 권한, 저장 공간 문제를 해결한 뒤 **다시 시도** 버튼이 있으면 선택합니다. |
| 정책 재생을 시작할 수 없습니다 | 재생 창에 표시된 메시지를 읽고 **다시 확인** 버튼이 있으면 선택합니다. 이 창에서 재생하려면 호환되는 패키지를 사용할 수 있어야 합니다. |
| **로봇에 배포**를 사용할 수 없습니다 | 역할이 승인되었는지, 패키지가 준비되었는지, 배포 서비스를 사용할 수 있는지, 대상 로봇에 아직 처리되지 않은 배포가 있는지 확인합니다. |
| 배포 진행 상황을 갱신할 수 없습니다 | 새 요청을 보내기 전에 배포 상세를 다시 불러옵니다. 창을 닫아도 기존 배포는 계속됩니다. |

</SectionCard>
