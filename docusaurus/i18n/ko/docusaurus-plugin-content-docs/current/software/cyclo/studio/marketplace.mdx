**Cyclo Marketplace**는 [Cyclo Studio](/docs/software/cyclo/cyclo_studio)의 로봇 데이터셋·3D 에셋 카탈로그입니다. 필요한 에셋을 찾고 사양과 라이선스를 확인한 뒤, 무료 에셋을 주문해 파일을 다운로드합니다.

목록과 상품 상세는 실제 ROBOTIS 상품을 촬영한 화면입니다. 장바구니와 라이브러리는 예제 데이터를 넣어 재현했습니다. 상품 구성과 사양은 달라질 수 있습니다.

:::info[현재 지원 범위]
현재는 무료 에셋만 주문할 수 있습니다. 유료 결제와 **가격** 필터는 아직 지원하지 않습니다. 가격이 있는 에셋도 상세 정보를 볼 수 있지만, 최종 결제 금액이 0원이 아닌 주문은 완료할 수 없습니다.
:::

## 시작하기 전에

- 에셋 목록과 상세 정보는 로그인하지 않아도 볼 수 있습니다.
- 찜하기, 장바구니, 주문, 다운로드를 이용하려면 로그인해야 합니다.
- 이메일로 가입했다면 이메일 인증을 마친 뒤 로그인합니다.

Cyclo Studio에서 **마켓플레이스** 메뉴를 엽니다.

1. 필터와 정렬로 필요한 에셋을 찾습니다.
2. 상세 정보에서 파일 형식, 로봇 기종, 버전, 라이선스를 확인합니다.
3. **바로 구매** 또는 장바구니에서 무료 에셋을 주문합니다.
4. **마이 페이지 → 라이브러리**에서 파일을 다운로드합니다.

</SectionCard>

## 에셋 찾기

### 필터 적용하기

상품 목록 옆의 필터를 선택합니다. 화면이 좁거나 필터 영역이 세로로 다 들어가지 않으면 **필터** 버튼을 눌러 패널을 엽니다.

| 필터 | 사용 방법 |
| --- | --- |
| **상품 종류** | **데이터셋** 또는 **3D 에셋**을 선택합니다. |
| **파일 포맷** | **LeRobot Dataset**, **Sapiens K1 Motion** 등 목록에 있는 형식을 선택합니다. |
| **카테고리** | 원하는 상품 카테고리를 선택합니다. |
| **로봇 기종** | `ffw_sg2_rev1`처럼 전체 식별자를 입력합니다. 이름의 일부만 입력하면 일치하는 에셋을 찾을 수 없습니다. |

서로 다른 필터를 함께 적용할 수 있으며, 각 항목에서는 하나씩 선택합니다. 목록 위에서 적용한 필터를 개별 해제할 수 있습니다. **초기화**를 누르면 모든 필터를 지우고 정렬을 **최신 공개순**으로 되돌립니다.

<img src="/img/software/cyclo/studio/marketplace/catalog-ko.png" alt="LeRobot Dataset 필터를 적용한 실제 ROBOTIS 상품 목록" style={{display: 'block', width: '100%', maxWidth: 1100, height: 'auto', margin: '1rem auto 2rem'}} />

### 목록 정렬하기

목록 위의 정렬 메뉴는 처음에 **최신 공개순**으로 표시됩니다. **인기순**, **평점순**, **조회수 높은순**, **낮은 가격순**, **높은 가격순**으로 바꿀 수 있습니다.

목록을 아래로 스크롤하면 다음 에셋을 불러옵니다. **상품 더 보기** 버튼이 나타나면 눌러서 계속 확인합니다.

### 에셋 찜하기

에셋 카드에 마우스를 올리거나 키보드로 카드의 버튼에 초점을 맞추면 작업 아이콘이 나타납니다. 하트 모양의 **찜하기**를 누르면 해당 에셋을 찜합니다. 다시 누르면 해제합니다. 이 기능은 로그인 후 이용합니다.

## 상세 정보 확인하기

에셋 카드를 누르면 상세 창이 열립니다. 화살표나 미리보기 이미지를 눌러 다른 이미지와 영상을 확인합니다. 영상은 재생 버튼으로 조작합니다.

주문하기 전에 다음 정보를 확인합니다.

| 항목 | 확인할 내용 |
| --- | --- |
| **제공 포맷**, **총 파일 용량** | 사용 중인 도구가 파일 형식을 지원하는지, 저장 공간이 충분한지 확인합니다. |
| **상품 버전** | 버전 이름과 **현재 버전 활성일**을 확인합니다. 날짜는 정보가 있을 때 표시됩니다. |
| **라이선스**, **라이선스 상세** | 파일을 사용하거나 재배포하기 전에 라이선스와 별도 조건을 읽습니다. |
| **데이터셋 속성** | 로봇 기종, 수집 환경, 에피소드 수, 샘플 수, 샘플링 레이트를 확인합니다. |
| **센서와 관측 데이터** | 카메라 종류, 해상도, 프레임 레이트, 관절 상태 데이터 포함 여부를 확인합니다. |

<img src="/img/software/cyclo/studio/marketplace/asset-details-ko.png" alt="Shower Puff Pick & Place의 실제 사진, 버전, 라이선스, 제공 포맷과 바로 구매·장바구니 담기 버튼이 있는 상세 화면" style={{display: 'block', width: '100%', maxWidth: 1100, height: 'auto', margin: '1rem auto 2rem'}} />

사양 아래에는 세 가지 탭이 있습니다.

- **설명**: 판매자가 작성한 에셋 소개를 읽습니다.
- **포맷 / 버전**: 파일 이름, 형식, 크기를 확인합니다. 이미 보유한 에셋은 내려받을 수 있는 파일 옆에 다운로드 버튼이 나타날 수 있습니다.
- **리뷰**: 평점과 구매 리뷰, 판매자의 답글을 읽습니다. 이 화면에서는 리뷰를 작성할 수 없습니다.

판매자가 제공하지 않은 정보는 표시하지 않습니다. 로봇 기종이 같더라도 파일 형식이나 센서 구성이 다를 수 있으므로 설명과 사양을 함께 확인합니다.

</SectionCard>

## 무료 에셋 주문하기

무료 에셋도 주문을 완료해야 라이브러리에 추가됩니다. 찜하거나 장바구니에 담기만 해서는 다운로드할 수 없습니다.

### 에셋 하나 주문하기

1. 상세 창에서 **바로 구매**를 누릅니다.
2. 로그인 안내가 나타나면 로그인합니다.
3. **주문 결제** 화면에서 상품과 금액을 확인합니다.
4. 아래의 주문 완료 절차를 따릅니다.

### 장바구니에서 주문하기

1. 상세 창에서 **장바구니 담기**를 누릅니다. 에셋 카드의 장바구니 아이콘을 누르면 해당 상품을 담고 장바구니로 이동합니다.
2. 담아 둔 상품을 확인하려면 탐색 메뉴에서 **장바구니**를 엽니다.
3. 주문할 상품을 선택합니다. **전체 선택**을 누르면 주문할 수 있는 상품을 모두 선택합니다.
4. 상품과 주문 요약을 확인한 뒤 **결제 하기**를 누릅니다.

**선택 삭제**는 선택한 상품을 장바구니에서 지웁니다. **주문불가삭제**는 주문할 수 없는 상품을 한꺼번에 지웁니다. 이미 보유한 에셋이나 본인이 소속된 스토어의 에셋은 구매할 수 없습니다.

### 주문 완료하기

1. **주문 결제** 화면에서 상품, 할인 내역, **최종 결제 금액**을 확인합니다. 유료 결제를 지원하지 않으므로 결제 금액이 0원이어야 합니다.
2. 주문 동의 문구를 읽고, 동의하는 경우에만 체크박스를 선택합니다.
3. 금액이 함께 표시된 **결제하기** 버튼을 누릅니다.
4. **구매가 완료되었습니다.** 안내가 나타나면 **라이브러리에서 확인**을 누릅니다.

금액이나 약관이 바뀌었다는 안내가 나오면 변경 내용을 확인한 뒤 다시 주문합니다. 이미 처리 중인 주문이 있다면 완료될 때까지 기다립니다.

:::note[결제 수단]
현재 결제 수단 영역에서는 카드를 등록할 수 없습니다. 유료 주문도 지원하지 않습니다.
:::

## 파일 다운로드하기

1. 탐색 메뉴의 **더 보기(···) → 마이 페이지**를 열고 **라이브러리** 탭을 선택합니다. 주문 완료 화면의 **라이브러리에서 확인**도 같은 곳으로 이동합니다.
2. 원하는 에셋의 **파일 보기** 화살표를 눌러 파일 목록을 펼칩니다.
3. 파일 이름, 형식, 크기를 확인하고 필요한 파일 옆의 **다운로드**를 누릅니다.
4. 브라우저가 다운로드나 새 창을 차단하면 허용한 뒤 다시 시도합니다.

</figure>

보유한 에셋은 Marketplace 카드의 다운로드 아이콘으로도 받을 수 있습니다. 파일이 여러 개면 **포맷 / 버전**에서 필요한 파일을 선택합니다. 다운로드는 파일별로 진행합니다.

:::tip[이미 보유한 에셋]
상세 창의 **라이브러리에서 다운받기** 버튼이 비활성 상태라면 **마이 페이지 → 라이브러리**에서 파일을 다운로드합니다. 현재 계정으로 받을 수 있는 파일을 라이브러리에서 확인합니다.
:::

## 문제가 생겼을 때

| 상황 | 확인 및 조치 |
| --- | --- |
| 조건에 맞는 에셋이 없습니다. | 필터를 해제하거나 **초기화**를 누릅니다. **로봇 기종**에 전체 식별자를 입력했는지도 확인합니다. |
| 필터 항목이나 상품 목록을 불러오지 못합니다. | 오류가 난 영역의 **다시 시도**를 누릅니다. 계속 실패하면 네트워크 연결을 확인합니다. |
| 로그인 안내가 나타납니다. | 에셋을 주문할 계정이나 이미 보유한 계정으로 로그인합니다. |
| 주문할 수 없는 상품이 있다는 안내가 나옵니다. | 장바구니로 돌아가 주문할 수 없는 상품을 지우고 주문 대상을 다시 선택합니다. |
| 금액이나 약관이 바뀌었다는 안내가 나옵니다. | 변경된 금액과 동의 내용을 확인한 뒤 다시 주문합니다. |
| 이미 보유한 에셋입니다. | 다시 주문하지 않고 **마이 페이지 → 라이브러리**에서 확인합니다. |
| 금액이 0원이 아닌 주문을 완료할 수 없습니다. | 현재는 무료 에셋만 주문할 수 있습니다. 유료 결제는 아직 지원하지 않습니다. |
| 라이브러리에 파일이 보이지 않습니다. | 주문을 완료했는지, 주문한 계정으로 로그인했는지 확인합니다. 에셋을 펼친 뒤 로딩 오류가 있다면 다시 시도합니다. |
| 다운로드가 시작되지 않습니다. | 브라우저에서 차단한 다운로드나 새 창을 허용한 뒤 **다운로드**를 다시 눌러 새 링크를 받습니다. |

</SectionCard>
