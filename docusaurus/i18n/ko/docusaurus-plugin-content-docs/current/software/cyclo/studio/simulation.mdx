## Play \{#play}

**시뮬레이션**에서 **기본 모델 체험**(Try built-in models)을 선택하거나 프로젝트에서 **Play**를 엽니다. Play는 클라우드 GPU 세션 없이 브라우저에서 실행됩니다.

### 기본 걷기 모델 \{#built-in-walk}

**모델 선택**(Select Model)을 열고 **기본 모델**(Built-in models)에서 **걷기**(Walk)를 선택합니다.

<SimulationScreenshot file="play-model-picker" width={1440} height={950} focus="21.3% 44.4% 74.1% 51%" alt="Play의 기본 모델 목록에서 걷기 모델이 강조된 화면" />

1. **시작**(Start) 버튼이 활성화되면 선택하고 3D 화면을 클릭합니다.
2. 아래 영상처럼 **↑** 키를 누르고 있으면 앞으로 걷고, **Shift** 키를 함께 누르면 달립니다. **↓** 키로 뒤로 이동하고 **←/→** 키로 방향을 바꾸며 **Space** 키로 움직임을 멈춥니다.
3. **정지**(Stop)를 선택하면 서 있는 상태를 제어하는 모드로 돌아갑니다. **초기화**(Initialize)를 선택하면 로봇을 시작 상태로 되돌립니다.

## 프로젝트 만들기 \{#create-a-project}

1. Cyclo Studio에 로그인하고 기본 탐색 메뉴에서 **시뮬레이션**을 선택합니다.
2. **새 프로젝트**(New project)를 선택하고 **Sapiens K1**을 고릅니다. **프로젝트 이름**을 입력하고 **만들기**를 선택합니다. 기존 작업을 이어가려면 **내 프로젝트**에서 프로젝트를 선택합니다.
3. 프로젝트는 **Play**에서 열립니다. 3D 화면 옆 도구 모음에서 **모션 만들기**를 엽니다.

<SimulationScreenshot file="new-project-button" width={324} height={72} alt="시뮬레이션 프로젝트 목록의 새 프로젝트 버튼" />

프로젝트 목록으로 돌아가려면 **프로젝트 홈**을 선택합니다. 프로젝트 이름을 바꾸려면 프로젝트 카드에서 연필 아이콘을 누른 뒤 **이름 저장**을 선택합니다. 프로젝트를 목록에서 제거하려면 실행 중인 작업과 GPU 세션을 중지한 후 휴지통 아이콘을 누르고 **목록에서 삭제**를 선택합니다. 프로젝트의 모션, 학습 결과, 배포한 모델은 보존됩니다.

## 모션 만들기 \{#create-motion}

### 텍스트로 로봇 모션 만들기 \{#from-text-to-a-robot-motion}

1. **텍스트**를 선택합니다. **동작 설명**에 원하는 동작을 입력합니다. 예를 들어 “오른손을 어깨 높이까지 들어 가볍게 흔들어 주세요”라고 입력합니다(영문 예시 “Raise your right hand to shoulder height and give a little wave.”). <strong>모션 길이 (초)</strong>는 2\~10초, **후보 수**는 1\~4개로 설정합니다.
2. **모션 생성**을 선택합니다. **내 모션**(My Motions)에 후보가 표시되면 **동작 보기**(Preview motion)를 선택하고 타임라인을 이용해 **K1 로봇** 화면에서 모션을 확인합니다.

만든 기준 모션으로 학습하려면 미리보기에서 **Mimic 학습에 사용**(Use for Mimic training)을 선택하거나 모션 카드에서 **학습**을 선택합니다. 학습이 끝나면 [Play](#play)에서 로봇이 기준 모션을 얼마나 잘 따라 하는지 확인합니다.

나중에 텍스트 프롬프트를 다시 사용하려면 **모션 초안 저장**을 선택합니다. 모션 생성에 실패하면 **초안 및 이전 생성 기록**에서 해당 시도의 상태를 확인하고 **마이 페이지**에서 남은 모션 생성 시간을 확인합니다.

## 학습 \{#training}

모션 미리보기에서 **Mimic 학습에 사용**을 선택하면 해당 모션이 선택된 상태로 학습 화면이 열립니다. 학습 화면에서 시작하려면 **새 학습**을 선택하고 **학습 이름**을 입력한 뒤 **다음**을 눌러 **학습 유형**을 선택합니다.

<SimulationScreenshot file="training-workspace" width={605} height={390} focus="47.9% 2.6% 7.7% 2.5%" alt="학습 유형 선택 화면에서 Locomotion과 Mimic이 강조된 모습" />

| 학습 유형 | 설정 |
| --- | --- |
| **Locomotion** | **걷기 · 안정성과 부드러움** 또는 **달리기 · 속도 추종**을 선택합니다. |
| **Mimic** | 미리 본 모션을 사용하거나 **내 모션**에서 저장된 모션을 선택합니다. **파일 업로드**로 최대 128 MiB의 호환되는 CYCLO Sapiens K1 리타게팅 ZIP 파일을 올리거나 **마켓플레이스**에서 구매한 모션 중 학습에 사용할 수 있는 모션을 선택할 수도 있습니다. |

1. **학습 설정**에서 **목표 학습 회차**(Target iterations)를 설정합니다.
2. **GPU 및 시작**에서 **GPU 프로필**을 선택하고 **학습 시작**(Start training)을 누릅니다. 사용 가능한 GPU를 확인하려면 **GPU 새로고침**을 선택합니다.
3. 실시간 뷰어가 연결될 때까지 기다립니다.

보상 가중치는 목표 속도를 추종하거나 기준 모션을 따라 하는 등 학습에서 어떤 동작에 우선순위를 둘지 정합니다. 첫 학습에는 **Mimic**의 기본 가중치나 **Locomotion** 프리셋의 가중치를 사용합니다. Mimic의 가중치를 조정하려면 **학습 설정**에서 **고급 설정 열기**를 선택합니다. Locomotion의 가중치는 **Locomotion 보상 프리셋** 아래에서 수정합니다. 변경 사항은 다음 학습부터 적용됩니다.

Mimic 학습은 예상 소요 시간을 약 **3~10시간**으로 잡습니다. 실제 학습 시간은 기준 모션 길이, 목표 학습 회차, GPU 프로필 및 기타 설정에 따라 달라집니다.

학습에는 GPU와 학습 시간이 필요합니다. GPU를 선택할 때 **학습 가능 시간**을 확인하거나 **마이 페이지** → **잔여 시간**을 확인합니다. 학습 화면을 나가거나 브라우저를 닫아도 학습 시간과 서버 제한 범위 내에서 학습이 계속될 수 있습니다. 진행 상황을 보려면 **학습**을 다시 엽니다.

## 학습 결과와 모델 \{#training-results-and-models}

### 학습 결과 확인 및 테스트 \{#review-and-test-a-training-run}

**학습** → **학습 기록**을 열고 저장된 학습의 **결과 보기**(View results) 또는 실행 중인 학습의 **진행 보기**를 선택합니다. 검색, **필터** 또는 **이전 학습 더 보기**로 원하는 학습을 찾을 수 있습니다.

<SimulationScreenshot file="training-history" width={696} height={578} focus="80.9% 24.3% 11.8% 56.6%" alt="학습 기록에서 저장된 학습의 결과 보기 버튼이 강조된 화면" />

결과 화면에서 학습 상태, 반복 횟수, 보상 추이를 확인합니다. **모델**에서 체크포인트를 펼치고 **3D Play에서 테스트**를 선택합니다. 결과 화면 옆에서 체크포인트의 정책이 자동으로 실행되어 로봇이 어떻게 움직이는지 확인할 수 있습니다.

<SimulationScreenshot file="checkpoint-preview" width={1176} height={850} focus="68.7% 41.8% 25.7% 44.8%" alt="시뮬레이터 옆에 펼친 체크포인트에서 3D Play에서 테스트 버튼이 강조된 화면" />

- Play에서 **환경 편집**으로 장애물을 추가하거나 **체크포인트 미리보기 닫기**를 선택해 결과 화면으로 돌아갑니다.
- 재생할 수 없는 경우 **테스트 가능**으로 표시된 체크포인트를 선택하거나 패키지가 준비된 뒤 **학습 파일 새로고침**을 선택합니다. 체크포인트의 지표와 파일은 **상세 지표 · 다운로드**에서 확인합니다.
- 학습이 완료되면 **이 모델로 움직여 보기** 버튼이 표시될 때 선택할 수 있습니다. 텍스트나 영상에서 만든 모션으로 진행한 Mimic 학습이 자동 저장 조건을 충족하면 **Hub 자동 저장 결과**에서 관련 Dataset과 Actions의 저장 여부를 확인할 수 있습니다. [허브 가이드](./hub.mdx)

### 저장된 체크포인트에서 학습 이어가기 \{#continue-from-a-saved-checkpoint}

체크포인트 작업 메뉴에서 **이 체크포인트에서 이어 학습**을 선택합니다. **체크포인트에서 이어 학습** 화면에서 새 학습이 도달할 **최종 목표 회차**를 입력합니다. 예를 들어 2,200회차에서 시작해 5,000회차까지 학습하려면 **5,000**을 입력합니다. 학습 환경과 GPU 시간 설정을 확인한 다음 **GPU에서 이어 학습**을 선택합니다.

이전 학습 상태를 복원하여 새 학습을 시작합니다. 원래 체크포인트는 계속 사용할 수 있으며 시뮬레이션 에피소드는 처음부터 시작합니다. 수치가 불안정해 학습이 중단됐다면 더 이전 체크포인트에서 학습을 다시 시작하는 방법을 고려하세요.

### 학습한 모델 찾기 \{#find-your-trained-models}

**모델**을 열고 **내가 학습한 모델**(My trained models)을 확인합니다. 이름, 모션 또는 날짜로 검색하고 각 학습의 **체크포인트**를 펼쳐 사용 가능한 버전을 비교합니다.

<SimulationScreenshot file="models-play" width={696} height={636} focus="62.7% 75.7% 30.7% 6%" alt="내가 학습한 모델 목록의 모델 카드에서 Play에서 실행 버튼이 강조된 화면" />

- 모델의 **Play에서 실행**(Run in Play)을 선택합니다. 재생 패키지가 준비된 체크포인트는 **Play**를 선택해 실행할 수 있습니다. 해당 학습을 열려면 **원본 학습**을 선택합니다.
- **모델로 저장** 버튼이 표시되면 원본 파일에 연결된 모델을 이름을 지정해 저장할 수 있습니다. **모델 이름**은 최대 100자입니다.
- Play의 모델 선택 화면에서 **내 모델** 아래의 호환되는 체크포인트를 선택하고 준비가 끝나면 **시작**을 선택합니다. **+ 모델 추가** 버튼이 표시되면 호환되는 CYCLO ZIP 파일을 추가할 수 있습니다. 페이지를 새로고침하거나 프로젝트를 전환하기 전까지 해당 모델을 테스트할 수 있습니다.

### 모델 카드 또는 학습 결과 삭제 \{#remove-a-model-card-or-training-result}

| 작업 | 삭제 범위 |
| --- | --- |
| **모델**의 **카드 삭제** | 모델 라이브러리의 카드를 삭제합니다. 학습 기록과 체크포인트는 계속 사용할 수 있습니다. |
| **학습 기록**의 **학습 기록 삭제** | 프로젝트에서 해당 학습 기록과 체크포인트를 삭제합니다. |
| 학습 결과의 **체크포인트 삭제** | 선택한 체크포인트와 관련 재생 파일을 삭제합니다. 다른 체크포인트는 계속 사용할 수 있습니다. |

학습이 실행 중이면 완료될 때까지 기다린 후 학습 기록이나 체크포인트를 삭제합니다. 로봇에 이미 설치한 모델은 이러한 작업을 해도 유지됩니다.

## 로봇에 모델 배포 \{#deploy-a-model-to-a-robot}

### Sapiens K1 설정 \{#set-up-your-sapiens-k1}

처음 설정할 때는 Sapiens K1의 전원을 켜고 인터넷에 연결합니다. 로봇 PC에 Docker가 설치되어 있어야 합니다. 데이터 전송을 지원하는 USB-C 케이블과 Chrome 또는 Edge처럼 Web Serial을 지원하는 데스크톱 브라우저를 사용합니다. HTTPS로 Cyclo Studio에 로그인하고 설정된 **로봇 ID**를 모르면 로봇 관리자에게 문의합니다.

1. 컴퓨터를 로봇의 USB 시리얼 포트에 연결합니다. **시뮬레이션**을 열고 오른쪽 위에서 **로봇 설정**(Robot Setup)을 선택합니다.

   <figure className={styles.screenshot} style={{maxWidth: 372}}>
     <img src={useBaseUrl('/img/software/cyclo/studio/simulation/robot-setup-button.webp')} width={372} height={113} alt="시뮬레이션 화면 오른쪽 위에서 새 프로젝트 옆에 있는 로봇 설정 버튼" loading="lazy" />
   </figure>

2. 브라우저의 시리얼 포트 선택 창에서 로봇의 포트를 선택한 뒤 **연결**을 누릅니다. 포트 이름은 장치와 운영체제에 따라 다릅니다. 목록이 비어 있으면 로봇의 전원, 케이블, USB 포트를 확인합니다.
3. Cyclo Studio가 root 계정으로 로그인을 시도합니다. 입력 창이 나타나면 로봇 PC의 **Linux 비밀번호 (필요한 경우)**를 입력하고 **로그인**을 선택합니다.
4. **로봇 설정 진행 상태**에서 MQTT 클라이언트가 실행 중이라는 메시지가 표시될 때까지 기다립니다. Cyclo Studio는 클라이언트가 없으면 설치하고 컨테이너가 중지된 상태이면 시작합니다.

   <SimulationScreenshot file="robot-setup-progress" width={1160} height={456} focus="34% 44% 55% 1.6%" alt="Linux 셸 연결과 MQTT 클라이언트 실행이 확인된 로봇 설정 진행 화면과 하단의 로봇 PC 메시지 및 닫기 버튼" />

설정에 실패하면 **로봇 PC 메시지**를 펼쳐 보고 로봇의 인터넷 연결을 확인합니다. **다시 확인** 버튼이 표시되면 선택합니다. 설정 결과를 확인할 수 없으면 창을 닫고 다시 연결해 로봇 상태를 확인합니다. **닫기**를 선택하면 USB 시리얼 연결이 끊어집니다. 클라이언트가 실행 중이면 로봇 PC의 설정이 완료된 것입니다. 로봇이 네트워크로 응답했는지는 아래 배포 단계에서 확인합니다.

### 모델 전송 및 설치 확인 \{#send-the-model-and-confirm-installation}

Play에서 모델을 테스트하고 배포하려는 체크포인트가 선택되어 있는지 확인합니다.

**로봇 배포**(Deploy) → **모델 추가**를 열고 프로젝트의 모델을 선택한 뒤 **배포 확인**(Review deployment)을 선택합니다.

<SimulationScreenshot file="deploy-action" width={702} height={612} focus="78.1% 17.4% 14.5% 58.4%" alt="로봇 배포에서 체크포인트를 선택한 뒤 배포 확인 버튼이 강조된 화면" />

1. 체크포인트, **모델 이름**, **로봇 ID**를 확인합니다. 로봇 ID는 대소문자를 구분하며 영문자, 숫자, 밑줄 또는 하이픈을 사용해 1~64자로 입력할 수 있습니다.
2. 안내가 표시되면 **GPU에서 검증·변환**을 선택한 뒤 **검증 종료 · 파일 준비**를 선택합니다. 변환에는 GPU 시간이 사용됩니다. 준비가 끝난 파일을 전송할 때는 추가 GPU 세션이 필요 없습니다.
3. 버튼 위의 배포할 모델과 대상 로봇을 확인한 뒤 **로봇에 배포**(Deploy to robot)를 선택합니다.

   <SimulationScreenshot file="deploy-review" width={570} height={828} focus="85.5% 8.2% 9.7% 65.8%" alt="모델과 대상 로봇이 표시된 배포 확인 화면에서 로봇에 배포 버튼이 강조된 모습" />

4. **배포 상세**에서 **파일 준비**, **요청 전달**, **파일 받기**, **모델 적용**, **완료** 단계를 확인합니다. 아래 화면은 **파일 준비** 단계가 진행 중인 모습입니다. **로봇 수신 완료**는 로봇이 요청을 받았음을 나타냅니다. **완료** 단계가 강조되고 상태가 **설치 완료**(Installed)로 바뀔 때까지 기다립니다.

   <SimulationScreenshot file="deploy-progress" width={556} height={718} focus="46.7% 13.5% 44.5% 7.8%" alt="배포 상태가 파일 준비 중으로 표시되고 파일 준비 단계만 강조된 화면" />

5. 배포 기록을 다시 열려면 프로젝트 상단의 **로봇 배포**를 선택한 다음 **로봇 배포 기록**에서 해당 기록을 찾습니다. 로봇이 마지막으로 보고한 설치 모델 목록을 보려면 **로봇에 설치된 모델**에서 **로봇 ID**를 선택합니다. 모션 실행은 로봇에서 별도로 시작합니다.

모델 카드에서 **로봇으로 보내기**를 선택하거나 체크포인트에서 **로봇에 배포**를 선택해 배포를 시작할 수도 있습니다. 설치 모델 목록이 확인되지 않거나 배포 기록에 **상태 확인 필요**(Check robot status)가 표시되면, 로봇에서 파일 다운로드와 설치 여부를 직접 확인한 뒤 **확인했어요 · 새 배포 허용**을 선택합니다.
