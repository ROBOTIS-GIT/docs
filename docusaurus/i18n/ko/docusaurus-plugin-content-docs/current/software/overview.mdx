<div className="software-overview-subsection">

### DYNAMIXEL Wizard 2.0

[DYNAMIXEL Wizard 2.0](/docs/software/dynamixel_wizard_2_0/introduction)은 다양한 운영체제에서 DYNAMIXEL 제품을 통합 관리할 수 있는 도구입니다.

DYNAMIXEL Wizard 2.0은 다음 기능을 제공합니다.

- DYNAMIXEL 펌웨어 업데이트
- DYNAMIXEL 진단
- DYNAMIXEL 설정 및 테스트
- DYNAMIXEL 데이터 실시간 그래프 표시
- DYNAMIXEL 패킷 생성 및 모니터링

</div>

<div className="software-overview-subsection">

### DYNAMIXEL SDK

[DYNAMIXEL SDK](https://docs.robotis.com/docs/software/dynamixel_sdk/)는 패킷 통신을 사용해 DYNAMIXEL 제어 기능을 제공하는 소프트웨어 개발 도구입니다.

DYNAMIXEL SDK의 API는 DYNAMIXEL 액추에이터와 DYNAMIXEL 기반 플랫폼에 맞춰 설계되었습니다.

소프트웨어를 올바르게 사용하려면 C/C++ 프로그래밍 언어에 대한 이해가 필요합니다.

</div>

<div className="software-overview-subsection">

### DYNAMIXEL Easy SDK

[DYNAMIXEL Easy SDK](/docs/software/dynamixel_easy_sdk)는 DYNAMIXEL SDK를 모터 객체 중심 설계로 감싸 처음 사용하는 사용자도 쉽게 다룰 수 있도록 만든 라이브러리입니다.

</div>

<div className="software-overview-subsection">

### DYNAMIXEL Workbench

[DYNAMIXEL Workbench](https://docs.robotis.com/docs/software/dynamixel_workbench/)는 DYNAMIXEL을 간단하게 제어할 수 있는 API를 제공하는 라이브러리입니다.

</div>

#### R+ Manager 2.0

[R+ Manager 2.0](/docs/software/rplus_manager_2_0)은 센서, 모터, 제어기, 서보의 펌웨어를 관리하고 테스트할 수 있는 도구입니다.

#### R+ Task 2.0

R+ Task 2.0은 CM-550과 같은 ROBOTIS 전용 제어기에 다운로드할 명령을 간소화된 C 언어 형태로 작성하는 태스크 편집기입니다.

#### R+ Motion 2.0

R+ Motion 2.0은 로봇의 자세를 만들고 연결하여 동작 루틴을 구성할 수 있는 모션 편집기입니다. ROBOTIS 제어기에 다운로드한 모션 파일은 R+ Motion 2.0에서 재생하거나 R+ Task 2.0으로 만든 코드에 삽입할 수 있습니다.

#### R+ Design 2.0

R+ Design 2.0은 단계별 로봇 조립 과정을 대화형으로 안내합니다. 선택 기능인 Creator Mode를 사용하면 ROBOTIS 부품 기반의 구조물을 직접 설계하고 개발할 수 있습니다.

#### R+ Mobile Apps

<ul className="software-overview-links">
  <li>R+ m.Task 2.0 <em>(기존 e-Manual)</em></li>

  <li>R+ m.Design <em>(기존 e-Manual)</em></li>

</ul>

R+ Block은 ROBOTIS 제어기를 Scratch 2.0 Offline Editor에 연결하여 블록 프로그래밍 방식으로 로봇을 프로그래밍할 수 있게 해줍니다.
